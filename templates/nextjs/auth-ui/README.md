# auth-ui template

Minimal Next.js App Router template for authentication-focused UI.

## Stack
- Next.js (App Router, TypeScript)
- Tailwind CSS
- Vendored shadcn-style UI primitives in `components/ui`

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Notes
- This template has no backend or database.
- Add your auth provider (Auth.js, Clerk, Supabase, custom API) as needed.
