# commerce-ui template

Minimal Next.js App Router template for product grid / storefront UI.

## Stack
- Next.js (App Router, TypeScript)
- Tailwind CSS
- Vendored shadcn-style UI primitives in `components/ui`

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Notes
- No checkout, payment, or database included.
- Extend with server actions or external APIs only when needed.
