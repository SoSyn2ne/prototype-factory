첫 시도는 견적 템플릿이 가장 작다. 파일 변환은 실제 형식과 예외율을 확보한 뒤,
현장 키트는 대리점의 책임·자격·공식 안내와 이동 원가를 확인한 뒤 진행한다.
어느 제안도 고객 접근이 확보되었다고 가정하지 않는다.

## 확인한 자료와 해석 한도

모든 링크 확인일은 2026-10-27이다. 확인된 공급사 설명·채용 업무와 우리 제안을 구분한다.

- [Salesmap 공식 요금 안내](https://salesmap.kr/pricing)는 견적 발행·영업 관리의
  기존 유료 대안이다. 청소팀의 구매나 맞춤 Excel 수요를 입증하지 않는다.
- [고용24 제조업 견적·원가 자동화 채용](https://www.work24.go.kr/wk/a/b/1500/empDetailAuthView.do?infoTypeCd=VALIDATION&infoTypeGroup=tb_workinfoworknet&wantedAuthNo=K180032609300075)은
  Excel 연동 견적·가격 데이터 업무를 맡길 고용 의향이다. 제조업에서 출장 에어컨 청소로
  좁힌 것은 인접 업종 가설이며, 소프트웨어 구매 기록이 아니다.
- [Sellmate 공식 기능 안내](https://www.sellmate.io/sellmate)는 채널 주문 파일을
  운송사 Excel 형식으로 고치는 기존 업무와 솔루션을 설명한다. 정확히 세 형식의 수요나
  제안 프로그램 결제를 보여 주지 않는다.
- [공식 일자리센터의 카페예 주문 관리 채용](https://www.1577-0365.or.kr/pro/workview/KJ21622609300003?wantedInfoUrl=https%3A%2F%2Fwww.work24.go.kr%2Fwk%2Fa%2Fb%2F1500%2FempDetailAuthView.do%3FwantedAuthNo%3DKJ21622609300003%26infoTypeCd%3DVALIDATION%26infoTypeGroup%3Dtb_workinfoworknet)은
  주문 취합·관리·CS와 Excel/ERP 인력이 필요한 업무 신호다. 업체가 우리 프로그램을
  원한다거나 구매할 예산이 있다는 뜻은 아니다.
- [TossPlace 설치·지원 FAQ](https://guide.tossplace.com/trouble/faq)와
  [긴급 결제 모드 안내](https://guide.tossplace.com/trouble/emergency-payment-mode)는
  공급사 운영 안내다. 장비·계약·조건에 따라 다르며 다른 POS/KDS나 보편적 오프라인
  결제로 일반화하지 않는다. 새 키트의 유료 수요도 증명하지 않는다.
- 기존 S06 Reddit 글은 확인일에 삭제/필터 처리되어 장비 대수·45분 지원 지연을
  현재 증거로 쓰지 않았다. 기존 S09 글 작성자는 자동화 제품 개발 중임을 밝히므로,
  의견과 이해관계가 섞인 자료다. 해당 주장을 시장 통계나 한국 업체 구매 증거로 사용하지 않는다.

## 공통 통과·중단 기준

한 고객이 합의한 유료 파일럿 비용을 실제로 결제하고, 같은 사례에서 기존 시간·오류와
납품 후 결과를 비교하며 고객이 결과를 검토해야 한다. 만족, 반복 사용, 재결제는
첫 결제와 다른 사건으로 각각 기록한다. 아직 어느 것도 발생했다고 표시하지 않는다.

기존 무료/유료 도구가 충분하거나 고객 접근이 안 되면 중단한다. 구축·교육·이동·수동 예외·
수정·지원 원가가 요금을 넘으면 범위를 줄이거나 종료한다. 세 상품 모두 처음에는 일회성이다.
월 관리에는 실제 변경 반영·검토·점검의 납품물과 빈도·지원 한도가 필요하다.
무제한 지원이나 수동적 정상 가동·안전 보장을 월 요금 이유로 삼지 않는다.

CSV 프로그램은 자동 카카오 수집·주문/배송 처리를 하지 않는다. 현장 키트는 전원·케이블·
네트워크 초기화를 지시하지 않으며 각 공급사의 승인된 담당자에게 연결한다.
