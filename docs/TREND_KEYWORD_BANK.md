# Trend Keyword Bank

Use this as a seed list for `/pf idea` and daily Phase A searches. Do not ship ideas from keywords alone. Combine a keyword with a real trigger, user anxiety/desire, data source, and one-screen interaction.

## Search Pattern

Use combinations like:

- `<trend keyword> + 위치 / 재고 / 웨이팅 / 후기 / 가격 / 양도 / 교환`
- `<trend keyword> + 카톡 / 답장 / 말투 / 변환 / 소개팅 / 회사`
- `<trend keyword> + 비용 / 손해 / 보험 / 구독 / 학원비 / 리셀`
- `<trend keyword> + 엄마카페 / 블라인드 / 디시 / 더쿠 / X / Reddit`

## Candidate Formula

Strong PF candidates usually look like:

`trend keyword + immediate anxiety/desire + one-screen tool`

Examples:

- MBTI 카톡 답장 변환기
- 두쫀꾸 판매점/재고 지도
- 팝업스토어 웨이팅 생존 보드
- 팬싸 응모비 손익 계산기
- 펫보험 갱신 폭탄 비교표
- 회사 말투 순화 번역기
- 굿즈 랜덤깡 교환 매칭판
