# Assumptions (KNOWN / ASSUMPTION / UNKNOWN)

## KNOWN
- The demo must run fully offline with vanilla HTML, CSS, and JS only.
- Required inputs are group, closeness, urgency, event date, channel, and notes.
- Required outputs are three variants with copy buttons and visible numeric scores.

## ASSUMPTION
- Users are drafting one-off nudges, not running a bulk reminder campaign.
- Higher closeness should allow warmer language; higher urgency should tighten the ask.
- Notes are short context fragments such as seating, catering, or travel cutoffs.

## UNKNOWN
- Whether output should stay English-only or support KR/EN later.
- Whether users want guest-name placeholders instead of group-level wording.
- Whether the score should eventually map to real test data instead of heuristics.
