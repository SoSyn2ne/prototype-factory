# PRD — Dating Photo Reality Check

## Problem
- A playful authenticity booth that helps daters spot over-AI’d profile photos and publish a funny real-human confidence card.
- External signal references:
  - Signal 8: Reddit r/ChristianDating — AI-generated dating photos becoming normal — https://www.reddit.com/r/ChristianDating/comments/1sh2ntw/ai_generated_dating_profile_pics_are_becoming_a/
  - Signal 9: Evie Magazine — AI-generated profiles on dating apps as scam risk — https://www.eviemagazine.com/post/ai-generated-profiles-on-dating-apps-are-the-latest-scam-to-watch-out-for

## Target user
- Dating-app users, matchmakers, singles communities, safety-conscious daters, and friends reviewing a profile before someone gets embarrassed or catfished.

## Key UX
- Upload or paste profile photos and prompts; the app highlights too-perfect signals, asks humanizing proof questions, suggests warmer real-photo replacements, and generates a shareable “probably human” card.

## Required UI sections
- profile photo drop zone
- too-perfect signal scanner
- human proof question deck
- catfish embarrassment meter
- real-photo replacement coach
- friend review reaction strip
- shareable probably-human card

## Stitch prompt
Design a playful mobile-first dating safety prototype called Dating Photo Reality Check for dating-app users, matchmakers, singles communities, safety-conscious daters, and friends reviewing a profile before someone gets embarrassed or catfished. Users should upload or paste profile photos, captions, and conversation openers, then highlight too-perfect AI-photo signals, ask humanizing proof questions, suggest warmer real-photo replacements, estimate catfish embarrassment risk, and generate a shareable probably-human confidence card. Include a profile photo drop zone, too-perfect signal scanner, human proof question deck, catfish embarrassment meter, real-photo replacement coach, friend review reaction strip, and shareable probably-human card. Design direction: use a playful-experimental aesthetic with dating-app swipes, glossy pink/blue gradients, cheeky authenticity stickers, memeable verdict cards, and bold micro-animations so the prototype feels funny, protective, and viral rather than accusatory.

## Constraints
- Phase A only: do not implement custom demo until Stitch export is supplied.

- Preserve the assigned design profile in downstream demo generation.

## Non-goals

- Production-grade integrations or automated external API calls.
