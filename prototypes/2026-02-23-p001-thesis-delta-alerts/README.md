# Thesis Delta Alerts

Daily, falsifiable alerts that tell you what changed in your investment thesis—and what to do next.

## Status
- prototype (spec-first)

## Concept
A lightweight “incident-response style” daily brief for long-term investing.

- **Anchor (similar):** news alerts / newsletters / portfolio trackers that send “what happened”
- **Contrast #1:** incident response runbooks (severity, impact, next actions, owner)
- **Contrast #2:** game daily quests (small, clear actions that create momentum)

**Synthesis:** instead of summarizing news, generate a *Thesis Delta Card* that:
1) states the claim it may affect, 2) labels uncertainty (KNOWN/ASSUMPTION/UNKNOWN), and 3) proposes one tiny verification action.
