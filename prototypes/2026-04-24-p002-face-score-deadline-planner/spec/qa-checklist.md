# QA checklist — Face Score Deadline Planner

## Happy path
- User can add an event and immediately see a ranked routine path.
- Budget and payoff tradeoffs remain visible in one screen.
- Confidence notes and rescue steps are written as concrete actions, not placeholders.

## Edge cases
- Very short deadlines still preserve a useful rescue path.
- Minimal-input users still get a readable plan without broken empty states.
