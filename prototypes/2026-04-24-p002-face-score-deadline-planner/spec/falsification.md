# Falsification checklist — Face Score Deadline Planner

1. If users treat beauty prep as emotional self-care rather than a prioritization problem, the planner may feel too cold.
2. If visual payoff cannot be simplified credibly, the ranking system will feel fake.
3. If deadline events vary too widely, the shared template may not feel relevant enough.
4. If salon and product recommendations become the main expectation, the product may drift into an affiliate content business.
5. If users only use the tool once per year, recurring value may be weak.
6. If the interface increases self-criticism instead of clarity, users will bounce quickly.
