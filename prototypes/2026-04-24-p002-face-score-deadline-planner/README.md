# Face Score Deadline Planner

A glow-up scheduling planner that helps users choose the cheapest high-payoff skin, hair, and styling moves before interviews, blind dates, or reunion photos.

## Context
- Theme: 외모
- Design profile: premium-editorial
- Target user: Young professionals and women in Korea preparing for a visible deadline event who want to look more expensive and rested without buying every trending treatment.

## Key UX
- Show the shortest path from tired and uneven to camera-ready by ranking appearance actions by time, cost, and visible payoff.

## Required UI sections
- deadline glamour snapshot
- event countdown strip
- skin-hair-style payoff matrix
- budgeted routine ladder
- before-photo confidence notes
- last-minute rescue drawer

## Stitch prompt
Design a desktop beauty prep planner called Face Score Deadline Planner for people who need to look more polished for an interview, date, reunion, or photo-heavy event without wasting money on random treatments. It should help users rank skin, hair, and styling moves by time, cost, and visible payoff so they can become camera-ready on a deadline. Include a deadline glamour snapshot, an event countdown strip, a skin-hair-style payoff matrix, a budgeted routine ladder, before-photo confidence notes, and a last-minute rescue drawer. Design direction: use a premium-editorial aesthetic with warm ivory and stone tones, polished editorial typography, elegant spacing, and restrained beauty-service cues so the product feels aspirational, composed, and quietly luxurious.
