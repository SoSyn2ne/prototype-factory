# Falsification checklist (5–7)

1. Reject if users cannot understand category stacking without reading long text.
2. Test drag-to-split interaction with at least six cart items.
3. Verify uncertainty labels prevent false precision.
4. Confirm savings deltas and delay tradeoffs both remain visible.
5. Reject if it feels like generic ecommerce checkout.
6. Check mobile layout for cart rows and shipment groups.
7. Validate that the share card clearly says split or ship together.
