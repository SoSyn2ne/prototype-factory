# Health Screening Turnaround Coach

A post-checkup reset planner that turns scary health-screening flags into a calm 8-week routine for food, movement, sleep, and retest readiness.

## Status
- prototype

## Theme and design
- Theme: 건강
- Design profile: calm-consumer

## Core UX
- Translate red-flag lab numbers into a simple weekly recovery plan with clear behavior targets, emotional reassurance, and visible progress toward the next test date.
