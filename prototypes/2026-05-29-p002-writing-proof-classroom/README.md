## Stitch prompt
Create a responsive web app prototype for "Writing Proof Classroom," a low-friction writing room that records draft process evidence without turning every essay into an AI accusation fight. Include: assignment launch header, student focused writing room, outline/draft/reflection steps, paste/import event log, version-history strip, teacher process-timeline review, student explanation panel, parent/admin share packet, tutor coaching rubric, and policy-safe export without AI probability scoring. Design direction: use the calm-consumer profile with reassuring classroom language, soft but clear process states, low-drama evidence cards, and teacher-friendly review surfaces; it should feel like a trust-preserving writing workflow, not surveillance software.
