# Falsification checklist

1. If it becomes a generic pricing calculator, reject.
2. If one-night vs long-stay margin is not visible, the core value is missing.
3. If guest backlash is decorative instead of tied to specific policies, redesign.
4. If checkout task copy is absent, the guest-trust angle is weak.
5. If cleaner quote comparison is not actionable, simplify.
6. If post-booking fee warnings are missing, the product ignores the strongest pain signal.
7. If the first screen lacks operator density, revise for the assigned profile.
