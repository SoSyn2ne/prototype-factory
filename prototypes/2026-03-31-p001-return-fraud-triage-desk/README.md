# Return Fraud Triage Desk

An operations desk that helps support teams triage suspicious return claims fast, protect margin, and escalate only the cases worth manual review.

## Status
- prototype

## How to use
- Review the framing in `spec/prd.md`.
- Stitch export is ingested in `demo/` and preserved in `demo/original/code.html`.
- Open the PF-safe demo wrapper to inspect the screen locally.
