# QA checklist

## Happy path
- First screen communicates: When care costs $7,500 to $24,000 a month, “I think they did it” is not enough.
- User can identify the target user and trigger within 3 seconds.
- User can complete the primary mechanic: shift baton.
- Prototype produces: Shift handoff report and weekly care consistency summary..

## Edge cases
- Empty input state explains what proof/data is needed.
- User with partial evidence can still get a next step.
- Mobile layout keeps key actions reachable.
- Copy avoids claiming legal, medical, insurance, or financial guarantees.

## Acceptance verification
- Design profile appears exactly once as field-ops.
- Required sections are present: Today care baton, Medication and meal checkoff, Exception photo/note log, Next caregiver briefing, Monthly cost and coverage snapshot.
- Stitch prompt cites signals S7, S8, S9 as problem evidence only.
- No custom demo is implemented during Phase A.
