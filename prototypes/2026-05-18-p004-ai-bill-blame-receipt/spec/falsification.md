# Falsification checklist (5-7)

1. The core user does not recognize the triggering event as urgent.
2. Existing tools already solve the exact workflow with less effort.
3. Required inputs are too hard to gather during the panic moment.
4. The output artifact is not trusted by the intended recipient.
5. The design profile does not fit the user context or makes the product feel unserious.
6. The idea is too close to a recent PF batch after reviewing user, trigger, data source, and interaction mechanic.
7. Stitch cannot render the required UI sections clearly in one primary experience.
