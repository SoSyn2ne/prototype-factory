# Falsification checklist (5-7)

1. The first screen reads like a generic dashboard instead of a escalation file.
2. The prototype does not visibly produce State complaint or small-claims packet with evidence timeline.
3. The required UI sections are missing or reduced below the Phase A spec.
4. The design does not match the calm-consumer profile.
5. The idea cannot cite its source signals: S12, S13.
6. The core trigger is not obvious in 3 seconds: The friendly contractor has your deposit, your texts, and suddenly no calendar.
7. The flow asks for vague data instead of concrete inputs from the source-signal workaround.
