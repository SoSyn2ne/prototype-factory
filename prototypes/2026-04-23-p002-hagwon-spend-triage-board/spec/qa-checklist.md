# QA checklist — Hagwon Spend Triage Board

## Happy path
- User can input multiple classes and immediately see total spend and fatigue load.
- Keep, cut, and replace actions update the weekly timetable clearly.
- Decision notes can capture the reason for each tradeoff without placeholder text.

## Edge cases
- Empty or partially filled manual inputs still preserve a readable layout.
- Very high stress or urgency scenarios still keep one obvious next action visible.

## Acceptance verification
- Theme is labeled as 사교육.
- Design profile is labeled as operator-dense.
- Required UI sections are present in the written spec and ready for Stitch export handoff.
