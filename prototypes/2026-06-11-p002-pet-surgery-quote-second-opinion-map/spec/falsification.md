# Falsification checklist (5–7)

1. The UI encourages delay without showing urgency and symptom risk.
2. The concept reads like veterinary diagnosis instead of quote/aid triage.
3. The map does not visibly compare second-opinion options, distance, and payment/aid routes.
4. The call sheet is missing quote line items or clinic questions.
5. The design profile is not visibly calm-consumer.
6. Source signals S3 and S4 are not referenced in the concept notes.
7. Any placeholder text remains in the spec.
