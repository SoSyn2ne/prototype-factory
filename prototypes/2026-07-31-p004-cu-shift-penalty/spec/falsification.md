# Falsification checklist — p004 KR 편의점 시프트/알바비 Penalty 시뮬레이터

1. 5명의 편의점/1인 자영업자 점주가 "엑셀로 충분하다"고 답하면 kill.
2. 3 시나리오 (현행/19시간 단축/부분 무인화) 인건비 계산이 실제 사례와 ±10% 차이나면 kill.
3. 시프트 7칸 자동 분배가 현실적이지 않으면 (점주 5명 평가) kill.
4. owner 노동시간 gauge가 실제 owner 노동 시간과 ±2시간 차이나면 kill.
5. 소상공인 정책자금 데이터 freshness > 14일이면 kill.
6. 모바일/태블릿 1-hand 인터랙션이 1분 안에 1 시나리오 결정 못 하면 kill.
7. 소상공인 정책자금/카드 referral로 수익화 모델이 안 서면 kill.
