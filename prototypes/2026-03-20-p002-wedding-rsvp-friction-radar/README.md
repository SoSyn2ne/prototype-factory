# Wedding RSVP Friction Radar

A lightweight dashboard that finds where guests drop off (viewed → maybe → RSVP) and suggests targeted nudge templates.

## Status
- prototype

## Why this exists
Wedding RSVP follow-ups are stressful because you don’t know *who* needs a nudge and *what kind* of nudge is respectful.

This prototype shows an offline workflow:
- segment guests,
- spot the biggest drop-off,
- generate a polite message draft for that situation.

## How to run (demo)
- Open `demo/index.html` in a browser (works offline / `file://`).
- Filter by segment and click a guest.
- Generate a nudge and adjust tone.

## Manual checklist
- Segment filter updates counts and table.
- Generating nudges changes copy immediately.
- No external network requests.
