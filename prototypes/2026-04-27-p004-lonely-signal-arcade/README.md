# Lonely Signal Arcade

A playful anti-loneliness prototype that turns tiny check-ins, awkward invites, and missed social chances into a glowing social quest map.

## Status
- Phase A scaffolded for Stitch export ingest.

## Candidate
- Type: Fun / Experimental
- Theme: 외로움
- Design profile: playful-experimental
- Target user: Young adults who feel socially stuck, want more low-pressure connection, and need a playful push to send one message instead of doom-scrolling alone.
- Key UX: Convert loneliness into a game-like signal path: pick a tiny social quest, send a low-risk invite, and watch connection energy build through visual feedback.
