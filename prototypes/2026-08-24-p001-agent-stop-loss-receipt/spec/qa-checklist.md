# QA checklist

## Happy path
- First screen states the job and primary action.
- Core interaction runs from input through final artifact.
- Required sections: goal + stop-condition intake; live work drift strip; cost/file/test ledger; salvage preview; stop-or-continue gate; decision receipt.

## Edge cases
- Empty input, incomplete input, blocked action, error, retry, and completed state are distinct.
- Long labels and mobile width do not hide the primary action.
- Sample data is clearly labeled.

## Acceptance verification
- Exactly one design profile: operator-dense.
- Theme matches: graphite workbench, one amber action accent, compact 40px evidence rows, 8px corners, no celebratory KPI hero.
- Sources S01, S09 resolve to the daily evidence list.
- No custom demo is implemented during Phase A.
