# PRD - Friend Pitch Night Studio

## Summary
A playful event kit that helps friends pitch their single friends offline without turning the night into another dating-app profile review.

## Candidate type
- Fun / Experimental

## Problem
- S8: Singles are burned out from swiping and moving toward run clubs, dinners, friend pitches, and lower-pressure in-person formats.
- S9: Users ask strangers for profile reviews after premium tiers and no results, showing shame and uncertainty around self-presentation.

## Target user
- Gen Z and millennial friend groups, singles-event hosts, community organizers, and creators making offline dating events more social.

## Key UX
- Friends build a short pitch deck for one single person, choose the vibe, add conversation-safe details, set boundaries, and generate a live event slide plus shareable invite card.

## Required UI sections
- Pitch subject consent and boundary check
- Friend quote collector with green/yellow/red detail labels
- Vibe selector for dinner-party, run-club, karaoke, book-club, and chaotic PowerPoint night
- Slide builder with strengths, ideal first setting, and do-not-say-this guardrails
- Audience reaction meter and match-intro queue
- Event host control panel for timing, slides, and opt-out
- Shareable invite card and post-night reflection
