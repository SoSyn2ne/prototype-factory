# Assumptions (KNOWN / ASSUMPTION / UNKNOWN)

## KNOWN
- Core concept: Compare venue, photo, makeup, and ceremony timelines to catch handoff gaps before wedding day.
- Primary user: Couples or wedding coordinators juggling multiple vendor schedules and last-minute timing changes.
- Desired interaction style: A merged timeline view that highlights conflicts, missing owners, and too-tight buffers with clear fix suggestions.

## ASSUMPTION
- Users prefer a single summary screen before drilling into details.
- The first version can rely on manually entered or mocked data.
- The most valuable output is a prioritized action list, not raw data exhaust.

## UNKNOWN
- Which data fields are absolutely mandatory on day one.
- Whether users want print/export first or collaboration first.
- Which visualization earns the fastest trust in real usage.
