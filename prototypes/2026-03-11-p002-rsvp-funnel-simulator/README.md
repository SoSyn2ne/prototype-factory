# RSVP Funnel Simulator

Model a wedding RSVP journey (invited→opened→responded) and stress-test reminder timing with a simple conversion simulator.

## Status
- prototype

## How to run (demo)
- Open `demo/index.html` in a browser.
- Everything is local; scenarios persist via `localStorage`.

## Manual checklist
- Create a scenario with 120 invites and a caterer deadline.
- Add a reminder at T-14 days and compare to T-7 days.
- Confirm the forecast chart and "by deadline" number updates.
- Refresh; scenario should still exist.
