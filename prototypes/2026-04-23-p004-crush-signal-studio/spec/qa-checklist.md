# QA checklist — Crush Signal Studio

## Happy path
- User can enter a crush scenario and get multiple move cards without placeholder copy.
- Risk-versus-reward scenes clearly differentiate bold, safe, and chaotic options.
- The recap drawer leaves the user with a memorable shareable outcome.

## Edge cases
- Empty or partially filled manual inputs still preserve a readable layout.
- Very high stress or urgency scenarios still keep one obvious next action visible.

## Acceptance verification
- Theme is labeled as 성욕.
- Design profile is labeled as playful-experimental.
- Required UI sections are present in the written spec and ready for Stitch export handoff.
