# PRD — Wedding Trip Stack Tetris

## Problem
- Wedding guests fit flights, outfits, gifts, PTO, and guilt into a budget block puzzle before the season overflows.

## Target user
- Wedding guests, friend groups, couples attending multiple events, and social-budget content creators.

## Key UX
- Drag wedding obligations into a season grid, stack shared lodging and outfits, watch guilt and budget meters, and export a polite decline or attendance plan.

## Required UI sections
- wedding event queue
- season budget grid
- trip-stack blocks
- outfit and gift reuse lane
- guilt meter
- plan/decline card export

## Design profile
- financial-analyst

## Theme
- wedding guest budget, social pressure, travel planning

## Source signal references
- S13 MarketWatch wedding guest cost pressure
- S14 viral prop-hunt and fast social game loops

## Stitch prompt
Build a polished web prototype called "Wedding Trip Stack Tetris" for guests juggling too many weddings in one season. The first screen should show wedding events as draggable budget blocks, a season grid, shared lodging and outfit reuse lanes, gift and PTO costs, a guilt meter, and exportable attend/decline cards. Required sections: wedding event queue, season budget grid, trip-stack blocks, outfit and gift reuse lane, guilt meter, and plan/decline card export. Design direction: use the financial-analyst profile with crisp budget math, playful block-grid structure, tasteful social-pressure cues, and clean cards that feel shareable.

## Constraints
- Phase A only: do not implement a custom demo here.
- The 08:30 Stitch automation should export code.html and screen.png into the expected drop folder.

## Success metrics
- A reviewer can understand the first screen, target user, source evidence, and design profile without additional context.
- Stitch prompt is copy/paste-ready and contains the tailored profile direction.
