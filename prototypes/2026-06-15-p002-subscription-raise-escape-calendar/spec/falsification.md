# Falsification checklist (5-7)

1. Users say the problem is annoying but not urgent enough to open a tool.
2. Existing platform features already solve the trigger moment.
3. The source signals are isolated anecdotes rather than repeated workarounds.
4. The generated UI looks like a generic dashboard instead of the named workflow.
5. The output artifact is not useful enough to save, send, print, or act on.
6. Users cannot gather the required evidence quickly.
7. The product creates more anxiety than clarity.
