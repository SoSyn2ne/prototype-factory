# Falsification checklist (7)

1. If users still rely on their spreadsheet because this adds one more place to update, it fails.
2. If suggested messages feel “too templated” and users don’t copy them, the messaging value is weak.
3. If urgency ranking causes arguments (e.g., partner disagrees), the model needs transparency/explanations.
4. If friction is hard to estimate and users leave it blank, the input model is wrong.
5. If most guests respond quickly and there’s little triage work, the product is unnecessary.
6. If planners need multi-event/venue constraints (meal choices, plus-ones) first, this scope is mis-prioritized.
7. If privacy concerns still block usage even offline (shared laptop), the UX needs stronger local protection.
