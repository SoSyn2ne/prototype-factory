# Falsification checklist (5–7)

1. The first screen reads like a generic ecommerce dashboard instead of TikTok Shop return triage.
2. Settlement lines, shop-score risk, fund holds, and return inspection decisions are not visible.
3. The operator cannot tell which returns need action before a deadline.
4. The design profile `operator-dense` is not evident in layout density, controls, and status language.
5. The prototype implies guaranteed dispute recovery or legal advice.
6. Signal references, theme, and design profile are missing from metadata or PRD.
7. The concept overlaps with prior chargeback prototypes without platform-specific mechanics.
