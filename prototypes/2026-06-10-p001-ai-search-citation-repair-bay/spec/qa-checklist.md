# QA checklist

## Happy path
- Select a bad AI answer for the sample dental clinic.
- See the wrong competitor and missing citation highlighted.
- Add a website FAQ patch and directory update to the repair packet.
- Export the repair packet.

## Edge cases
- AI answer is mostly correct but cites a weak or stale source.
- Competitor is correctly cited for a different service area.
- Owner's canonical facts are incomplete.

## Acceptance verification
- The Stitch output should show brand facts, comparison lanes, citation gap table, repair queue, and packet preview.
- The visual direction should read as operator-dense, not a marketing landing page.
