# PRD - Wearable Panic Detox Booth

## One-liner
A playful health-tech reset that helps obsessive smartwatch and ring checkers turn scary metrics into calmer experiments and shareable boundaries.

## Candidate type
Fun / Experimental

## Target user
Smartwatch, smart ring, HRV, sleep-score, and recovery-score users who compulsively check metrics and want a lighter way to regain control.

## Problem
The target user is facing an emotionally charged, expensive, or reputation-sensitive decision where raw information is scattered across messages, screenshots, bills, device metrics, or family/operator memory. The prototype should turn that scattered situation into one clear guided workflow.

## Key UX
Users pick their panic metric, reveal the checking loop, set a tiny experiment, hide noisy numbers, and generate a funny boundary card for themselves or friends.

## Required UI sections
- Panic metric selector
- Checking-loop confession wheel
- Signal-versus-noise explainer cards
- Tiny experiment builder
- Number hiding and notification boundary controls
- Doctor-question note pad
- Detox streak booth
- Shareable calm-data boundary card

## Stitch prompt
Design a playful experimental web product called Wearable Panic Detox Booth for smartwatch, smart ring, HRV, sleep-score, and recovery-score users who compulsively check metrics and want a lighter way to regain control. Users choose the metric that scares them, map their checking loop, learn what the signal can and cannot prove, set a tiny real-world experiment, hide noisy numbers for a chosen window, prepare doctor questions when needed, and generate a shareable calm-data boundary card. Include a panic metric selector, checking-loop confession wheel, signal-versus-noise explainer cards, tiny experiment builder, number hiding and notification boundary controls, doctor-question note pad, detox streak booth, and shareable calm-data boundary card. Design direction: use the playful-experimental profile with bright clinic-arcade energy, tactile booth controls, friendly warning labels, expressive but legible data cards, and one obvious panic-to-boundary flow so the concept feels funny and portfolio-worthy without trivializing health anxiety.

## Non-goals
- Do not implement a production backend in Phase A.
- Do not replace professional legal, medical, financial, or admissions advice.
- Do not turn the experience into a generic dashboard; preserve the core workflow.
