# Falsification Checklist - Gig Algorithm Pay Diary

1. Can the target user understand the value without reading an explainer?
2. Does the prototype avoid becoming a generic dashboard?
3. Does each source signal support a real user pain rather than just a trend headline?
4. Would the user currently solve this with screenshots, spreadsheets, notes, calls, or forum advice?
5. Is the output shareable or actionable within one session?
6. Does the design profile visibly shape the UI?
7. Is the prototype different from the last 7 PF daily batches by user, trigger, data source, or interaction mechanic?
