# QA checklist

## Happy path
- First screen communicates: “Fair use” feels different when your face, voice, article, or fan community becomes someone else’s model fuel.
- User can identify the target user and trigger within 3 seconds.
- User can complete the primary mechanic: consent/takedown timeline.
- Prototype produces: Consent ledger page plus takedown/licensing draft..

## Edge cases
- Empty input state explains what proof/data is needed.
- User with partial evidence can still get a next step.
- Mobile layout keeps key actions reachable.
- Copy avoids claiming legal, medical, insurance, or financial guarantees.

## Acceptance verification
- Design profile appears exactly once as premium-editorial.
- Required sections are present: Work catalog intake, Consent status timeline, AI-use evidence drawer, License ask calculator, Takedown/notice draft.
- Stitch prompt cites signals S15, S16, S17 as problem evidence only.
- No custom demo is implemented during Phase A.
