# Falsification checklist

1. If the app feels like a joke and not a housing decision tool, it fails.
2. If monthly rent, deposit, and subsidy state are not visible together, the workflow is broken.
3. If roommate cards ignore lifestyle conflict, the concept loses its emotional hook.
4. If deposit risk is oversimplified into legal advice, redesign.
5. If the draft-board composition hides the main recommendation, simplify.
6. If the app duplicates a generic rent calculator, reject.
7. If Korean renter context is not obvious from the first screen, revise.
