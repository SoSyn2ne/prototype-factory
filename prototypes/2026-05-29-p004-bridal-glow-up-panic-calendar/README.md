## Stitch prompt
Create a responsive web app prototype for "Bridal Glow-Up Panic Calendar," a wedding-countdown beauty planner that turns last-minute glow-up anxiety into safe, budget-aware, photo-ready micro-decisions. Include: wedding countdown and panic-level header, budget and photo-priority intake, routine inventory, safe-to-try calendar, lock-in/no-new-product zones, vendor appointment and patch-test timeline, last-30-days micro-decision deck, photo-confidence ritual lane, and shareable "do not panic buy this" card. Design direction: use the playful-experimental profile with stylish bridal countdown energy, bold but readable panic states, tactile calendar cards, beauty-budget cues, and shareable advice moments; it should feel like a clever anti-panic companion, not a generic wedding checklist.
