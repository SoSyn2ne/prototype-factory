## Happy path
- User can identify the target user and core job from the first viewport.
- User can follow the primary workflow from input to decision/export/share outcome.
- All required UI sections are present.
- Design profile is exactly one of the PF profiles: playful-experimental.

## Edge cases
- Empty state explains what to add first without a marketing landing page.
- Risk/warning states are visible without overwhelming the screen.
- Mobile layout keeps controls usable and text contained.
