# GPU Job Health Triage Board

A lightweight board to classify failing GPU jobs (OOM/thermal/driver/data) and suggest the next diagnostic step.

## Status
- prototype

## How to run (demo)
- Open `demo/index.html` in a browser.
- Paste a short log excerpt and toggle any observed symptoms.

## Manual checklist
- Example buttons fill the form and produce output.
- Classification + next steps update when inputs change.
- Copy note copies a concise incident note to clipboard.
- Tagging updates counts.
