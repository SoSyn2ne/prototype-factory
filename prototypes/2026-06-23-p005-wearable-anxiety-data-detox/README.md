# Wearable Anxiety Data Detox

Health wearable users separate useful signals from false alarms before sleep scores and recovery metrics hijack their day.

## Target user
Smart ring, Whoop, Apple Watch, and fitness tracker users who feel anxious or confused by unreliable sleep, recovery, and stress metrics.

## Key UX
User imports daily wearable signals and lived context; the app labels which alerts deserve action, which need confirmation, and which should be muted for anxiety control.

## Required UI sections
- Morning score sanity header with wearable score vs lived context
- False alarm sorter for sleep, recovery, ECG, stress, and activity signals
- Symptom and context journal with caffeine, illness, travel, and workload
- Action threshold builder for doctor call, rest day, retest, or ignore
- Subscription and device trust meter
- Data detox mode scheduler for muting noncritical metrics
- Shareable calm summary for coach, partner, or clinician
