# Falsification checklist (5–7)

1. **Top results are noise:** On 10 transcripts, users judge >50% of the top-5 flags as irrelevant (false positives).
2. **Misses obvious red flags:** For the same set, the tool fails to flag clear phrases like “withdrawing guidance”, “inventory correction”, “pricing pressure”, or “license/export restrictions”.
3. **Rule explanations don’t help:** Even with “Explain rules” on, users cannot understand why an item is flagged, so they don’t trust the output.
4. **Highlight UX fails:** Users click a flag and still can’t quickly find the exact quote in the transcript (scrolling/highlighting not reliable).
5. **Workflow mismatch:** Users want “upload PDF / fetch transcript / export to notes” as table stakes and won’t paste text manually.
6. **Compliance blocks usage:** Even a local-only browser tool is disallowed for transcript handling in the target environment.
7. **Category model is wrong:** Users repeatedly ask for different primary buckets (e.g., margin, FX, backlog, lead times) making the current taxonomy unhelpful.
