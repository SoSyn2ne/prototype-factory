# PRD — Layoff Buffer Action Map

## Problem
- A household cash defense workspace that helps salaried families stress-test layoffs, severance timing, debt pressure, and spending cuts before a job shock turns into a forced panic sale.
- Households usually discover their true cash fragility only after the income shock arrives, when every move feels late, emotional, and expensive.

## Target user
- Dual-income households and mid-career workers who worry that one bad quarter, restructuring rumor, or surprise dismissal could wreck savings momentum.

## Constraints
- Time: Users should understand the top action path in under 5 minutes.
- Budget: The first version should work with manual input, lightweight imports, and no deep enterprise integrations.
- Platform: Desktop-first planning product designed for a single high-focus session.

## Non-goals
- Full back-office system replacement.
- Heavy automation that requires hidden AI decisions.
- Multi-role admin tooling beyond the core operator or end-user workflow.

## Success metrics
- Users can understand risk, upside, or chemistry state in one screen.
- Users can identify the next action without reading a long manual.
- The interface makes the emotional driver of the product feel obvious rather than abstract.

## Notes
- Theme: 자산 방어.
- Design profile: financial-analyst.
- Core UI sections: household runway snapshot, severance timing scenarios, bill pressure waterfall, cut-now versus cut-later board, emergency cash move planner, partner alignment notes drawer.
