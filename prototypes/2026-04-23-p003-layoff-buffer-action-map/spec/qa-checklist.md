# QA checklist — Layoff Buffer Action Map

## Happy path
- User can compare at least two layoff scenarios with visible runway differences.
- Essential bills and optional cuts are visually distinct in the waterfall and cut board.
- The next three protective actions are obvious without reading long instructions.

## Edge cases
- Empty or partially filled manual inputs still preserve a readable layout.
- Very high stress or urgency scenarios still keep one obvious next action visible.

## Acceptance verification
- Theme is labeled as 자산 방어.
- Design profile is labeled as financial-analyst.
- Required UI sections are present in the written spec and ready for Stitch export handoff.
