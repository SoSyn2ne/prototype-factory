# GPU Power-Cap Experiment Planner

Plan and log power-cap/undervolt experiments with expected perf, thermals, and cost-per-job.

## Status
- prototype

## How to run
- Open `demo/index.html` in a browser.

## Manual checklist
- Enter baseline 200W / 72°C / 100 units/hr and electricity price.
- Confirm a cap table (120–200W) appears.
- Move sensitivity slider → values update.
- Log one run → appears and persists after refresh.
