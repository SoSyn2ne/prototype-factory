## Stitch prompt
Design a desktop seller-defense operations product called TikTok Shop Payout Freeze Desk for TikTok Shop sellers, small DTC brands, marketplace operators, and accountants facing withheld payouts, fraudulent return claims, rising seller fees, and frozen accounts. Users should import payout statements, order IDs, refund/return claims, affiliate and ad spend, Seller Center notices, appeal deadlines, and cash obligations, then separate true margin from platform hold risk, build evidence packets for disputed returns, prioritize appeal actions, and forecast whether the shop can survive the next payout cycle. Include a payout-hold intake, order/refund evidence board, fee and ad-spend margin waterfall, frozen-account deadline rail, appeal packet builder, cash-gap forecast, and operator handoff checklist. Design direction: use an operator-dense aesthetic with compact transaction tables, urgent but disciplined red/amber status rails, evidence thumbnails, payout timers, and spreadsheet-like margin clarity so the product feels like a serious rescue desk for sellers whose cash is trapped, not a generic ecommerce dashboard.
