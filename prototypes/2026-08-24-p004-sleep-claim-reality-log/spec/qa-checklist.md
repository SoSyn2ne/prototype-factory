# QA checklist

## Happy path
- First screen states the job and primary action.
- Core interaction runs from input through final artifact.
- Required sections: claim pinboard; morning check-in; confounder tags; agreement timeline; uncertainty explainer; clinician question card.

## Edge cases
- Empty input, incomplete input, blocked action, error, retry, and completed state are distinct.
- Long labels and mobile width do not hide the primary action.
- Sample data is clearly labeled.

## Acceptance verification
- Exactly one design profile: calm-consumer.
- Theme matches: quiet midnight-blue and cream, one lavender accent, spacious diary rhythm, 12px cards, no medical alarm styling.
- Sources S04, S10 resolve to the daily evidence list.
- No custom demo is implemented during Phase A.
