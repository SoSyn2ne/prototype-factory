# QA checklist

## Happy path
- Open the prototype spec and understand the main decision loop within one pass.
- Confirm the required UI sections support the core workflow: Turn scattered symptoms into a readable weekly pattern, spot which routines actually help, and prepare a clearer conversation for the next doctor visit without spiraling.

## Edge cases
- Validate that emotionally sensitive states still feel clear and non-chaotic.
- Check that the design profile (calm-consumer) stays visible without overpowering usability.

## Acceptance verification
- Theme is explicitly labeled as 건강.
- Stitch prompt is copy-ready and includes explicit design direction.
- Meta/spec text matches the daily idea card with no placeholders.
