# Perimenopause Pattern Coach

A symptom-pattern planning dashboard that helps women connect sleep, mood, cycle shifts, and recovery habits into a calmer weekly health plan before daily life starts unraveling.

## Status
- prototype

## Theme
- 건강

## Design profile
- calm-consumer

## Key UX
- Turn scattered symptoms into a readable weekly pattern, spot which routines actually help, and prepare a clearer conversation for the next doctor visit without spiraling.

## Required UI sections
- symptom and cycle summary
- weekly pattern timeline
- sleep and energy tracker
- trigger and relief journal
- routine experiment cards
- doctor visit prep drawer

## Stitch prompt
```
Design a desktop women’s health planning dashboard called Perimenopause Pattern Coach for adults navigating confusing shifts in sleep, mood, energy, and menstrual patterns. It should help users connect symptoms, recovery habits, and cycle changes into a calmer weekly health plan that supports self-observation and better doctor conversations. Include a symptom and cycle summary, a weekly pattern timeline, a sleep and energy tracker, a trigger and relief journal, routine experiment cards, and a doctor visit prep drawer. Design direction: use a calm-consumer aesthetic with warm neutrals, soft blue-green accents, friendly card groupings, and low-stress guided clarity so the product feels reassuring, emotionally steady, and health-serious without becoming clinical.
```
