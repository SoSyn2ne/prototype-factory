# QA checklist

## Happy path
- User sees the trigger: The brochure says AI genius; your calendar says $2,400 and no refund after Friday.
- User enters or reviews the evidence/input implied by: hype-vs-proof sorter.
- User reaches the output artifact: Camp decision receipt with refund deadline and questions to ask.

## Edge cases
- Missing evidence or incomplete source data still produces a clear next-step checklist.
- User understands what is known, assumed, and risky without legal/medical/financial overclaiming.
- Mobile layout keeps the main action and status visible.
