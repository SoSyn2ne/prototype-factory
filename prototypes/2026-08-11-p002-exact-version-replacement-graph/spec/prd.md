# PRD — Exact-Version Replacement Graph

## Problem / target
Silent material, sizing, and formulation changes make “same product” searches unreliable. Target: runners, fragrance collectors, sensory-sensitive buyers, and everyday consumers.

## Core UX
Scan label/photo → version fingerprint → drift timeline → owner-confirmed substitute graph → old-stock watch. Sections: scan, fingerprint, comparison, graph, confidence stories, watchlist.

## Design / theme / evidence
- Profile: `calm-consumer`; theme: 자산 방어.
- Sources: S5 https://news.ycombinator.com/item?id=49095601; S4 https://news.hada.io/topic?id=32332.
- QA: exact-version distinction obvious; confidence never looks authoritative without owner evidence; watch action works; mobile scan is clear.

## Stitch prompt
Design a responsive consumer web app named “Exact-Version Replacement Graph.” The first screen lets a user upload a label photo or enter a product name, size, purchase year, and material. Show an exact-version fingerprint, a horizontal timeline exposing silent formulation/material changes, three owner-confirmed replacement cards with confidence and quoted fit notes, a small node graph connecting old stock to substitutes, and a restock/watch toggle. Include shoes, perfume, and socks as realistic sample modes. Design direction: use the calm-consumer profile with warm off-white surfaces, one sage accent, generous spacing, reassuring copy, soft but consistent radii, and no noisy marketplace banners.
