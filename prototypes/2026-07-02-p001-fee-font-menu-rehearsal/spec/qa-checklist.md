# QA checklist

## Happy path
- User sees the trigger: A new fee law says your service charge must be as visible as the burger, not buried at checkout.
- User enters or reviews the evidence/input implied by: fee-disclosure surface audit.
- User reaches the output artifact: Menu/QR/receipt patch packet plus staff fee script.

## Edge cases
- Missing evidence or incomplete source data still produces a clear next-step checklist.
- User understands what is known, assumed, and risky without legal/medical/financial overclaiming.
- Mobile layout keeps the main action and status visible.
