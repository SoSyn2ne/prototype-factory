# Falsification checklist (5-7)

1. A target user says the workflow is merely nice-to-have and would not change an urgent decision.
2. The first screen feels like a generic dashboard instead of the specific No-Show Deposit Notice Kit workflow.
3. The sample data does not make the cited source signals visible.
4. The user cannot explain the next action after 10 seconds.
5. The required UI sections are present but do not connect into one decision flow.
6. The design profile (operator-dense) is not recognizable in layout, density, color, and controls.
7. The output packet or decision card is not something a user would share or act on.
