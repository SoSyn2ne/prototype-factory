# Midnight Neighbor Signal Club

A playful social prototype where solo city dwellers post tiny late-night signals, discover nearby compatible moods, and unlock low-pressure micro-hangouts instead of doomscrolling alone.

## Status
- prototype

## Theme and design
- Theme: 외로움
- Design profile: playful-experimental

## Core UX
- Send a tiny midnight signal, watch nearby mood matches appear, and unlock a low-pressure shared plan only after both sides opt into the same vibe.
