# Falsification checklist - AI Slop Reputation Carnival

1. Target users say the problem is annoying but not urgent enough to pay for.
2. Existing platform-native tools already solve the workflow well enough.
3. Users cannot gather the required evidence or inputs without too much manual work.
4. The UI reads as another generic dashboard instead of the assigned design profile: playful-experimental.
5. The concept overlaps too closely with a recent PF batch after user review.
6. The Stitch output fails to expose the key UX in the first screen.
7. The idea depends on claims that the external signals do not actually support.
