# Falsification checklist (5–7)

1. The user cannot understand the concrete job-to-be-done from the hero screen.
2. The design does not clearly express the assigned profile: calm-consumer.
3. The core workflow is only a renamed dashboard/planner with no new trigger, data source, or interaction mechanic.
4. The prototype fails to cite the external/community signals in meta/spec.
5. The Stitch prompt omits required UI sections or design direction.
6. The expected drop folder is not clear for Phase B/C.
7. The idea cannot plausibly support either WTP or shareability from the cited signals.
