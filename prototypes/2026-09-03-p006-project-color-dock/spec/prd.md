# PRD — Project Color Dock

## Problem
Re-enter any project through a colored spatial drawer containing its exact windows, commands, notes, and unfinished thought.

## Target user
Developers and creators switching among many small projects.

## Arrival path
Search, community referral, or the trigger moment described in today's idea board.

## Business / validation route
Test whether the target user completes the core loop and shares or returns to the output artifact.

## Core loop / key UX
Open a colored drawer → preview window stack and unfinished thought → launch bundle → park with exit note.

## First screen
Make the trigger, primary action, and next outcome understandable in three seconds.

## Required UI sections
drawer wall; color/texture maker; spatial preview; unfinished thought; launch bundle; park ritual; replay.

## Design
- Assigned profile: `playful-experimental`
- Theme: context switching as a tactile toy

## Source signals
S8, S10 from `daily/2026-09-03/ideas.md`.

## Interaction rules
The main interaction must be functional in the later demo; include loading, empty, error, and completed states.

## Output artifact
A shareable or printable result specific to the idea, not a generic analytics summary.

## Share / return loop
Use the candidate-specific spread trigger in today's idea board.

## Constraints
- Phase A is spec-only; no custom demo.
- No external paid API required for prototype validation.

## Non-goals
- Production integrations, legal guarantees, or hidden automation.

## Success metrics
- User understands the first action in three seconds.
- User can finish one realistic core loop with sample data.

## QA / screenshot criteria
Drawer identity is legible without text and empty, broken-command, missing-window, and restored states exist.
