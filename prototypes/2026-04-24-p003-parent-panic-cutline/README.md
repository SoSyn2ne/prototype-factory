# Parent Panic Cutline

A private education triage board that helps parents decide which classes to keep, pause, or replace when monthly hagwon costs are rising faster than confidence scores.

## Context
- Theme: 사교육
- Design profile: operator-dense
- Target user: Parents managing multiple hagwon, tutor, worksheet, and test-prep bills who feel guilty cutting anything even when the family budget is tightening.

## Key UX
- Compress spend, fatigue, and subject confidence into one operator board so a parent can make one defensible study plan instead of stacking more classes.

## Required UI sections
- monthly tuition burn meter
- subject confidence grid
- child fatigue heatmap
- keep-pause-replace command board
- weekly schedule rebuilder
- caregiver alignment memo drawer

## Stitch prompt
Design a desktop parent decision desk called Parent Panic Cutline for families trying to control rising hagwon and tutor costs without feeling like they are sacrificing a child's future. It should help users compare monthly spend, subject confidence, and child fatigue so they can decide which classes to keep, pause, or replace in one defensible plan. Include a monthly tuition burn meter, a subject confidence grid, a child fatigue heatmap, a keep-pause-replace command board, a weekly schedule rebuilder, and a caregiver alignment memo drawer. Design direction: use an operator-dense aesthetic with compact planning surfaces, disciplined hierarchy, dark slate neutrals, and one sharp action accent so the product feels practical, high-signal, and made for hard family tradeoffs.
