- User can input multiple classes and immediately see total spend and fatigue pressure.
- Keep, pause, and replace actions update the weekly schedule clearly.
- Decision notes explain the tradeoff without placeholder text.

## Edge cases
- Sparse data still preserves a useful board state and readable hierarchy.
- High-cost months still keep one clear next action visible.
