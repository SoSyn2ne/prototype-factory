# Falsification checklist — Parent Panic Cutline

1. If parents almost never cut classes once enrolled, the board may not change behavior.
2. If fatigue and confidence are too subjective to compare, the core matrix will feel arbitrary.
3. If households mainly want tutor discovery rather than triage, the product is mispositioned.
4. If the weekly rebuild takes too long, usage will collapse into emergency-only sessions.
5. If caregiver disagreements dominate the workflow, single-screen planning may be insufficient.
6. If perceived academic payoff is impossible to summarize simply, trust will erode.
