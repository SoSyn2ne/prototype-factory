# Falsification checklist (5–7)

1. The target user cannot recognize their own workflow pain from the first screen.
2. The UI reads like a generic dashboard instead of a field-ops experience.
3. The external signals do not map to the core interaction.
4. The user cannot complete the primary decision/action path in under 3 minutes.
5. The prototype lacks enough concrete sample data to feel real.
6. The theme `자산 방어` is not visible in title, stakes, or copy.
7. The Stitch export cannot be mapped cleanly to `p003`.
