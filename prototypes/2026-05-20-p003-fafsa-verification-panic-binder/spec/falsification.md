# Falsification checklist (5-7)

1. Users cannot identify the next action within 10 seconds.
2. The evidence/document intake feels like a generic dashboard instead of a specific rescue workflow.
3. The output artifact is not credible enough to copy, share, submit, or act on.
4. The assigned design profile (calm-consumer) is not visible in the interface direction.
5. The theme (사교육) does not show up in the stakes or copy.
6. The prototype duplicates a recent PF batch without a new user, trigger, data source, or interaction mechanic.
7. The Stitch prompt omits one of the required UI sections.
