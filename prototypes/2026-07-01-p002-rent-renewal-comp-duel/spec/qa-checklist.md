# QA checklist

## Happy path
- First screen communicates: A 7% renewal hike is not final until you show the cheaper empty unit next door.
- User can identify the target user and trigger within 3 seconds.
- User can complete the primary mechanic: comp-card duel.
- Prototype produces: Negotiation email plus evidence cards and annual savings estimate..

## Edge cases
- Empty input state explains what proof/data is needed.
- User with partial evidence can still get a next step.
- Mobile layout keeps key actions reachable.
- Copy avoids claiming legal, medical, insurance, or financial guarantees.

## Acceptance verification
- Design profile appears exactly once as financial-analyst.
- Required sections are present: Renewal increase intake, Comparable rent evidence board, Landlord vacancy-cost counter, Tone-controlled email draft, Savings scoreboard.
- Stitch prompt cites signals S4, S5, S6 as problem evidence only.
- No custom demo is implemented during Phase A.
