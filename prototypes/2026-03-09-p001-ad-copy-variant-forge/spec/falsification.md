# Falsification checklist (7)

1. If users still rewrite >80% of variants, the forge is not saving time — what templates are missing?
2. Do “forbidden words” and max length constraints actually reduce iteration time, or do they add friction?
3. Does heuristic scoring mislead users (picking clickbait-y lines that hurt conversion)?
4. Are the produced variants too similar (low diversity) to meaningfully A/B test?
5. Is the UI slower than the spreadsheet workflow for real campaigns (time-to-export)?
6. Do users want *brand memory* (saved inputs, voice rules) immediately, making stateless usage non-viable?
7. Is the concept invalid because marketers already have a better tool (e.g., within ad platforms / existing suites) that makes this redundant?
