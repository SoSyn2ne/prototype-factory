# Falsification checklist — p006 Off-App Date Idea Dice

1. 5명의 20~30대 사용자가 "이미 Random date idea generator로 충분하다"고 답하면 kill.
2. 12개 sample mission 중 3개 이상이 현실적으로 불가능하면 (장소/시간/비용) kill.
3. 5-주사위 굴림 결과가 5-슬라이더 입력에 80% 이상 반응하지 않으면 kill.
4. 미션 카드 1장 (분위기/준비물/비용/실패 대안/사진 가이드) 중 1개라도 빈 항목이면 kill.
5. 1주 1개 미션 완료율 < 30% (인스타 스토리 재공유 기반) 이면 kill.
6. 모바일 1-hand 인터랙션이 30초 안에 미션 카드 생성 못 하면 kill.
7. 안전 가이드 명시로 첫 만남 사고 감소 효과 없으면 kill.
