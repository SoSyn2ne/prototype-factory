# QA checklist

## Happy path
- User lands directly on the main Five-Minute Drill workflow.
- User enters or reviews the minimum evidence.
- Prototype shows risk/priority/status clearly.
- Prototype produces registration drill card and backup ladder.

## Edge cases
- Empty evidence state is useful and specific.
- Extreme cost/risk/load values do not break layout.
- Mobile view keeps controls readable and non-overlapping.
