# PRD — ThreeUI Remix Roulette

## Problem
- Spin three live 3D UI primitives and one constraint, then build a 60-second interactive scene people can remix from a link.

## Target user
- Frontend designers, creative coders, livestreamers, and portfolio builders.

## Core loop
- Spin component/behavior/palette/constraint reels, tune a live scene for 60 seconds, publish, and extend a remix chain.

## First screen
- Make the trigger and primary action understandable in three seconds.

## Required UI sections
- Roulette reels; 3D stage; property knobs; timer; constraint; replay timeline; publish/remix.

## Design profile
- playful-experimental

## Theme
- 외모

## Source signal references
- S10, S12; full URLs and evidence notes are in daily/2026-08-25/ideas.md.

## Constraints
- Phase A spec only; no external APIs; use realistic local mock data.

## Success metrics
- Five target users can complete the core loop without explanation; three say the output is useful enough to save or share.

## QA / screenshot criteria
- The random rule is readable in 3 seconds; the stage responds visibly; published cards preserve parent/child remix lineage.
