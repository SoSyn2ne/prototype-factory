# PRD — Glow-Up ROI Cutline

## Problem
- A deadline beauty decision board that ranks skin, hair, body, and styling moves by visible payoff so users stop wasting cash before a date, interview, or photo day.

## Target user
- Young professionals and students preparing for a high-visibility moment who want to look sharper fast without buying every clinic package or trending product.

## Theme
- 외모

## Design profile
- premium-editorial

## Key UX
- Turn appearance anxiety into a ranked cutline: keep only the treatments and habits that fit the deadline, budget, and visible transformation goal.

## Required UI sections
- event pressure snapshot
- visible payoff ranking board
- budget cutline slider
- skin-hair-style treatment matrix
- seven-day rescue plan
- confidence before-after notes drawer

## Stitch prompt
Design a desktop beauty ROI planner called Glow-Up ROI Cutline for people preparing for a date, interview, reunion, or photo-heavy event who want the fastest visible appearance upgrade without wasting money. It should rank skin, hair, body, and styling moves by deadline, cost, and visible payoff, then cut low-impact actions from the plan. Include an event pressure snapshot, a visible payoff ranking board, a budget cutline slider, a skin-hair-style treatment matrix, a seven-day rescue plan, and a confidence before-after notes drawer. Design direction: use a premium-editorial aesthetic with warm ivory tones, polished magazine typography, elegant cards, soft beauty-service accents, and one refined action path so the product feels aspirational, expensive, and calm under pressure.
