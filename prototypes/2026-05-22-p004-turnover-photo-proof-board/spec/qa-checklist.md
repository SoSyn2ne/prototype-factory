# QA checklist

## Happy path
- Host opens Turnover Photo Proof Board.
- Host selects property and next check-in time.
- Cleaner completes timed room tasks and uploads required photos.
- Host receives guest-ready handoff and exportable issue packet.

## Edge cases
- Late checkout compresses the timeline.
- Cleaner finds damage before cleaning.
- Restock item is missing.
- No network during part of the turnover.

## Acceptance verification
- Includes design profile `field-ops`, theme `자산 방어`, and signal references.
- Stitch prompt includes timeline, task board, photo proof, issue log, handoff summary, and explicit field-ops design direction.
