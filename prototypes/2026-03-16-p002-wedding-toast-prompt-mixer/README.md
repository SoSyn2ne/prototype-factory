# Wedding Toast Prompt Mixer

Build a 60–90 second wedding toast by mixing prompts, stories, and tone—then rehearse with a timed teleprompter.

## Status
- prototype

## How to run (demo)
- Open `demo/index.html` in a browser.
- Fill names + pick tone, then click **Generate**.

## Manual checklist
- Generate produces a structured outline and estimated duration.
- Shuffle changes suggested prompts.
- Timer start/pause/reset works.
- Teleprompter mode is readable and toggles.
