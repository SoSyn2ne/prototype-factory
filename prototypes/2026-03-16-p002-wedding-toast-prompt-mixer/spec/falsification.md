# Falsification checklist (5–7)

1. Do users still feel stuck after selecting prompts (templates don’t unlock words)?
2. Does the generated outline feel too generic (“could be any couple”)?
3. Do users ignore the timer and still overshoot target length?
4. Does the teleprompter mode feel unusable on common phone sizes?
5. Are the tone options confusing (what’s the difference between “warm” and “funny”)?
6. Do users need multi-language support immediately (e.g., Korean/English mix)?
7. Does the mixer accidentally encourage risky content (roasts, exes, inside jokes)?
