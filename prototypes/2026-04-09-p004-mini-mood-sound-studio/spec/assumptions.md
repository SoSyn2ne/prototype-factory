# Assumptions (KNOWN / ASSUMPTION / UNKNOWN)

## KNOWN
- Vacancy days are one of the clearest operational pain points for small property teams.
- Turnover work spans multiple vendors and internal roles, so status fragmentation is a real problem.
- A strong desktop board can create value even before mobile field tooling exists.

## ASSUMPTION
- Users will prefer a pipeline plus timeline combination over a simple task list because sequence matters.
- Rework visibility will matter as much as initial task assignment for reducing vacancy days.
- Property managers will adopt a dedicated audio view if it maps directly to rent-loss prevention.

## UNKNOWN
- How much photo evidence needs to be first-class in the interface for users to trust readiness status.
- Whether vendor assignment should optimize for speed, cost, or relationship quality by default.
- Which audio step most often drives unpredictable delays across different property types.
