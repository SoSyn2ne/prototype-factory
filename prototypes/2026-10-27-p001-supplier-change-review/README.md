# 공급사 상품 변경 검수

## 현재 범위
공급사 상품 파일과 최신 Shopify 상품 내보내기를 연결해, 가격·재고 변경과 연결되지 않은 식별자를 사람이 확인하는 작은 프로그램의 기획이다. 현재 제공하는 것은 설계 문서와 **설계 예시 · 실제 파일 처리 미구현**인 읽기 전용 HTML이다. CSV 해석·상품 연결·검수·저장·Shopify 연동은 구현되지 않았다.

## 확인한 문제와 제안의 경계
[RayanCooper_47의 공급사 CSV 경험](https://www.reddit.com/r/dropshipping/comments/1sijsa8/how_are_you_guys_handling_supplier_csvs_for/)은 병합 열·이미지·옵션을 고친 전날 작업을 약 4시간이라고 보고한다. [One-Sun1995의 작업 설명](https://community.shopify.com/t/how-do-you-handle-supplier-spreadsheets-when-updating-your-store/676989/10)은 SKU와 Handle 연결, 변경 필드 제한, 별도 재고 파일 검사를 설명하며 마지막 조회 작업을 약 1시간이라고 보고한다. 두 사람의 일회성 시간 보고를 평균·절감 효과로 사용하지 않는다. 확인일은 2026-10-27이며 Reddit 게시일은 검색 색인상 2026-04-11, 절대 날짜 본문 확인은 못했다. 포럼 댓글은 2026-09-07이다.

## 다음 실증과 미확인 사항
사전 동의한 운영자 한 곳의 익명화된 파일 한 쌍을 수작업으로 먼저 대조한다. 연결 불가·중복·빈 값·가격/재고 변경을 기존 방식과 비교하고 담당자가 모든 예외를 판정한다. 구매자·자료 접근·가격·갱신 빈도·지불의사와 기존 도구 대비 이점은 미확인이다. 사이트 등록 뒤 상세 분석·실행 프롬프트를 사용하며, 상품 변경·자동 업로드는 범위에 없다.
