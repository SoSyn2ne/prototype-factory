# PRD — 공급사 상품 변경 검수

## Problem / Target user
공급사 상품 파일의 SKU·열·옵션을 기존 Shopify 상품과 맞추는 운영자 또는 상품 담당자가 대상이다. 두 작성자는 직접 수정 또는 조회 작업을 설명했지만 주기·구매 의사는 밝히지 않았다. 공급사 업데이트 때마다 같은 문제가 반복되는 고객인지 먼저 확인한다. 근거는 meta.json의 CSV-01·CSV-02이며 개발자의 홍보 댓글은 사용하지 않는다.

## Proposed scope
공급사 업데이트 파일 한 개와 같은 시점의 최신 스토어 상품/재고 내보내기 한 개를 운영자가 선택해 수작업 기준을 만든다. 식별자·데이터 정의·가격과 재고 파일의 차이를 먼저 확인하고, 연결 불가·중복·빈 값과 제안 변경을 별도로 표시하는 로컬 보조 도구가 제안이다. 이미지·HTML·옵션 해석, 자동 상품 생성·가격/재고 변경·업로드·외부 계정 접근은 제외한다. 임의 연결이나 빈 값의 0 처리도 금지한다.

## Success / Unknowns
유료 실증 통과는 합의한 범위·가격의 첫 실제 수금, 같은 파일 한 쌍의 검토 시간 개선, 누락·잘못된 연결 비증가와 모든 행·예외의 담당자 확인을 요구한다. 수금 없이 효용만 확인되면 업무 타당성 관찰로만 기록한다. 만족·다음 파일 재사용·재결제와 지원 원가는 별도로 확인하며 절감률이나 반복 매출을 지어내지 않는다. 현재 HTML은 정적 설계 예시이고 실행 가능한 처리 프로그램·빌드·실사용 검증은 없다.
