# PRD — 공급사 상품 변경 검수

## Problem / Target user

공급사 상품 파일의 SKU·열·옵션을 기존 스토어 상품과 맞추는 운영자 또는 상품 담당자가 대상이다. 두 작성자는 직접 수정 또는 조회 작업을 설명했지만 주기·구매 의사는 밝히지 않았다. 근거는 meta.json의 CSV-01·CSV-02이며 개발자의 홍보 댓글은 사용하지 않는다. 공급사 업데이트 때 같은 문제가 반복되는 고객인지 별도로 확인한다.

## MVP scope

`/tools/supplier-review`에서 기준 파일과 새 공급사 파일을 각각 선택한다. XLSX·CSV를 브라우저에서 읽고, 비교할 시트·SKU 열·비교 열을 지정한다. 첫 비어 있지 않은 행을 헤더로 사용하며 임의 헤더 행 선택은 지원하지 않는다. Univer 오픈소스의 읽기 전용 비교 화면과 SheetJS 파일 입출력을 사용한다. 파일별 5MiB, 유효 시트별 상품 데이터 10,000행·100열, 통합 문서 전체 100만 셀, XLSX 압축 해제 내용 50MiB를 처리 상한으로 둔다. 상품 표가 아닌 보조 시트는 이름과 사유를 경고하고 제외하며 유효한 상품 시트는 계속 사용할 수 있다.

SKU 바깥 공백을 제거한 뒤 정확히 같은 값만 연결하고 선행 0을 보존한다. 비교 값도 바깥 공백을 제거하고 엑셀 숫자는 실제 저장값으로 비교한다. 빈 값과 0을 구분하며 중복·빈 식별자가 있으면 원본 행을 알리고 비교를 중단한다. 한쪽에만 있는 행은 추가·제외 후보로 드러내고, 삭제나 상품 생성으로 자동 확정하지 않는다. 비교 값과 원본 행을 확인한 담당자가 변경을 승인한다. 승인 상태는 처음에 모두 해제하며 입력 파일이나 비교 설정이 바뀌면 폐기한다.

승인한 변경만 이전/현재 값·식별자·변경 종류·원본 행을 포함한 XLSX 검수 목록으로 내려받는다. 검수 목록은 Shopify 업로드 파일이나 원본 통합 문서 전체가 아니다. 원본 파일은 수정하지 않으며 값 이외의 서식·이미지·매크로 보존은 범위에 없다. 서버 파일 전송, 상용 Pro 서비스, 계정 연결, 스토어 쓰기와 자동 업로드는 포함하지 않는다.

다운로드는 헤더를 제외한 변경 필드 100,000행까지 지원한다. 승인한 필드 행 수를 파일 생성 전에 검사하고 초과하면 잘린 결과를 만들지 않고 중단한다. 승인 상태는 유지하며 승인 상품 수를 줄여 다시 내려받거나 비교 항목을 줄여 재검토할 수 있다.

## Success / Unknowns

기능 통과 조건은 샘플의 모든 변경·미변경·예외가 수작업 판정과 일치하고, 승인하지 않은 항목이 결과에 들어가지 않으며, 다운로드 파일을 다시 열어 값과 원본 추적 정보를 확인할 수 있는 것이다. 2026-11-12 로컬 브라우저에서 샘플 업로드·비교·선별 승인·다운로드, 중복 코드 오류와 재선택·변경 없음 상태를 확인했다. 전체 테스트 49개, 타입 검사와 프로덕션 빌드가 통과했으며 `qa-checklist.md`에 확인 범위와 남은 항목을 기록한다. 고객 실사용·고객의 Excel 앱 호환성 통과를 주장하지 않는다.

유료 실증 통과는 합의한 범위·가격의 첫 실제 수금, 같은 파일 한 쌍의 검토 시간 개선, 누락·잘못된 연결 비증가와 모든 예외의 담당자 확인을 요구한다. 수금 없이 효용만 확인되면 업무 타당성 관찰로만 기록한다. 구매자·파일 접근·가격·효과·재사용·재결제와 지원 원가는 미확인이다.
