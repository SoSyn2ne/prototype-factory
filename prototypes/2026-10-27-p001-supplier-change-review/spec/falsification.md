# Falsification — 공급사 상품 변경 검수

## 접근 단계
승인한 운영자나 익명화한 파일 한 쌍을 확보하지 못하거나, 해당 작업이 반복되지 않거나, 이미 쓰는 도구의 설정으로 충분하면 개발·유료 제안을 멈춘다. 커뮤니티 작성자를 확보된 고객으로 간주하지 않는다.

## 결과 단계
모호한 SKU를 추정 연결하거나 빈 값을 0으로 바꾸거나, 원본·변경 값·판정 근거를 행별로 추적하지 못하면 실패다. 기존 수작업과 대조한 누락·중복·잘못된 변경이 늘거나 사람이 검토하는 시간이 오히려 늘면 범위를 줄인다.

## 납품 단계
새 파일마다 새 규칙을 다시 만들어야 하거나 지원·수정 원가가 합의한 납품 범위를 넘으면 재설계한다. 만족 의견·재사용·실제 결제·재결제를 서로 바꿔 기록하지 않는다. 가격은 미정이며 첫 결제가 반복 사업을 입증하지 않는다.
