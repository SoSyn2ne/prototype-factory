# Falsification checklist (5–7)

1. If 5 out of 5 target users cannot explain the difference between `Starter`, `Pro`, and `Team` in under 20 seconds, does the tier structure fail clarity?
2. If users prefer to ignore the generated prices and rewrite all of them manually, is the generator output not valuable enough?
3. If annual vs monthly toggle changes do not alter users' stated purchase intent in interviews, is billing cadence a low-leverage variable here?
4. If copied UTM links are not actually used by testers in distribution, does this feature solve a non-problem?
5. If users dispute the proposed value metric as "not how we buy this," does the current input model miss core pricing drivers?
6. If the tracking plan panel is never referenced during review sessions, should tracking guidance be removed or redesigned?
