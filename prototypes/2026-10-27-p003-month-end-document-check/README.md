# 월마감 누락 서류 점검

**설계 예시 · 실제 파일 처리 미구현**

월별 기장 고객의 필수 서류 목록과 담당자가 승인한 수신 파일 목록을 비교해
수신 확인·누락·검토 필요를 나누고, 고객에게 요청할 문구의 초안을 만드는 제안이다.
현재는 Phase A 설계 문서와 읽기 전용 HTML 예시만 제공한다. 업로드·목록 대조·다운로드·발송 기능은 없다.

## 왜 이 작업인가

- [월별 자료·업무 수집 질문](https://www.reddit.com/r/Bookkeeping/comments/1vi9jzd/solutions_for_monthly_client_document_and_task/):
  약 두 다스의 월별 고객을 관리하는 담당자가 늦거나 묻히는 이메일과 여러 도구를 설명한다.
- [포털별 명세서 수집 질문](https://www.reddit.com/r/Bookkeeping/comments/1o150op/so_many_portal_logins_so_many_statements/):
  별도 운영자가 약 100개 QuickBooks Desktop 파일과 월 100건 안팎의 다운로드를 설명한다.

두 글은 2026-10-27 확인했다. 정확한 게시일은 미확인이다. 반복적인 자료 수집은 확인했지만
이 점검 프로그램의 구매 의사와 한국 사무소 적용은 확인하지 않았다. 두 번째 글의 포털 수집은
별도 문제이며, 이 제안이 로그인·다운로드 업무까지 해결한다고 주장하지 않는다.

## 첫 범위

한 사무소·이미 닫힌 한 달의 익명 자료만 쓴다.

1. 담당자가 고객 별칭·월·필수 서류 종류를 확정한다.
2. 승인된 수신 파일 목록의 고객·월·서류 종류와 대조한다.
3. 명시적으로 확인된 일치만 **수신 확인**으로 표시한다. 자료 내용의 정확성이나 마감 완료를 뜻하지 않는다.
4. 후보가 없으면 **누락**, 이름·월·계정이 모호하거나 중복이면 **검토 필요**로 분리한다.
5. 담당자가 상태표와 요청 **초안**을 검토하고 기존 연락 채널에서 직접 처리한다.

고객 업로드 서비스, 자동 메일, 은행·포털 로그인, 자격증명 수집, 파일 다운로드 대행,
재무·세무 판단은 포함하지 않는다. 가격·고객 접근·시간 절감·결제·반복 사용·재결제는 모두 미확인이다.

## 위험·미확인

파일명이 곧 고객·월·서류 종류를 보장하지 않는다. 잘못된 수신 확인을 막으려면 담당자 승인과
대조 근거가 필요하다. 실제 병목이 포털 자료 확보라면 목록 점검의 가치가 작을 수 있다.
기존 Excel이나 파일 공유 도구로 충분한지, 예외 처리·검토 원가가 요금 안에 들어가는지 먼저 확인한다.
