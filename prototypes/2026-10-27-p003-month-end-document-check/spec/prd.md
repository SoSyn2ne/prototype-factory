# PRD — 월마감 누락 서류 점검

## Problem

월별 기장 자료가 이메일·공유 폴더·고객 포털에 나뉘어 도착하면 담당자는 고객·대상 월·서류별로
수신 여부를 다시 확인하고 빠진 것을 요청한다. 파일 확보와 수신 목록 대조는 다른 작업이다.
이 설계는 이미 확보한 승인 목록의 점검만 다룬다.

## Target user / Buyer

- 사용자: 월별 자료 수신·분류·누락 요청을 하는 소규모 기장 사무소 담당자.
- 결제자 가설: 사무소 대표 또는 업무 책임자. 실제 구매자·예산·접근권은 미확인.
- 한국 적용은 해외 운영자 관찰을 좁힌 가설이며 국내 수요를 입증한 것이 아니다.

## Existing workaround / Arrival path

이메일 재검색·수동 요청·고객별 Excel과 기존 파일 공유/업무 도구 조합이 대안이다.
공개 기장 커뮤니티 또는 사무소 간 소개로 인터뷰 접근을 확인할 수 있다는 가설만 있다.
확정 고객·연락 동의는 없으며 자동 연락하지 않는다.

## Scope and data contract

첫 범위는 **한 사무소·이미 닫힌 한 달**이다. 입력 형식과 고객/파일 수 한도는 샘플 확인 뒤 합의한다.

| 자료 | 최소 항목 | 승인 책임 |
| --- | --- | --- |
| 필수 서류 목록 | 고객 별칭, 대상 월(YYYY-MM), 서류 종류, 필요 시 계좌 별칭, 필수 여부 | 기장 담당자 |
| 수신 파일 목록 | 파일 식별자·이름, 확인된 고객·월·서류 종류·계좌 별칭, 승인/보류 사유 | 기장 담당자 |
| 결과표 | 요구 항목, 상태, 대조한 파일, 근거 또는 검토 이유 | 담당자 최종 검토 |

파일명만으로 고객·월을 추정해 수신 확인하지 않는다. 원본 문서의 금액·내용을 판독하거나
회계상 적정성을 판단하지 않는다. 담당자가 승인한 목록이 잘못되었을 가능성도 검토 범위에 남긴다.

## States / Core loop

기준 목록 확인 → 승인된 수신 목록 대조 → 수신 확인·누락·검토 필요 분리 → 근거 검토 → 요청 초안 검토.

- **수신 확인:** 같은 고객·대상 월·서류 종류의 명시적 일치를 담당자가 확인한 상태. 마감 완료가 아니다.
- **누락:** 필수 항목과 일치하는 승인 파일이 목록에 없는 상태. 원본이 실제로 존재하지 않는다는 단정은 아니다.
- **검토 필요:** 매핑 미확인, 다른 월, 중복·충돌, 계정 불일치 등으로 판단을 멈춘 상태.
- 전체 필요 서류가 확정되지 않았으면 대조를 시작하지 않는다. 미확인 상태를 완료로 치환하지 않는다.

## Output artifact / First screen

첫 화면은 고객·닫힌 월·네 가지 필수 항목의 근거 있는 상태표와 요청 초안을 보여 준다.
요청 초안은 누락 요청과 확인 질문을 분리하며, 담당자가 기존 채널에서 직접 처리한다.
현재 HTML에는 합성 자료와 고정된 결과만 있으며 **설계 예시 · 실제 파일 처리 미구현**으로 표시한다.

## Non-goals

- 고객용 업로드 서비스, 자동 이메일·문자, 결제·청구 연동
- 은행·포털 로그인과 자격증명 수집, 원본 다운로드·삭제·수정
- 금액 검증, 장부 확정, 세무·재무 판단, 자료 완전성 보장
- 기존 문서·기장 시스템 전체 대체, 여러 사무소를 위한 호스팅

## First validation test

한 사무소의 닫힌 한 달에서 익명 필수 목록과 승인 수신 목록을 수동 기준표로 먼저 만든다.
동일 사례를 검토하면서 누락 추적·파일 분류·요청 초안 작성 시간과 수정량을 재고, 포털 수집 시간은 분리한다.
사람의 상태 판정과 요청 초안 검토가 필수다. 가격·지원 한도를 합의한 유료 파일럿의 첫 결제,
만족·반복 사용·재결제는 각기 다른 검증 사건이며 현재는 모두 미확인이다.

## Success / Stop criteria

- 필요한데 없는 자료를 수신 확인으로 표시하는 오류는 **0건**이어야 한다.
- 같은 사례의 추적·분류·초안 작성 시간이 수동 기준보다 줄고 검토 누락이 늘지 않아야 한다.
- 모든 대조 결과와 초안을 담당자가 확인한다. 유료 수요는 명시적으로 합의한 첫 결제로 별도 확인한다.
- 기존 시트로 충분하거나 포털 자료 확보가 병목이라 대조 시간 개선이 없으면 중단한다.
- 기준 목록·승인 데이터·검토자 확보가 안 되거나 예외/지원 원가가 요금을 넘으면 축소·중단한다.

## Risks / Unknowns

서류 명칭과 계좌 별칭이 사무소마다 다르고 월 경계·수정본·중복이 많을 수 있다.
외부 경험을 한국 사무소에 적용할 수 있는지, 목록 준비가 대조 절감보다 오래 걸리는지 미확인이다.
가명화·접근 권한·저장/삭제 책임과 실제 실행 환경도 계약 전에 확인한다.
