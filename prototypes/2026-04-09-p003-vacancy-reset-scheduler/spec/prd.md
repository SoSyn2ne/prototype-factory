# PRD — Vacancy Reset Scheduler

## Problem
- Small property teams lose rent when turnovers stall across cleaning, repairs, inspections, and listing prep.
- Work is usually coordinated through texts, vendor calls, and spreadsheets, which makes blockers invisible until move-in dates slip.

## Target user
- Small property managers, coliving operators, and turnover coordinators handling vendor-heavy unit resets.

## Constraints
- Time: Users need a board that highlights today’s blockers and vendor conflicts in one glance.
- Budget: The concept must feel useful before any deep property-management-system integration.
- Platform: Desktop-first operations board with field-friendly status language.

## Non-goals
- Full leasing CRM or rent collection.
- Contractor payroll and invoicing.
- Detailed maintenance diagnostics beyond turnover coordination.

## Success metrics
- Teams can identify which units are blocking occupancy and why within 3 minutes.
- Vendor assignment conflicts and rework loops are visible before they create extra vacancy days.
- Move-in readiness status is clear enough for an owner or manager to trust during daily review.

## Notes
- Design profile: field-ops.
- Core UI sections: vacancy-days KPI hero, unit turnover pipeline, task-stage timeline, vendor assignment board, blockers and rework panel, move-in readiness rail.
