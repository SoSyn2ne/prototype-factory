# Glow-Up Budget Recovery Planner

A cosmetic-treatment planning workspace that helps appearance-conscious users compare procedures, downtime, financing pain, and event deadlines before they overspend for a glow-up.

## Status
- prototype

## Concept snapshot
- Theme: 외모
- Design profile: premium-editorial
- Target user: Adults preparing for weddings, reunions, job changes, or dating re-entry who want to improve appearance fast without getting trapped in overpriced aesthetic packages.
- Key UX: Compare treatment paths side by side, see which combo fits the deadline and budget, and walk into a clinic consult with a calm plan instead of insecurity-driven impulse spending.

## Required UI sections
- event countdown hero
- procedure comparison cards
- downtime versus visibility timeline
- budget and financing pressure panel
- clinic consult question list
- recommended glow-up plan drawer

## Stitch prompt
Design a desktop aesthetic-planning workspace called Glow-Up Budget Recovery Planner for adults preparing for a visible life moment and trying to improve appearance without getting trapped in overpriced cosmetic packages. It should help users compare treatments, understand downtime, see how much visible payoff each option offers, and decide what to do before an event deadline without panic spending. Include an event countdown hero, procedure comparison cards, a downtime versus visibility timeline, a budget and financing pressure panel, a clinic consult question list, and a recommended glow-up plan drawer. Design direction: use a premium-editorial aesthetic with warm ivory, espresso, and muted rose tones, elegant typography, polished before-versus-after framing, and composed luxury spacing so the product feels aspirational, trustworthy, and appearance-serious rather than flashy.
