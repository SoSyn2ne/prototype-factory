# Chemistry Signal Mirror

A playful attraction sandbox where two people trade tiny flirt signals, reveal reciprocity safely, and unlock bolder prompts only when mutual chemistry is obvious.

## Status
- prototype

## Concept snapshot
- Theme: 성욕
- Design profile: playful-experimental
- Target user: Curious singles or couples in social chat contexts who want a safer, lower-awkwardness way to test attraction before making a bolder move.
- Key UX: Let users send tiny chemistry signals, watch mirrored interest build, and only surface flirtier prompts when both sides are clearly leaning in.

## Required UI sections
- signal intensity stage
- mirrored reciprocity meter
- prompt unlock carousel
- boundary and comfort toggles
- shared chemistry timeline
- playful next-move drawer

## Stitch prompt
Design a bold desktop social concept called Chemistry Signal Mirror for people who want to test attraction without jumping straight into overt flirting. It should let two users trade tiny chemistry signals, measure mirrored interest, keep boundaries explicit, and unlock bolder prompts only when both sides are clearly reciprocating. Include a signal intensity stage, a mirrored reciprocity meter, a prompt unlock carousel, boundary and comfort toggles, a shared chemistry timeline, and a playful next-move drawer. Design direction: use a playful-experimental aesthetic with glossy dark gradients, saturated cherry and ultraviolet accents, soft glass panels, and one crystal-clear escalating interaction path so the product feels sexy, mischievous, and portfolio-worthy without becoming crude or confusing.
