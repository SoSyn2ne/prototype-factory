# Falsification checklist (5–7)

1. Does the concept feel too abstract to replace normal flirting?
2. Will users find the mirrored meter juvenile instead of seductive?
3. Does explicit boundary framing kill the playful fantasy instead of supporting it?
4. Would a mobile-first format obviously outperform the desktop concept?
5. Are prompts the wrong mechanic if users mainly want emotional ambiguity?
6. Does the product lose value the moment mutual attraction is already obvious?
