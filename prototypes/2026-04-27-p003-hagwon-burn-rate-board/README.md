# Hagwon Burn Rate Board

A private education control panel that helps parents decide which hagwon, tutor, and workbook spend to keep, pause, or replace before guilt destroys the monthly budget.

## Status
- Phase A scaffolded for Stitch export ingest.

## Candidate
- Type: Practical / Commercial
- Theme: 사교육
- Design profile: operator-dense
- Target user: Korean parents managing multiple classes and tutors who fear falling behind but need a defensible way to reduce spend and child fatigue.
- Key UX: Put tuition burn, subject confidence, child fatigue, and exam timing on one board so parents can make one hard cut without feeling reckless.
