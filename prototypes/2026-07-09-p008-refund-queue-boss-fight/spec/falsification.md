# Falsification checklist

1. The first screen reads like a generic dashboard instead of timed card battler + consumer escalation checklist.
2. A target user cannot identify the next action within 5 seconds.
3. The required UI sections are missing: Cancelled trip case card; Evidence cards: notice, receipt, chat, policy, insurance; Boss meter for generic replies and delay tactics; Escalation move selector; Victory receipt with next real-world steps.
4. The design direction does not match playful-experimental.
5. The prototype depends on source claims as market-size proof instead of treating them as problem evidence.
6. The workflow duplicates one of the last 7 PF batches without a new user, trigger, data source, or interaction mechanic.
7. The final screen lacks a shareable output, packet, receipt, or result tied to: The victory receipt and boss screen are easy to screenshot and share with travel groups.
