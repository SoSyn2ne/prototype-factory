# Chip Cycle KPI Snapshot

A one-screen scorecard that turns messy semiconductor signals into a daily **Go / Hold / Avoid** stance with explicit receipts.

## Status
- prototype

## How to run (demo)
- Open `demo/index.html` in a browser.
- (Optional) Use the Bull/Base/Bear presets, then tweak signals to match your view.

## Manual checklist
- Sliders update stance + confidence + receipts.
- Presets set inputs correctly.
- Export copies a one-paragraph summary to clipboard.
- Works offline (no external network requests).
