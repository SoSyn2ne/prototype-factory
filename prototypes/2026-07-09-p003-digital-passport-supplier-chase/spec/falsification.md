# Falsification checklist

1. The first screen reads like a generic dashboard instead of compliance checklist + field follow-up board.
2. A target user cannot identify the next action within 5 seconds.
3. The required UI sections are missing: Product passport readiness score; Supplier data gap matrix; QR field checklist: materials, repair, lifecycle, identifiers; Escalation email composer; Audit trail and deadline lane.
4. The design direction does not match field-ops.
5. The prototype depends on source claims as market-size proof instead of treating them as problem evidence.
6. The workflow duplicates one of the last 7 PF batches without a new user, trigger, data source, or interaction mechanic.
7. The final screen lacks a shareable output, packet, receipt, or result tied to: The gap map can be sent to suppliers as a clear ask list, making the tool naturally collaborative.
