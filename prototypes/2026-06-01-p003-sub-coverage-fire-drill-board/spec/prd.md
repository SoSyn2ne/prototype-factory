# PRD - Sub Coverage Fire Drill Board

## One-liner
A school coverage planner that converts morning teacher absences into shareable sub plans, room moves, and panic-free handoffs.

## Problem
- Schools coordinate absences, substitutes, room moves, and lesson materials across fragmented tools and last-minute communication.
- Signals S7 and S8 show real confusion around sub-day readiness and staffing/budget-driven coverage scrambles.

## Target user
- School principals, assistant principals, office managers, and department leads.

## Key UX
- Start with today's absences, available substitutes, room constraints, and lesson-plan links. Generate a coverage map, missing-material flags, shareable sub cards, broadcast queue, load meter, and next-day repair list.

## Required UI sections
- Morning absence intake.
- Coverage map.
- Panic flags.
- Shareable sub cards.
- Broadcast queue.
- Admin load meter.
- End-of-day incident notes.

## Stitch prompt
Create a responsive operations web app called "Sub Coverage Fire Drill Board" for school administrators managing teacher absences. Build a fast morning-command workflow that converts absences into a coverage map, sub cards, missing-plan flags, room swaps, broadcasts, load balancing, and end-of-day incident notes. Required sections: absence intake, coverage map, panic flags, shareable sub cards, broadcast queue, admin load meter, and next-day repair list. Design direction: use the `field-ops` profile with reliable slate/steel styling, vivid action accents for urgent gaps, dense but legible planning surfaces, and touch-friendly controls for office staff under time pressure.
