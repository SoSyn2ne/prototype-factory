# Falsification checklist (5-7)

1. Schools already have mandatory coverage systems that block adoption.
2. District privacy/security rules prevent useful data entry.
3. Manual setup takes longer than the morning scramble it replaces.
4. Substitute teachers will not open shareable cards consistently.
5. Admin load balancing is politically sensitive.
6. Broadcast features duplicate existing messaging apps.
7. Procurement is too slow for a lightweight commercial wedge.
