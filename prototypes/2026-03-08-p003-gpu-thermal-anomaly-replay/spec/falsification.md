# Falsification checklist (7)

1. If the chart is removed and only a table remains, do users still find the replay useful (implying the UI is overbuilt)?
2. Do users mistrust heuristic anomaly labels and ignore them without a clear explanation?
3. Are adjustable thresholds confusing (too many knobs) for the target operator?
4. Does a single combined chart hide important detail compared to separate charts?
5. With noisy sampling (missing points), does the replay become misleading?
6. Are anomalies more often fan-control issues (lag) than absolute temperature thresholds, requiring different heuristics?
7. Can this workflow be beaten by existing tools (Grafana, Afterburner logs) in time-to-insight?
