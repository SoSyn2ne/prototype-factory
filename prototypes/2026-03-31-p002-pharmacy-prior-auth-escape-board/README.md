# Pharmacy Prior-Auth Escape Board

A pharmacy ops board that rescues stuck prior-auth cases before patients churn, scripts lapse, or staff time gets buried in callbacks.

## Status
- prototype

## How to use
- Review the framing in `spec/prd.md`.
- Stitch export is ingested in `demo/` and preserved in `demo/original/code.html`.
- Open the PF-safe demo wrapper to inspect the screen locally.
