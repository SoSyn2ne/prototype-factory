# Falsification checklist (5-7)

1. The target user cannot understand the first screen without explanation.
2. The workflow produces a generic dashboard instead of teen micro-camp weekly swap sheet.
3. The cited source signals do not map to the chosen trigger moment.
4. The assigned calm-consumer profile is not visible in the layout, density, or tone.
5. The product cannot be tested with manually entered evidence.
6. The spread trigger is weak or creates no shareable artifact.
7. A recent PF batch already solved the same user, trigger, data source, and interaction.
