# PRD - Resale Flex Authenticity Mirror

## Problem
Gen Z resale buyers compare status, authenticity, price, and seller trust before a luxury bargain becomes embarrassment.

## Target user
Gen Z and millennial shoppers buying secondhand luxury, resale sellers, and stylists helping clients avoid fake or overhyped finds.

## Key UX
User drops a resale listing, seller profile, market comps, authentication clues, and outfit context; the app returns a flex score, trust risk, negotiation angle, and shareable decision card.

## Required UI sections
- Listing mirror header with price, brand, condition, and confidence
- Authentication clue checklist for tags, stitching, serials, and receipts
- Seller reputation and return-policy panel
- Market comp strip for resale vs new vs dupe prices
- Status-vs-savings flex meter
- Negotiation script and walk-away threshold
- Shareable buy/pass card for group chat

## Assigned design profile
premium-editorial

## Theme
외모 / 자산 방어 / 역전 - buying visible status without getting fooled.

## Source signal references
- S8 - ThredUp 2026 Resale Report, Gen Z is expected to drive a large share of resale growth and keeps using secondhand as a price/status channel: https://cf-assets-tup.thredup.com/resale_report/2026/ThredUp_Resale_Report_2026.pdf
- S9 - Vogue, resale is becoming core to luxury but trust, human validation, seller reputation, and authentication remain decisive: https://www.vogue.com/article/how-to-sell-vintage-and-secondhand

## Stitch prompt
Build a production-grade web app prototype called "Resale Flex Authenticity Mirror" for Gen Z resale shoppers deciding whether a secondhand luxury listing is worth buying. The first screen must be a working resale decision mirror with a listing header, authentication clue checklist, seller reputation panel, market comp strip, status-vs-savings flex meter, negotiation script, walk-away threshold, and shareable buy/pass card. Use realistic sample data: used Prada nylon bag, $640 listing, $1,950 retail, seller with 94% rating, missing dust bag, serial photo present, two comp listings, one dupe alternative, and a group chat vote. Design direction: use the premium-editorial profile with refined high-trust composition, elegant but scannable typography, restrained luxury tones, and one quiet CTA color for the final buy/pass decision. Do not make a marketing landing page; the first screen must be the working app.

## Constraints
- Phase A only: no custom demo implementation.
- Stitch output must preserve the assigned design profile.
- First screen must be the working app, not a marketing landing page.
