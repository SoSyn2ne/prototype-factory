# Wedding Dietary Snapshot

Capture guest dietary needs in one place and generate a kitchen-ready summary + export.

## Status
- prototype

## What’s inside
- `spec/prd.md` — one-page PRD
- `spec/assumptions.md` — KNOWN / ASSUMPTION / UNKNOWN map
- `spec/falsification.md` — 7 disproof questions
- `spec/qa-checklist.md` — manual checks
- `demo/` — vanilla HTML/CSS/JS (offline)

## Routes (gallery)
- Detail route: `/p/2026-03-10-p002`
- Demo route: `/d/2026-03-10-p002`

## How to run demo (static)
- Open `demo/index.html` directly, or:
- `cd prototypes/2026-03-10-p002-wedding-dietary-snapshot/demo`
- `python3 -m http.server 4173`
- Visit `http://localhost:4173`

## Why this exists
Dietary constraints are a “small detail” until the kitchen needs a clean, counted list. This tool aims to reduce last-minute Slack/DM chaos.
