# Falsification checklist (5–7)

1. Does the operator still fall back to spreadsheets because bulk entry is faster there?
2. Do the preset tags fail (too limited), causing heavy use of “Other” and making summaries useless?
3. In real usage, is duplicate entry common enough that it breaks trust in the counts?
4. Does JSON export not match what caterers want (they demand a printable sheet/CSV)?
5. Do planners refuse to track allergies here because they need stronger audit trails?
6. Does the summary view fail to answer the real question (e.g., “which guests are nut allergy?”)?
7. After one event, does anyone choose to use this again (repeatability signal)?
