# PRD — Cosmetics Safety File Deadline Map

## Problem
- K-beauty exporters turn the 2026 draft into a product-by-product evidence calendar before the comment window closes.

## Target user
- Korean indie cosmetics brands, OEM/ODM coordinators, and small exporters preparing for MFDS safety-assessment files.

## Arrival path
- Search/community referral at the moment this trigger becomes urgent: K-beauty compliance / export readiness.

## Business / validation route
- Validate with a focused landing/demo and measure completion plus artifact sharing; monetize through a lightweight subscription, template pack, or qualified partner lead.

## Core loop
- Import product SKUs, classify first-wave timing, map missing safety evidence, assign owners, and export a dated readiness pack.

## First screen
- Communicate the one-liner in three seconds and expose the first input beside a realistic result preview.

## Key screens
- SKU intake; threshold and phase classifier; evidence matrix; comment-window countdown; owner calendar; export pack.

## Interaction rules
- One decisive primary action per state; preserve entered data; show loading, empty, success, and blocked/error states.

## Output artifact
- Export pack can be sent to OEM, safety assessor, and founder as one shared truth.

## Share / return loop
- Export pack can be sent to OEM, safety assessor, and founder as one shared truth.

## Constraints
- Time: one-session prototype.
- Budget: local mock data; no paid external API.
- Platform: responsive web, desktop and mobile.

## Non-goals
- Full production integrations, legal guarantees, payments, or custom Phase A demo.

## Success metrics
- First action understood in 3 seconds; core flow completed without instruction; output shared or saved.

## QA / screenshot criteria
- Assigned profile operator-dense is unmistakable; primary interaction and result fit above fold; mobile has no overflow; all required sections visible.
