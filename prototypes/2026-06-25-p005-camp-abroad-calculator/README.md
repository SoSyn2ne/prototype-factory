# Camp Abroad Calculator

A childcare arbitrage calculator for parents comparing local summer camps, overseas programs, travel, work coverage, and social pressure.

## Status
- prototype

## Prototype brief
- Label: Practical / Commercial
- Design profile: premium-editorial
- Theme: 사교육 / 자산 방어 / 외모
- Target user: Working parents in high-cost cities planning summer childcare under budget and schedule pressure.

## Stitch prompt

Create a responsive web app prototype called "Camp Abroad Calculator" for working parents comparing summer childcare and camp options. Start on the decision workspace. Include a family summer calendar, camp comparison table, true-cost calculator, weekly coverage confidence meter, parent-network notes, child-fit checklist, and decision summary. Use realistic sample options such as local NYC day camp, sleepaway camp, Europe day camp, overseas swim camp, public lottery program, and shared caregiver. Design direction: use the premium-editorial profile with refined family-finance styling, elegant but readable typography, curated comparison cards, warm charcoal/stone tones, and one quiet CTA color.
