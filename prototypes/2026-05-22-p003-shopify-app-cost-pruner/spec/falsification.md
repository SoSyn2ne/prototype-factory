# Falsification checklist (5–7)

1. Merchants cannot gather app billing data quickly.
2. Cut recommendations feel too risky without deeper store context.
3. The savings forecast is not trusted.
4. Duplicate-function mapping fails on common app stacks.
5. Users already solve this with spreadsheets and do not need a product.
6. Shopify APIs or billing visibility block a realistic path.
7. Dashboard density hides the top 3 recommended cuts.
