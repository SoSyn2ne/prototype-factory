# Falsification checklist

1. If the first screen reads like a marketing landing page, the Phase B output fails.
2. If the workflow could be renamed into any generic dashboard, the concept fails novelty.
3. If cited source-signal pain is not visible in the UI sample data, the prototype is too abstract.
4. If the assigned design profile is not obvious from density, hierarchy, and tone, redesign.
5. If the user cannot see the next action within 30 seconds, the key UX is weak.
6. If risk/deadline/cost mechanics are hidden behind copy, the product is not concrete enough.
7. If the Stitch prompt omits realistic sample data, regenerate before ingest.
