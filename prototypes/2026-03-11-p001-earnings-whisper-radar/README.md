# Earnings Whisper Radar

Turn an earnings calendar into a risk-aware watchlist with catalyst checklists and post-earnings review prompts.

## Status
- prototype

## What this is
A *process tool* for earnings week: track a small set of names, attach a few structured prep steps, and compute a readiness score that reflects how prepared you are (not what the stock will do).

## How to run (demo)
- Open `demo/index.html` in a browser.
- Everything is local and persists via `localStorage`.

## Manual checklist
- Add 2–3 tickers with different dates.
- Filter to “next 3 days” and confirm list updates.
- Open a ticker and complete checklist items; score should change live.
- Refresh the page; the watchlist should remain.
