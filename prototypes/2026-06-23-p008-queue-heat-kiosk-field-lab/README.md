# Queue Heat Kiosk Field Lab

Field operators test kiosk queue friction with body-language notes, senior help moments, and abandonment triggers.

## Target user
Cafe/franchise operators, retail ops teams, accessibility testers, and kiosk vendors observing real-world queue frustration.

## Key UX
Observer runs a live field test: logs queue length, hesitation, help requests, failed taps, senior/disabled friction, and abandonment; the app turns observations into a retrofit brief.

## Required UI sections
- Live queue heat header with wait time, abandonment, and assist events
- Body-language tap log for hesitation, backtracking, and shoulder checks
- Kiosk screen friction checklist
- Senior and accessibility help moment recorder
- Staff interruption and recovery timer
- Retrofit recommendation board for signage, flow, and fallback ordering
- Before/after test report export
