# QA checklist

## Happy path
- Opportunity queue makes the most monetizable arrivals obvious.
- Selected guest detail combines stay context, add-ons, and offer actions cleanly.
- Premium styling still preserves strong desktop scannability.

## Edge cases
- Guests with no prior stay history still show useful state.
- Multiple room categories and add-on types remain easy to compare.
- Dense arrival days do not collapse the layout.

## Acceptance verification
- Metadata and specs reflect all required sections and prompt text.
- No placeholder text remains in scaffold docs.
- Demo remains minimal and non-custom.
