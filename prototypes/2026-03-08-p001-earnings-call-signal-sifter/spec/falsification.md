# Falsification checklist (7)

1. If I remove the “falsification queue”, do users still act on the signals (follow-up tasks), or do signals become a dead-end?
2. Do users find “exactly 5 signals” constraining in a bad way (missing nuance), causing them to abandon the workflow?
3. Does keyword filtering actually catch inconsistencies (e.g., “inventory” appears in multiple signals) or is it unused?
4. Are the five categories too investor-specific (advanced jargon) for the target user, reducing comprehension?
5. Does confidence sliding devolve into random “50%” defaults (no meaningful variance), implying the control adds friction without insight?
6. In real transcripts, do useful quotes frequently span multiple paragraphs, making the “excerpt” field hard to capture accurately?
7. When comparing against a manual workflow (notes app), is this UI measurably faster or does it add steps?
