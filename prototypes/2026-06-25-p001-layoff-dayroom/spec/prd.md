# PRD — Layoff Dayroom

## Problem
A daily command room for laid-off professionals to turn panic, ghosting, and scattered applications into a visible recovery routine.

## Target user
Recently laid-off white-collar workers and career coaches supporting job seekers through long search cycles.

## Key UX
Morning check-in chooses the day's search posture, then a board tracks applications, follow-up windows, warm intros, rejection patterns, and one human accountability action.

## Required UI sections
- Today posture strip: runway, energy, urgency, and confidence.
- Application lane board with status, last touch, next action, and ghosting age.
- Follow-up clock for recruiters, referrals, and networking asks.
- Rejection pattern reader with role, seniority, location, and resume variant.
- Accountability room with one small offline or peer action.
- Runway-safe task list for benefit paperwork, budget holds, and skill proof.
- Weekly recovery report for coach, partner, or support group.
