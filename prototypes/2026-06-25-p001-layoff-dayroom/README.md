# Layoff Dayroom

A daily command room for laid-off professionals to turn panic, ghosting, and scattered applications into a visible recovery routine.

## Status
- prototype

## Prototype brief
- Label: Practical / Commercial
- Design profile: calm-consumer
- Theme: 자산 방어 / 외로움 / 역전
- Target user: Recently laid-off white-collar workers and career coaches supporting job seekers through long search cycles.

## Stitch prompt

Create a polished responsive web app prototype called "Layoff Dayroom" for recently laid-off professionals managing a long job search. The first screen should be the actual daily command room, not a landing page. Include a top posture strip showing runway, energy, urgency, and confidence; an application lane board; follow-up clock; rejection pattern reader; accountability room; runway-safe task list; and weekly recovery report. Use realistic sample data for recruiter ghosting, referral asks, interview loops, and budget pressure. Design direction: use the calm-consumer profile with soft, reassuring surfaces, one gentle accent, steady next actions, readable cards, and no shame-heavy alarm styling.
