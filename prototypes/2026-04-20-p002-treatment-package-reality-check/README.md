# Treatment Package Reality Check

A cosmetic procedure planning workspace that helps users compare package deals, downtime, and visible payoff before insecurity-driven upsells blow the budget.

## Status
- prototype

## Theme
- 외모

## Design profile
- premium-editorial

## Key UX
- Line up clinic offers side by side, inspect how much visible change each package realistically buys, and walk into a consult with calmer boundaries and a smarter spend ceiling.

## Required UI sections
- event and confidence summary
- package comparison cards
- downtime versus visibility timeline
- financing pressure panel
- clinic question list
- recommended spend-limit drawer

## Stitch prompt
```
Design a desktop cosmetic-planning workspace called Treatment Package Reality Check for adults considering skin, injectable, or contouring packages before a visible life event. It should help users compare package deals, expected visible payoff, downtime burden, financing pressure, and clinic credibility before insecurity-driven upsells push them past a rational budget. Include an event and confidence summary, package comparison cards, a downtime versus visibility timeline, a financing pressure panel, a clinic question list, and a recommended spend-limit drawer. Design direction: use a premium-editorial aesthetic with warm stone and espresso tones, elegant typography, polished before-and-after framing, and composed luxury spacing so the product feels aspirational, discerning, and financially self-protective rather than salesy.
```
