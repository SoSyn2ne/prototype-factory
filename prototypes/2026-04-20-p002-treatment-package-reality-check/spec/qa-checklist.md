# QA checklist

## Happy path
- Open the prototype spec and understand the main decision loop within one pass.
- Confirm the required UI sections support the core workflow: Line up clinic offers side by side, inspect how much visible change each package realistically buys, and walk into a consult with calmer boundaries and a smarter spend ceiling.

## Edge cases
- Validate that emotionally sensitive states still feel clear and non-chaotic.
- Check that the design profile (premium-editorial) stays visible without overpowering usability.

## Acceptance verification
- Theme is explicitly labeled as 외모.
- Stitch prompt is copy-ready and includes explicit design direction.
- Meta/spec text matches the daily idea card with no placeholders.
