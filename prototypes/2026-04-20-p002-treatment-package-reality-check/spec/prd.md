# PRD — Treatment Package Reality Check

## Problem
- A cosmetic procedure planning workspace that helps users compare package deals, downtime, and visible payoff before insecurity-driven upsells blow the budget.
- Clinic sales flows are optimized to increase treatment size, not to help appearance-driven buyers judge visible payoff against debt, downtime, and emotional pressure.

## Target user
- Appearance-conscious adults considering skin, injectables, or contouring packages for a visible life event within the next 90 days.

## Constraints
- Time: Users should narrow to one realistic package path in under 7 minutes.
- Budget: Version one should use manual package entry and heuristic payoff framing instead of clinic integrations.
- Platform: Desktop-first comparison experience for pre-consult planning.

## Non-goals
- Medical diagnosis or personalized treatment advice.
- A marketplace that routes leads to clinics.
- Social beauty content or influencer-style discovery.

## Success metrics
- Users can define a spend ceiling before entering a consult.
- Users can compare visible payoff versus downtime without opening separate notes.
- The interface lowers regret risk by making package tradeoffs explicit.
