# Option Chain Sentiment Snap

A lightweight, local-only option-chain snapshot: enter a few strike rows and get a quick sentiment + key-strike read.

## How To Run Demo
```bash
# from repo root
cd prototypes/2026-03-12-p001-option-chain-sentiment-snap/demo
python3 -m http.server 8000
# open http://localhost:8000
```
