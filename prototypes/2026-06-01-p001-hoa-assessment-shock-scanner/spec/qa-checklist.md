# QA checklist

## Happy path
- User can see all required sections from the PRD.
- A pasted HOA excerpt produces red flags, scenario estimates, and an action queue.
- Design reads as financial-analyst: data-forward, calm, premium, and compact.

## Edge cases
- Missing HO-6 document.
- Conflicting HOA and insurance language.
- No obvious assessment language.
- Very large deductible scenario.

## Acceptance verification
- Includes design profile, theme, and signal references.
- Stitch prompt is present and copy/paste ready.
- No implementation beyond Phase A scaffolding is expected.
