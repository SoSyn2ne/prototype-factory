# Academy Waitlist Escape Planner

A cram-school seat capture planner that helps anxious parents compare academy options, waitlist odds, commute pain, and monthly spend before the next registration window closes.

## Status
- prototype

## Theme and design
- Theme: 사교육
- Design profile: operator-dense

## Core UX
- Compare academies side by side, see which waitlists are still realistically winnable, and turn family panic into a single enrollment attack plan before seats disappear.
