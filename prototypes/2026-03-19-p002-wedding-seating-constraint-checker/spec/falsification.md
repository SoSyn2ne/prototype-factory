# Falsification checklist (5–7)

1. Users say “this is obvious in my spreadsheet” and don’t gain speed or confidence.
2. The avoid/together constraints cover too little of real seating complexity, making the tool feel toy-like.
3. Conflict output is not actionable (users can’t quickly see what to change).
4. Users need automatic “suggest fixes” immediately; manual iteration is too slow.
5. Drag-and-drop floor plan is table stakes; list-based UI is rejected.
6. Data entry is too tedious compared to existing planning tools.
7. The planner role requires printing/export and share links; without it, the tool is not used.
