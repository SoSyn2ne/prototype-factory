# Falsification checklist (5–7)

1. If the main postcard stage is not immediately eye-catching, the concept loses its core payoff.
2. If mood and planet controls feel redundant, customization depth is fake rather than meaningful.
3. If caption generation feels bolted on, the share flow is weak.
4. If the export/share tray does not suggest a concrete outcome, the product loop feels incomplete.
5. If the interface feels like a generic dashboard instead of a playful studio, the design direction failed.
6. If the screen is too busy to understand in one glance, delight turns into friction.
