# QA checklist

## Happy path
- Open the demo and understand the create → tweak → caption → export loop.
- Preview the stitched screen without missing local assets.

## Edge cases
- Demo still renders when external networks are blocked.
- Asset paths remain local and portable.

## Acceptance verification
- Title, one-liner, and visual theme match the daily idea file.
- Required UI sections are visible in the stitched screen.
