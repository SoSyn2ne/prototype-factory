# PRD — Pocket Planet Postcard Composer

## Problem
- Casual creators want a delightful, fast way to make tiny world postcard visuals without using a heavy design tool.

## Target user
- Casual creators, students, and portfolio browsers who enjoy whimsical visual tools.

## Constraints
- Time: postcard should feel editable in a few minutes.
- Budget: lightweight demo-first prototype.
- Platform: desktop web.

## Non-goals
- Full 3D scene editing.
- Real soundtrack generation.

## Success metrics
- Users can create one share-worthy postcard concept in a single session.
- The main controls make the visual customization loop obvious.

## Notes
- Design should optimize for charm, shareability, and visual payoff.
