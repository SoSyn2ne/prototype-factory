# PRD — 쇼핑몰 정산 차이 추적

## Problem / Target user
Shopify 순입금의 매출·수수료·환불 구성을 장부와 대조하는 스토어 운영자 또는 기장 담당자가 대상이다. PAY-01은 입금마다 수동 분리와 가끔 발생하는 실수를, PAY-02는 Q4 보고서 대조·지원 문의를 직접 설명한다. 두 사례는 서로 다른 저자의 경험이며 일반적인 손실·누락 금액·월 소요시간이나 구매 의사를 증명하지 않는다.

## Proposed scope
한 스토어의 정산명세 한 건과 그 명세에 대응하는 익명 거래 내보내기 파일을 범위로 한다. 운영자가 파일 정의·포함 항목·기간·통화·식별자를 먼저 확인한 뒤 확인된 구성과 미연결·미설명 항목을 원본 행으로 추적하는 읽기 전용 검토 자료를 제안한다. 은행 로그인, 세금 판단, 자동 분개, 환불·입금 실행, 누락 자금 판정, 계정 연결과 외부 전송은 제외한다.

## Success / Unknowns
유료 실증 통과는 합의한 범위·가격의 첫 실제 수금, 같은 명세의 근거 확인 시간 개선, 잘못된 연결·추정 분류 비증가와 담당자의 모든 설명·미해결 항목 확인을 요구한다. 수금 없이 효용만 확인되면 업무 타당성 관찰로만 기록한다. 정의가 다른 보고서는 대조 불가로 두며 만족·다음 명세 재사용·재결제는 별도로 확인한다. 돈을 찾아 주거나 회계 정확도를 보장하지 않는다. 현재는 정적 설계 예시뿐이며 파일 처리·실제 스토어 검증·계산 엔진은 구현되지 않았다.
