# UI spec — 쇼핑몰 정산 차이 추적

## 현재 설계 예시
첫 화면에는 제목, “설계 예시 · 실제 파일 처리 미구현”, 대조할 자료의 정의와 가상 검토 행을 둔다. 구성 항목·원본 근거·연결 상태·담당자 확인을 중심으로 읽으며 실제 정산 합계·회수 금액·정확도 수치를 표시하지 않는다. 기존 제품의 중립 표면·한 강조색을 쓰고 작은 화면의 표는 가로 스크롤한다.

## 향후 구성과 상태
범위 확인 → 한 명세와 거래 파일 → 근거 행 연결 → 설명 가능/미연결/정의 불일치 목록이 핵심이다. 준비 전, 읽기 실패, 대조 불가, 검토 중, 담당자가 확인한 자료를 별도 상태로 둔다. 빈 목록을 자동으로 “모든 정산 정상”으로 바꾸지 않고, 계산과 회계 판단을 구분한다.

## 이벤트와 접근성
현재 동작은 상세 분석·직접 원문 링크 이동뿐이며 업로드·계산·은행 연결·회계 반영·다운로드 버튼은 없다. 향후 구현은 한 항목을 선택하면 원본 행·식별자·기간과 아직 모르는 정의를 보여 주도록 한다. 한 개 h1, 표 제목·머리글·키보드 포커스·본문 대비를 유지한다. 납품은 로컬 읽기 전용 자료부터 검토한다.
