# QA checklist — p008 KR 알바/단톡방 사기 패턴 Sniffer

## Happy path
- 메시지 paste ("좋아요 1건당 3000원, 첫 입금 후 작업 시작") → 0.5초 안에 사기 패턴 점수 87.
- 6-category radar (첫 입금 후 고액 요청, 긴급성, 신원 비공개) 표시.
- "1분 행동 3개" 카드 (링크 클릭 금지, 단톡방 나가기, 경찰 112 신고).
- 4종 신고 패킷 (경찰 112/금융감독원 1332/스팸/KISA) 1-click copy 정상.
- 안전 정통 알바 채널 5개 (워크넷/사람인/크몽/잡코리아/알바몬) 표시.

## Edge cases
- 메시지 짧음 (< 50자) → 점수 신뢰도 낮음 경고.
- URL 포함 → "링크 클릭 금지" 자동 추가.
- "검증된 단톡방" 표시 → 검증된 단톡방 카테고리 +25.
- 연예인/인플루언서 사칭 → 사칭 카테고리 +30.
- 모바일 1-hand 인터랙션.

## Acceptance verification
- 6 sample scam messages 모두 점수 + 6-category + 1분 행동 + 4종 패킷 채워짐.
- 사기 패턴 재현율 ≥ 0.80.
- 4종 패킷 법무 검토 통과.
- 안전 채널 5개 이상 freshness ≤ 14일.
- 모바일 1-hand 가능.
- KR-only copy.
