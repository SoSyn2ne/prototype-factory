# Falsification checklist (5–7)

1. Users still need too many clicks outside the screen to send a confident quote.
2. The quote builder feels like admin work instead of speed leverage.
3. Competitor-risk language feels gimmicky or untrustworthy.
4. Trade businesses prefer route scheduling first and quoting second.
5. The same layout does not generalize across HVAC, plumbing, and electrical contexts.
6. Lead urgency signals are too vague to support real prioritization.
7. The design direction produces a marketing page feel instead of an ops tool.
