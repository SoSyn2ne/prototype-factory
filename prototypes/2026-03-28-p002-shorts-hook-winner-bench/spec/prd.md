# PRD — Shorts Hook Winner Bench

## Problem
- A creative review bench that ranks short-form video hooks by retention signal so teams can scale winners before ad spend is wasted.
- Users currently track the workflow across spreadsheets, inboxes, and ad-hoc follow-ups.
- The prototype should make the highest-value next action obvious in one desktop screen.

## Target user
- Performance marketers and short-form content operators running many hooks per week.

## Key UX
- Compare hook concepts instantly, see where viewers drop, and choose the next batch to scale, remix, or kill without digging through scattered analytics.

## Required UI sections
- Hook-performance hero
- Hook ranking board
- Retention drop chart
- Remix opportunity card
- Audience-fit notes panel
- Scale decision footer

## Constraints
- Time: Phase A only; do not build a custom production demo yet.
- Budget: static prototype / Stitch-export friendly.
- Platform: responsive web UI with a desktop-first composition.

## Non-goals
- No live integrations or external APIs.
- No backend auth, billing, or notification plumbing.
- No fully custom demo logic beyond scaffold + stub.

## Success metrics
- A user understands the core workflow in under 30 seconds.
- The main decision path is visually obvious without onboarding.
- A Stitch export can drop into the stub demo slot with minimal cleanup.

## Stitch prompt
- Design a high-clarity desktop analytics product called "Shorts Hook Winner Bench" for operators reviewing short-form video hooks. Use a punchy creative-ops design direction with charcoal, soft ivory, and neon cyan accents; make hierarchy bold, charts easy to scan, and the overall product feel fast, experimental, and performance-driven. Include: (1) a hook-performance hero with active tests, winners today, and scale-now CTA, (2) a hook ranking board listing concept, spend, CTR, hold rate, and win status, (3) a retention drop chart comparing first-3-second and first-10-second falloff, (4) a remix opportunity card suggesting stronger opening lines or visuals, (5) an audience-fit notes panel with segment reactions and fatigue signals, and (6) a scale decision footer with keep, remix, pause, and projected spend allocation. Use realistic mocked creator/ad data, desktop-first layout, concise labels, and no code blocks.
