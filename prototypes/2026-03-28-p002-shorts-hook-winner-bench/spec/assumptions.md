# Assumptions (KNOWN / ASSUMPTION / UNKNOWN)

## KNOWN
- Fast hook comparison is the core value story, not full campaign reporting.
- Operators need to see retention and spend efficiency together to decide quickly.
- A desktop-first review bench should make winners and losers obvious at a glance.

## ASSUMPTION
- Teams already test multiple opening hooks against similar audience segments each week.
- Remix suggestions are more valuable than long-form diagnostics in the first review pass.
- Most scale decisions happen in short operator review sessions, not deep analyst workflows.

## UNKNOWN
- Which retention threshold feels trustworthy enough to greenlight more spend.
- How much creative thumbnail or script context belongs beside the ranking board.
- Whether users prefer card-based concepts or compact table rows for hook review.
