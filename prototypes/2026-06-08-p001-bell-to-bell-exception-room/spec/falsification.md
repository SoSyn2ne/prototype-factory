# Falsification checklist

1. If the prototype feels like student surveillance, the concept fails.
2. If exception expiry is not visible in the queue, the main workflow fails.
3. If the heatmap cannot show hallway and lunch-period gaps, the operational premise is weak.
4. If parent escalation copy is generic and not tied to policy state, the value is thin.
5. If teacher buy-in is framed as blame rather than coverage risk, adoption risk is high.
6. If a same-day huddle script is missing, it is only a dashboard.
7. If the screen cannot be understood by an assistant principal in one glance, redesign.
