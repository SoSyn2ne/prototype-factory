# QA checklist

## Happy path
- First screen clearly states: Players bet which trending AI-agent repo will survive the week before the hype meter buries it.
- Shows target workflow for: Developer communities, AI-tool skeptics, devrel teams, and portfolio viewers who enjoy open-source trend humor.
- Includes all required UI sections: repo horse lineup, hype meter, durability cards, weekly race lane, collapse animation state, shareable prediction card.
- Uses exactly one design profile: playful-experimental.
- Includes a clear output artifact or decision state.

## Edge cases
- Empty or incomplete input state is visible.
- Risk, cost, conflict, or pressure states do not rely on color alone.
- Long labels fit on mobile and desktop.
- The UI does not become a marketing landing page.
