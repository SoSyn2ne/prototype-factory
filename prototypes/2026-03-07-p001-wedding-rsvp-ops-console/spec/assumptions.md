# Assumptions (KNOWN / ASSUMPTION / UNKNOWN)

## KNOWN
- Day-of ops needs a printable artifact (venue/catering often wants a paper copy).
- Dietary notes are a common failure point (allergy risk + last-minute confusion).

## ASSUMPTION
- A simple heuristic seating suggestion (keep groups together, fill tables) provides real value even if imperfect.
- For a small wedding, local-only storage is acceptable for an MVP demo.

## UNKNOWN
- How much the user wants *editing* seating vs. “suggest once then export”.
- Whether the “group” concept maps to real relationships well enough (families vs friend circles vs coworkers).
- What minimum fields are required in different regions (kids meals, halal/kosher, etc.).
