# 10-K Red Flag Radar

Paste 10-K excerpts, tag risk signals, and export a tight due-diligence checklist.

## Status
- prototype

## How to run
- Open `demo/index.html` in a browser (offline; no server required).

## Manual checklist
- Paste a Risk Factors paragraph and click **Scan**.
- Confirm you get category scores + an evidence view.
- Add one custom phrase (e.g., “covenant”) and re-scan.
- Click **Copy checklist** and paste into a note.
