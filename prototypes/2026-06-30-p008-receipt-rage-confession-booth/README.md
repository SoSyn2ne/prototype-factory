## Stitch Prompt

```text
Create a responsive web prototype for "Receipt Rage Confession Booth", a shareable consumer vent booth that turns hidden fees and terrible service stories into a clean complaint poster and action script. Target user: consumers angry about fees, dynamic prices, and service dead-ends who want to vent without sounding chaotic. Build the key UX around entering a fee/service story, classifying the rage type, generating a poster, and receiving a practical complaint script or policy action link. Required UI sections: rage story intake, hidden fee autopsy, complaint tone selector, shareable poster generator, and action script and escalation links. Design direction: use the premium-editorial profile with refined contrast, editorial typography, one quiet CTA color, and polished complaint-card layouts. Use source signals S15, S1, and S3 as problem evidence only.
```
