# Falsification checklist (5–7)

1. Do users refuse to enter scores (impact/confidence) because it feels "fake precision"?
2. Do users disagree with the horizon penalty so strongly that ranking feels wrong?
3. Does the ladder create false certainty ("high score" = "buy") without context?
4. Are falsification prompts ignored unless they are highly personalized to the thesis?
5. Does the tool only work for short-term catalysts and fail for long-horizon narratives?
6. Would a simple notes template in Notion/Apple Notes be faster for the same outcome?
7. Does the ranking need an additional dimension (risk, position size, downside) to be useful?
