# QA checklist — $500 Proof Ladder

## Happy path
- Complete: Choose a paid-proof target, drag seven experiments onto a 14-day ladder, log asks/deposits/refusals, then continue/pivot/kill.
- Confirm every required section is present: Project snapshot; proof target; experiment deck; 14-day ladder; ask script; evidence ledger; decision gate; receipt.

## Edge cases
- Empty input, malformed input, low-confidence evidence, long text, and mobile width have explicit states.

## Acceptance verification
- Every experiment has time, audience, proof strength, and a copyable ask; progress uses actual evidence rather than task completion.
- Source refs S4, S5 and profile calm-consumer match ideas.md and meta.json.
