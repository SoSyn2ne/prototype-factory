# QA checklist

## Happy path
- Bay board shows profitable vs leaking slots clearly.
- Selected period view connects schedule, labor load, and parts readiness coherently.
- Recovered-profit rail supports the same optimization story as the board.

## Edge cases
- Empty bays, delayed parts, and overtime states all render cleanly.
- Dense schedules remain readable on desktop.
- Mixed job durations do not collapse layout.

## Acceptance verification
- All required UI sections appear in filled docs and metadata.
- No placeholder bullets remain from templates.
- Demo remains stubbed, not custom-built.
