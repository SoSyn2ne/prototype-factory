# Falsification checklist (5–7)

1. Managers already solve this in whiteboards or existing shop software with no pain.
2. Parts readiness is not important enough to warrant a dedicated panel.
3. Margin recovery is less persuasive than on-time completion metrics.
4. The board view hides too much detail for real scheduling decisions.
5. Technician load needs skills and certification data to be meaningful.
6. Overtime creep is usually accepted and not actively managed.
7. Recovered-profit rail adds clutter without changing prioritization.
