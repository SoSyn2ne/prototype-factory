# QA checklist

## Happy path
- A singles-event host creates a real/recent/respectful booth card with a fresh cafe prompt, one friend quote, privacy toggles, and a wall-mode slide for the mixer.

## Edge cases
- User has been falsely accused of using AI photos.
- Friend quote includes too much private detail.
- User wants proof without a face photo.
- Platform ban note needs to be saved but not shared.

## Acceptance verification
- meta.json includes designProfile, theme, candidateLabel, and sourceSignals.
- spec/prd.md includes target user, key UX, required sections, profile, theme, and sources.
- No placeholder bullets remain in spec files.
