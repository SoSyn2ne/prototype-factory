# Assumptions (KNOWN / ASSUMPTION / UNKNOWN)

## KNOWN
- Core concept: Turn overnight GPU jobs, incidents, and maintenance notes into a morning handoff board with clear owner actions.
- Primary user: Solo operators or small AI teams running home-lab / small-server GPU workloads overnight.
- Desired interaction style: A morning ops board that summarizes completed jobs, failures, thermal anomalies, and the first three actions to take.

## ASSUMPTION
- Users prefer a single summary screen before drilling into details.
- The first version can rely on manually entered or mocked data.
- The most valuable output is a prioritized action list, not raw data exhaust.

## UNKNOWN
- Which data fields are absolutely mandatory on day one.
- Whether users want print/export first or collaboration first.
- Which visualization earns the fastest trust in real usage.
