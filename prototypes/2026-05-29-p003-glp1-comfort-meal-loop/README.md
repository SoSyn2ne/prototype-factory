## Stitch prompt
Create a responsive web app prototype for "GLP-1 Comfort Meal Loop," a dose-week meal and symptom planner for people on GLP-1s who need tiny, tolerable defaults instead of another diet dashboard. Include: dose-week status header, tiny meal default planner, nausea/constipation/fatigue/hydration/injection-site symptom check-ins, food aversion safe-repeat list, grocery mini-list, provider-contact flag panel, non-emergency disclaimer, appointment summary export, and trend strip for appetite, energy, and tolerance. Design direction: use the calm-consumer profile with gentle health guidance, low-pressure check-ins, soft risk flags, and practical meal cards; it should feel supportive and provider-ready, not like a weight-loss leaderboard or medical diagnosis tool.
