# Private Camp Flex Mirror

A playful status mirror for parents to test whether elite camp spending is network-building, anxiety spending, or pure flex.

## Phase
- Phase A spec for Stitch generation.

## Design Profile
- playful-experimental

## Theme
- 역전

## Source Signals
- S11: New York Post, 2026-06-24 - Some parents spend $20K+ on elite summer camps, framing them as networking and confidence investments. (https://nypost.com/2026/06/24/lifestyle/posh-moms-spend-thousands-on-fancy-sleepawy-camps-and-gear/)
- S13: KidPlanr citing parent-reported Reddit pain, 2026 - A parent reports budgeting $3,600 for camp, then finding registration and materials fees that push the total higher. (https://kidplanr.com/blog/bay-area-summer-camp-hidden-costs-2026)

## Stitch Prompt

```text
Create a responsive web prototype for "Private Camp Flex Mirror", a playful status mirror for parents to test whether elite camp spending is network-building, anxiety spending, or pure flex. Target user: affluent or aspirational parents tempted by elite summer camp culture and worried about being left behind. Build the key UX around provocative tradeoff cards, a camp spend persona, and a shareable social-pressure receipt. Required UI sections: camp flex intake cards, network value meter, anxiety spend detector, parent persona result, and shareable receipt poster. Design direction: use the playful-experimental profile with a bold but readable composition, one memorable accent, and a strong shareable first impression without hiding the workflow. Use source signals S11 and S13 as problem evidence only.
```
