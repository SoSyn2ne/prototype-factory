# Falsification Sprint Planner

Turn assumptions into 1-day experiments with ROI scoring and explicit kill criteria.

## Status
- prototype

## What this is
A spec-first prototype exploring a simple workflow:
- define hypotheses,
- select a test template,
- set explicit kill criteria,
- prioritize with a lightweight score,
- log evidence and decide.

## How to use
- Read the spec in `spec/`.
- Open the demo UI at `demo/index.html` (static, vanilla HTML/CSS/JS).

## Manual checklist
- Create a card → verify score updates as you change sliders.
- Add evidence → mark verdict.
- Confirm top card is clearly recommended to run today.
