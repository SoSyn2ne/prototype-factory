# Falsification checklist (5–7)

1. 5명 사용자가 "이미 vendor customer care에 직접 연락한다"고 답하면 kill.
2. Five target users say the recovery/score feels wrong on a real pasted input.
3. Three target users say the 1-pager is not copyable / shareable as-is.
4. Two target users flag legal/regulatory inaccuracies serious enough to abandon.
5. The primary user can complete the core loop (paste → 점수 → vendor 매칭 → opt-out → 사례 공유 → 보상.) in under 60 seconds.
6. Mobile screenshot QA fails readability (44px controls / single-screen flow).
7. No measurable share trigger ("내 차량 화면 점수 88" X 공유.) within two weeks of soft launch.
