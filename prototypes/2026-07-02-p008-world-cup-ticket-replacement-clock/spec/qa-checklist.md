# QA checklist

## Happy path
- User sees the trigger: Your match ticket vanished, the flight is booked, and “comparable” might mean worse seats across town.
- User enters or reviews the evidence/input implied by: replacement fairness duel.
- User reaches the output artifact: Escalation letter, complaint checklist, and shareable group risk card.

## Edge cases
- Missing evidence or incomplete source data still produces a clear next-step checklist.
- User understands what is known, assumed, and risky without legal/medical/financial overclaiming.
- Mobile layout keeps the main action and status visible.
