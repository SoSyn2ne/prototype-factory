# ChipSignal Daily Brief

A 5-minute daily semiconductor/AI-hardware brief that turns news + earnings calendar into actionable portfolio tripwires (hold/add/trim) with explicit uncertainty labels.

## Status
- prototype

## What’s inside
- `spec/prd.md` — product requirements + Anti-RAG synthesis (anchor + 2 contrasts)
- `spec/assumptions.md` — G1 uncertainty labels (KNOWN/ASSUMPTION/UNKNOWN)
- `spec/falsification.md` — G2 falsification checklist (5–7)
- `spec/qa-checklist.md` — acceptance + edge cases

## How to use
- Read `spec/prd.md` first.
- If we decide to build v1, the next artifact is a **daily message template** (Markdown/Telegram) plus a small rule engine.
