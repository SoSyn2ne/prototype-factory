# QA checklist

## Happy path
- User enters state, care setting, household, assets, income, notices, and deadline.
- User sees a spenddown question ledger and missing-document list.
- User exports a handoff packet for professional review.

## Edge cases
- Spouse remains at home while one parent enters nursing care.
- Five-year lookback documents are incomplete.
- Renewal notice is close to deadline.

## Acceptance verification
- No placeholder bullets remain in specs.
- Prompt includes the `calm-consumer` design direction.
- UI copy states that it organizes questions and documents, not legal advice.
