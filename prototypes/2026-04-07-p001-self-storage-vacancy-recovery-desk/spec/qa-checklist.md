# QA checklist

## Happy path
- Vacancy queue clearly ranks units by recovery value and urgency.
- Selected detail view combines pricing, lead, and action context coherently.
- KPI hero and forecast rail reinforce the same occupancy story.

## Edge cases
- Facilities with sparse lead activity still render cleanly.
- Multiple unit sizes remain comparable without visual confusion.
- Empty-state clusters do not break hierarchy.

## Acceptance verification
- All required UI sections appear in metadata and spec docs.
- No placeholder template bullets remain.
- Demo stays scaffold-level only.
