# Falsification checklist (5–7)

1. Users say it feels like a toy and doesn’t resemble real incidents.
2. The suggested checklists are too generic to be worth using.
3. Without real telemetry, users won’t practice drills.
4. The UI adds friction vs. just opening a runbook doc.
5. Users require export/share as a hard requirement.
6. The drillboard encourages the wrong actions (unsafe reboots, data loss).
7. The incident log is not readable enough for postmortems.
