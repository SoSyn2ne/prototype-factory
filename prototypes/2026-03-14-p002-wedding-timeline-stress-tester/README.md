# Wedding Timeline Stress Tester

Model your wedding-day schedule, inject delays, and see where the plan breaks.

## Status
- prototype

## How to run
- Open `demo/index.html` in a browser.

## Manual checklist
- Add 6–10 tasks.
- Apply +20 min delay to Hair/Makeup and run stress test.
- Confirm alerts show overlaps/travel/buffer issues.
- Click Reset.
- Export JSON and confirm it parses.
