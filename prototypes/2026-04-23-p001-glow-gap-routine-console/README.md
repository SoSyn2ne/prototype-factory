# Glow Gap Routine Console

A beauty prep planner that helps users map skin, hair, sleep, and event timing into the cheapest routine that closes the gap between how tired they feel and how polished they need to look.

## Status
- prototype

## Theme
- 외모

## Design profile
- premium-editorial

## Target user
- Korean office workers, bridesmaids, job seekers, and creators who need to look pulled together for a deadline event without overspending on random treatments.

## Key UX
- Turn appearance anxiety into a prioritized prep ladder that shows what to do today, what can wait, and what is not worth paying for.

## Core UI sections
- face readiness snapshot
- event countdown timeline
- skin-hair-sleep gap matrix
- routine priority ladder
- budget versus payoff planner
- emergency fix notes drawer

## Stitch prompt
Design a desktop beauty prep planner called Glow Gap Routine Console for people who need to look noticeably more polished for an upcoming event without wasting money on random products or treatments. It should help users map skin, hair, sleep, and schedule pressure into a prioritized routine that closes the gap between how tired they feel and how polished they need to look. Include a face readiness snapshot, an event countdown timeline, a skin-hair-sleep gap matrix, a routine priority ladder, a budget versus payoff planner, and an emergency fix notes drawer. Design direction: use a premium-editorial aesthetic with warm stone tones, polished editorial typography, restrained luxury spacing, and calm beauty-service cues so the product feels aspirational, trustworthy, and quietly high-end.
