# QA checklist

## Happy path
- Create a case for a suspicious writing assignment.
- Sort evidence into fact, pattern, assumption, and missing.
- Choose a student recall check.
- Generate a neutral parent conference packet.

## Edge cases
- Evidence is weak and should not produce an accusation.
- Parent demands an immediate grade change.
- Admin requires a policy-specific consequence category.

## Acceptance verification
- The Stitch output should show case intake, evidence sorter, recall check builder, parent script, consequence matrix, caution panel, restoration plan, and export packet.
- The visual direction should read as calm-consumer and teacher-safe.
