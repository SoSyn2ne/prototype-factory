# Falsification checklist (5–7)

1. If teachers expect a detector verdict, the product positioning must be clearer.
2. If parent scripts overclaim, the concept becomes unsafe.
3. If evidence sorting takes longer than writing an email, adoption will be poor.
4. If school policies vary too much, the consequence matrix must stay editable.
5. If the flow feels punitive, add restoration and skill-building prominence.
6. If students' privacy concerns are not visible, admin buyers may reject it.
7. If Stitch makes it look like consumer therapy, tighten the educator workflow surfaces.
