# QA checklist

## Happy path
- User can compare at least two bid packages against reserve impact and urgency without opening separate documents.
- User can identify which project mix is safest for the current quarter.
- User can extract a concise board recommendation from the summary area.

## Edge cases
- One project has only a single bid.
- Reserve study is outdated and urgency scores are disputed.
- Two bids have similar price but very different owner disruption patterns.

## Acceptance verification
- Meta and spec files align on title, audience, design profile, and required UI sections.
- Product framing stays analytical and board-facing rather than contractor-facing.
- Demo remains a stub, not a full capital-planning implementation.
