# QA checklist

## Happy path
- User reviews a lease renewal with rent, CPI, CAM, insurance, and deposit deltas.
- User compares stay, move, and counteroffer cards.
- User exports broker/lawyer review memo copy.

## Edge cases
- CPI clause has no cap.
- CAM estimate is missing but prior-year actuals exist.
- Relocation cost outweighs rent increase.

## Acceptance verification
- No placeholder bullets remain in specs.
- Prompt includes the `financial-analyst` design direction.
- UI copy frames outputs as negotiation prep, not legal advice.
