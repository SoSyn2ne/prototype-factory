# Refund Human Trail

A consumer proof room for automated airline or retailer refund failures where broken forms, vanished support, and scam numbers create money-loss risk.

## Status
- prototype

## Prototype brief
- Label: Practical / Commercial
- Design profile: financial-analyst
- Theme: 자산 방어 / 외로움
- Target user: Travelers and shoppers fighting automated refund systems, plus consumer advocates who help them file complaints.

## Stitch prompt

Create a responsive web app prototype called "Refund Human Trail" for consumers documenting automated refund failures. The first screen should be a case workspace, not marketing. Include refund case header, deadline and amount risk, timeline builder, evidence upload grid, scam-risk checker, complaint packet generator, verified human-contact map, and final filing checklist. Use realistic sample data from a canceled flight/refund form failure with emails, failed pages, and suspected fake support numbers. Design direction: use the financial-analyst profile with rigorous case evidence, restrained charts, confidence badges, ink/off-white surfaces, and calm warning tones.
