# QA checklist

## Happy path
- Priority table sorts clearly by recovery value and close urgency.
- Selected quote reveals timeline, objections, and next action without navigation jumps.
- KPI hero and weekly rail reinforce the same pipeline story.

## Edge cases
- Long quote lists remain readable.
- Low-data quotes still render with a safe fallback state.
- Different objection types do not break the layout.

## Acceptance verification
- All required UI sections are present in docs and scaffold metadata.
- No placeholder bullets remain in spec files.
- Stub demo remains minimal and non-custom.
