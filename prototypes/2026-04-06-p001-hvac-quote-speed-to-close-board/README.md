# HVAC Quote Speed-to-Close Board

A home-service sales console that shows which HVAC quotes are most likely to close today and what friction is delaying the deal.

## Target user
- HVAC owners, inside sales coordinators, and service managers running small-to-mid-sized install teams.

## Key UX
- Rank open quotes by close probability and revenue impact, open one deal, and see customer urgency, financing friction, and the next best action in one screen.

## Required UI sections
- pipeline KPI hero
- open-quote priority table
- homeowner urgency timeline
- financing and objection panel
- next-action drawer
- weekly close-rate rail

## Stitch prompt
- Design a desktop sales operations app called **HVAC Quote Speed-to-Close Board** for HVAC install teams. It should help operators prioritize open quotes based on close probability, revenue value, homeowner urgency, and financing friction so they can recover deals before they stall. Include a pipeline KPI hero, an open-quote priority table, a homeowner urgency timeline, a financing and objection panel, a next-action drawer, and a weekly close-rate rail. **Design direction: use a confident field-sales visual system with deep blue surfaces, cool gray neutrals, and energetic orange accents; keep hierarchy sharp, numbers and tables instantly scannable, and the product feel practical, trustworthy, and revenue-focused.**
