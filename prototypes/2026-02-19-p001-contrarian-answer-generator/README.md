# Contrarian Answer Generator

`Contrarian Answer Generator`는 AI 답변 A를 그대로 수용하지 않고, 반대 관점에서 빠르게 검증하기 위한 정적 웹 프로토타입입니다.

## 무엇을 하나요?
입력한 답변을 기준으로 아래 5개 블록을 자동 생성합니다.

1. 핵심 전제(3)
2. 반대 시나리오(3) + 각 시나리오별 관측 가능한 신호
3. 실패 모드 분류(데이터/전제/비용/실행/법·보안/타이밍)
4. 반증 체크리스트(우선순위 7개 질문)
5. 다음 액션(3)

특징:
- 외부 API 호출 없이 로컬 JS 함수로 생성
- 템플릿 + 휴리스틱 기반
- 같은 입력이면 같은 출력(결정론적)
- `Aggressive` 스위치로 더 강한 반박 톤 선택 가능

## 로컬 실행
빌드 도구 없이 바로 실행할 수 있습니다.

1. `prototypes/2026-02-19-p001-contrarian-answer-generator/web/index.html` 파일을 브라우저에서 엽니다.
2. `Answer A`와 필요 시 `Context`를 입력합니다.
3. `Generate`를 눌러 결과를 확인합니다.

## 예시
### 입력
- Answer A:
  - "우리 팀은 고객지원 챗봇을 도입하면 반복 문의가 줄고, 운영비를 크게 절감할 수 있습니다. 내부 문서만 연결해도 초기 품질은 충분합니다."
- Context:
  - "3개월 안에 비용 절감이 필요함"

### 출력(요약 예시)
- 핵심 전제:
  - "반복 문의가 실제로 자동화 가능한 형태다"
  - "내부 문서만으로도 정확도가 유지된다"
  - "도입 비용보다 절감 효과가 먼저 나타난다"
- 반대 시나리오:
  - "자동화가 어려운 문의 비중이 높아 기대 절감이 무너짐" + 관측 신호
- 실패 모드:
  - 데이터/전제/비용/실행/법·보안/타이밍별 리스크 문장
- 반증 체크리스트:
  - 우선순위 질문 7개
- 다음 액션:
  - 1주 내 샘플 검증, 실패 기준 합의, 의사결정 게이트 설정
