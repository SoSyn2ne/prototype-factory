# Falsification checklist — Creator Offer Triage

1. Can the target user identify the core action in three seconds?
2. Does the interaction solve the cited pain better than a note or spreadsheet?
3. Can users complete the happy path without training?
4. Are evidence and inference visibly distinct?
5. Do edge states change the user's next action?
6. Does the `operator-dense` profile improve clarity for this context?
7. Would the user return or share the output artifact?
