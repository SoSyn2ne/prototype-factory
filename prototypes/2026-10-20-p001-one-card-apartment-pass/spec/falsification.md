# Falsification checklist

1. Residents still need an app installation before any useful action completes.
2. Older users cannot identify the correct action tile within ten seconds.
3. A failed token hides the phone, paper, or management-office fallback.
4. Household identity remains visible after a shared device completes an action.
5. Management staff report more support work than the current multi-app process.
6. The first screen looks like a property dashboard instead of a calm one-use strip.
7. Source S01 cannot be reproduced with local resident interviews.
