## Stitch prompt
Build a production-grade web app prototype called "Customer Rage Case File" for consumers trapped in terrible support loops, suspicious dynamic pricing, or refund dead ends. The first screen must be a working complaint packet builder with rage-to-evidence intake, fee and price-change timeline, support transcript sorter, refund ask calculator, regulator/company escalation selector, complaint letter preview, and shareable calm case card. Use realistic sample data: airline fee jump, telecom chat loop, subscription cancellation screenshot, 16% complaint surge note, junk fee line item, and a customer trying not to sound unhinged. Design direction: use the playful-experimental profile with a bold case-file metaphor, memorable evidence stamps, strong but readable contrast, and one obvious workflow that converts anger into leverage. Do not make a marketing landing page; the first screen must be the working app.
