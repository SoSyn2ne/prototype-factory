# Falsification checklist (5-7)

1. Target users do not recognize the pain from the first screen.
2. The workflow feels like a renamed generic dashboard instead of a new interaction.
3. The assigned design profile (operator-dense) is not visible in layout, density, color, or controls.
4. The prototype fails to show at least six required UI sections.
5. The cited signals cannot be traced from the spec.
6. The Stitch prompt omits the tailored design-direction sentence.
7. The output encourages risky claims beyond workflow support.
