## Stitch prompt
Create a responsive web app prototype for "Custom Order Chargeback Firewall," a made-to-order seller workspace that locks measurements, approval photos, delivery proof, and customer replies before a dispute can erase the margin. Include: merchant-account risk header, custom order timeline, measurement and scope-lock confirmation panel, photo proof locker, customer-message evidence thread, pre-ship dispute-risk checklist, bank/processor evidence bundle builder, and repeat-offender watchlist. Design direction: use the operator-dense profile with compact dispute queues, hard-edged proof states, margin-at-risk numbers, crisp evidence timelines, and no-nonsense seller controls; it should feel built for custom merchants protecting cash flow, not a generic fraud dashboard.
