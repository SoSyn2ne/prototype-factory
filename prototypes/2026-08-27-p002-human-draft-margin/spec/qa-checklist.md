# QA checklist

## Happy path
- First screen communicates the goal in three seconds.
- User completes: Paste draft → receive margin questions → self-revise → inspect voice drift → export authorship receipt.
- Output is produced: Revision-process authorship receipt.

## Edge cases
- Render all failure and uncertainty states named in the PRD.
- Never imply unverified external facts or completed external actions.
- Preserve the premium-editorial profile on desktop and mobile.

## Acceptance verification
- Actual target-user, UX, sections, profile, theme, and source references are present.
- No placeholder text or custom Phase A demo exists.
- Mobile width 390px and desktop width 1440px remain readable.
