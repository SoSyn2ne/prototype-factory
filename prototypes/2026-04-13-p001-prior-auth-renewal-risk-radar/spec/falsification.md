# Falsification checklist (5–7)

1. Do existing pharmacy or hub tools already expose renewal risk clearly enough that another dashboard adds little value?
2. Is manual data upkeep too high for teams already overloaded with payer work?
3. Are payer renewal rules too inconsistent to present in one reusable triage model?
4. Does the true bottleneck sit with provider response time rather than coordinator visibility?
5. Would organizations reject a tool that surfaces patient workflow data outside current systems?
6. Are therapy interruption events too infrequent in the target segment to justify workflow change?
