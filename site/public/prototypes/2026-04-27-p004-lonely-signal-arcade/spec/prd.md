# PRD — Lonely Signal Arcade

## Problem
- A playful anti-loneliness prototype that turns tiny check-ins, awkward invites, and missed social chances into a glowing social quest map.

## Target user
- Young adults who feel socially stuck, want more low-pressure connection, and need a playful push to send one message instead of doom-scrolling alone.

## Theme
- 외로움

## Design profile
- playful-experimental

## Key UX
- Convert loneliness into a game-like signal path: pick a tiny social quest, send a low-risk invite, and watch connection energy build through visual feedback.

## Required UI sections
- loneliness weather card
- tiny quest carousel
- low-risk invite composer
- connection signal map
- awkwardness shield meter
- shareable social win recap drawer

## Stitch prompt
Design a bold desktop social quest prototype called Lonely Signal Arcade for young adults who feel socially stuck and need a playful push to send one small message instead of doom-scrolling alone. It should turn tiny check-ins, awkward invites, and missed social chances into a glowing quest map where users pick low-risk actions and build connection energy. Include a loneliness weather card, a tiny quest carousel, a low-risk invite composer, a connection signal map, an awkwardness shield meter, and a shareable social win recap drawer. Design direction: use a playful-experimental aesthetic with glossy dark surfaces, neon comfort gradients, expressive micro-animations, and one charming quest flow so the product feels emotionally warm, weirdly fun, and portfolio-worthy.
