# Falsification checklist

1. Target users do not recognize the problem from the first screen.
2. The core loop takes longer than a short prototype session.
3. The output artifact is not useful enough to save or share.
4. Existing tools solve the trigger with less friction.
5. Required data is unavailable or too sensitive.
6. The assigned profile obscures rather than clarifies the interaction.
7. Edge states make the concept unsafe or untrustworthy.
