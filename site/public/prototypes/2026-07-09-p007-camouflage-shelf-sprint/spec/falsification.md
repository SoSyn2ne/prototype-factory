# Falsification checklist

1. The first screen reads like a generic dashboard instead of Prop Hunt / Meccha Chameleon hide-and-seek + browser drawing toy.
2. A target user cannot identify the next action within 5 seconds.
3. The required UI sections are missing: Lobby and 15-second rule card; Shelf image playfield with sticker palette; Tint/scale/rotate controls; Seeker timer and reveal animation; Vote results: stealth, funniest, most cursed.
4. The design direction does not match playful-experimental.
5. The prototype depends on source claims as market-size proof instead of treating them as problem evidence.
6. The workflow duplicates one of the last 7 PF batches without a new user, trigger, data source, or interaction mechanic.
7. The final screen lacks a shareable output, packet, receipt, or result tied to: The final reveal image is inherently shareable in group chats and short clips.
