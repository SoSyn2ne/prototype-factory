# Falsification checklist (5-7)

1. Can the target user recognize the trigger from real life within 3 seconds?
2. Does the first screen show a working workflow instead of a generic dashboard or landing page?
3. Are the cited source signals visible enough to explain why this idea exists?
4. Is calm-consumer expressed through layout density, accent choice, state coverage, and controls?
5. Would the export artifact be useful enough to share or save?
6. Is this meaningfully different from the last 7 PF daily batches by user, trigger, data source, or interaction mechanic?
7. Would a user still understand the prototype on mobile without text overlap?
