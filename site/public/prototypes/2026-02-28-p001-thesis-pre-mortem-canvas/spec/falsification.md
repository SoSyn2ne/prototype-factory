# Falsification checklist (5–7)

1. **If one key assumption fails, does the thesis still hold?** Identify the single assumption with the highest impact.
2. **What specific evidence (this week) would contradict the thesis narrative?** (e.g., guidance, competitor roadmap, customer churn signal)
3. **Are you smuggling valuation into “quality”?** If the business is great but the price is wrong, what would you do?
4. **What’s the non-obvious bottleneck?** (manufacturing capacity, supply chain, regulation, talent, distribution)
5. **What would a strong bear case look like from an informed insider?** Write it as if you had to defend it.
6. **What is the "one metric" that should move first if you’re right?** If it doesn’t move, what does that imply?
7. **If the stock drops 30% tomorrow, what would you need to see to add vs exit?** Define the rule before the emotion.
