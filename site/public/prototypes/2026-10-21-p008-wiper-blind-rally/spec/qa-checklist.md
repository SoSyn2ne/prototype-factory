# QA checklist

## Happy path
- 두 폰을 페어링하고 운전자/내비게이터 역할을 나눈다.
- 와이퍼 때문에 지도가 가려지는 판을 끝내고 8초 클립 뒤 역할을 바꾼다.

## Edge cases
- 연결 끊김, 모션 권한 거부, 버튼 대체, 무음, 세로/가로 회전, 리플레이 거부.
- 충돌과 완주 모두 보상·재경기 상태를 가진다.

## Acceptance verification
- 한 문장만 보고 각 역할과 와이퍼 트레이드오프를 설명할 수 있다.
- 390px에서 주 제어가 잘리지 않고 역할별 화면이 혼동되지 않는다.
