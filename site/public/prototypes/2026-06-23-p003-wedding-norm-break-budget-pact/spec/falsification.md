# Falsification checklist (5-7)

1. The prototype looks like a generic dashboard instead of the assigned calm-consumer profile.
2. The first screen is a landing page rather than the working app.
3. The core trigger from S5 / S6 is not visible in the workflow.
4. The user cannot produce an output artifact, decision, packet, script, memo, or field report.
5. The UI sections are present but do not connect into one coherent workflow.
6. The sample data feels fake or too abstract for the target user.
7. The idea duplicates a recent PF batch without a new user, trigger, data source, or interaction mechanic.
