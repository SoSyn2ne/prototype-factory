# Falsification checklist (7)

1. If users don’t know which incident type they’re in, the first selector is already too hard.
2. If the recommended actions are obvious to experienced operators, the tool adds no value.
3. If the heuristic outputs are wrong often enough, trust collapses quickly.
4. If operators need *exact commands* for their environment, generic actions won’t help.
5. If the real bottleneck is lack of telemetry (no signals), a simulator doesn’t help.
6. If the animation is annoying (not calming), it will be ignored.
7. If incidents vary more by workload than by symptoms, a small toggle model won’t fit.
