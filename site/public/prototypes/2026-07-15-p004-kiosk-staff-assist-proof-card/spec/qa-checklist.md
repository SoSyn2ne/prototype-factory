# QA checklist

## Happy path
- First screen clearly states: Small stores prove customers can get human ordering help when self-service kiosks fail them.
- Shows target workflow for: Korean cafe, food-court, franchise, and small-store operators facing accessibility and kiosk usability obligations.
- Includes all required UI sections: scenario selector, staff handoff checklist, signage preview, customer script cards, proof log, manager export.
- Uses exactly one design profile: field-ops.
- Includes a clear output artifact or decision state.

## Edge cases
- Empty or incomplete input state is visible.
- Risk, cost, conflict, or pressure states do not rely on color alone.
- Long labels fit on mobile and desktop.
- The UI does not become a marketing landing page.
