# PRD — Creator Sponsorship Pipeline Board

## Problem
- A sponsorship pipeline board that helps small creators prioritize brand leads by close likelihood and payout quality.
- Users currently split this workflow across multiple inboxes, spreadsheets, and ad-hoc judgment calls.
- The prototype should compress the highest-confidence next action into one desktop screen.

## Target user
- Solo creators and creator managers juggling inbound brand deals across email, DMs, and spreadsheets.

## Key UX
- Know which conversations deserve attention now, what deliverables are blocking close, and where the best cash-per-effort deals sit.

## Required UI sections
- Deal-flow hero
- Sponsorship stage board
- Payout quality panel
- Deliverable readiness checklist
- Brand fit insights card
- Weekly cash forecast rail

## Constraints
- Time: Phase A only; do not build a custom production demo yet.
- Budget: static prototype / Stitch-export friendly.
- Platform: responsive web UI with a desktop-first composition.

## Non-goals
- No live integrations or external APIs.
- No backend auth, billing, or notification plumbing.
- No fully custom demo logic beyond scaffold + stub.

## Success metrics
- A user understands the core workflow in under 30 seconds.
- The main decision path is visually obvious without onboarding.
- A Stitch export can drop into the stub demo slot with minimal cleanup.

## Stitch prompt
- Design a premium desktop creator-business dashboard called "Creator Sponsorship Pipeline Board" for small creators managing brand partnership opportunities. Use an editorial-meets-CRM design direction with espresso, cream, and saturated violet accents; create elegant hierarchy, high-contrast deal stages, and an overall product feel that is aspirational, organized, and commercially sharp. Include: (1) a deal-flow hero with open pipeline value, likely closes this week, and next-best CTA, (2) a sponsorship stage board showing inquiry, negotiation, draft, and ready-to-sign deals, (3) a payout quality panel comparing flat fee, CPM effective payout, and effort cost, (4) a deliverable readiness checklist for script, usage rights, timeline, and revision risk, (5) a brand fit insights card with audience overlap and reputational fit, and (6) a weekly cash forecast rail with best-case and likely payout timing. Use realistic mocked creator-business data, desktop-first composition, concise labels, and no code blocks.
