# Falsification checklist (5–7)

1. Do users insist on live chain import (manual entry is unacceptable)?
2. Does the simple call/put ratio mislead more than it helps (hedging flows)?
3. Are key strikes only useful when combined with price levels and IV?
4. Do users prefer a heatmap over a summary card UI?
5. Does per-expiry breakdown dominate aggregated views?
6. Would a broker UI already cover this need?
7. Do users trust only backtested signals, not heuristic snapshots?
