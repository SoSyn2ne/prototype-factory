# Falsification checklist (5-7)

1. Does the idea solve a fresh problem rather than renaming a prior PF dashboard/rescue/planner?
2. Does the first screen make the target user's urgent trigger obvious?
3. Is the assigned design profile (operator-dense) visible in layout, density, color, and interaction style?
4. Are the external signals represented as problem evidence, not market-size proof?
5. Can the core workflow be understood without explanatory marketing copy?
6. Would a user pay, share, or save this because the output reduces embarrassment, money risk, compliance fear, or operational pain?
7. Does the Stitch prompt include all required UI sections and a tailored design-direction sentence?
