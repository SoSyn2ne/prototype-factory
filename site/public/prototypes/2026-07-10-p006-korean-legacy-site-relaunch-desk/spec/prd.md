# PRD — Korean Legacy Site Relaunch Desk

## Problem
- Small Korean agencies turn old Gnuboard-style sites into a calm React/CMS migration quote, checklist, and owner demo path.

## Target user
- Korean small web agencies, freelancers, and business owners maintaining old community boards, local business sites, or membership portals.

## Key UX
- Scan the old site type, map board/member/payment/content risks, choose a migration tier, and export a quote plus owner-facing relaunch demo checklist.

## Required UI sections
  - Legacy site intake
  - Board/member/content risk map
  - Migration tier selector
  - Owner demo storyboard
  - Cost and timeline estimate
  - SEO/redirect checklist
  - Relaunch quote packet

## Design profile
- premium-editorial

## Theme
- Korea web agency modernization

## Source signal references
- S5 (GeekNews / Hada front page, captured 2026-07-10); S6 (GeekNews / Hada front page, captured 2026-07-10)

## Output artifact
- legacy site relaunch quote packet
