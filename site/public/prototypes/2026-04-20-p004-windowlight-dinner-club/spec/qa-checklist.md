# QA checklist

## Happy path
- Open the prototype spec and understand the main decision loop within one pass.
- Confirm the required UI sections support the core workflow: Pick tonight’s dinner mood, enter a shared ambient room, and trade tiny signals of presence while the table scene slowly changes with everyone’s emotional tempo.

## Edge cases
- Validate that emotionally sensitive states still feel clear and non-chaotic.
- Check that the design profile (playful-experimental) stays visible without overpowering usability.

## Acceptance verification
- Theme is explicitly labeled as 외로움.
- Stitch prompt is copy-ready and includes explicit design direction.
- Meta/spec text matches the daily idea card with no placeholders.
