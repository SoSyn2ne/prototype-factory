# Falsification checklist (5–7)

1. Friend groups reject planning tools as less spontaneous than texting.
2. Without live local venue data, generated quests feel generic.
3. Low-cost recommendations still require transportation that users lack.
4. The playful framing trivializes loneliness rather than making action easier.
5. Users prefer existing event calendars, Discord groups, or TikTok lists.
6. Share cards do not create enough viral pull for a portfolio concept.
7. The UI becomes too game-like and loses practical route clarity.
