# Falsification checklist — Layoff Buffer Action Map

1. If users avoid the product because the subject feels too frightening, the tone is wrong.
2. If severance timing is too unpredictable to model usefully, scenario comparison may feel fake.
3. If households care more about job-search tactics than cash sequencing, the product is solving the wrong first problem.
4. If dual-income coordination is the real bottleneck, solo planning will not convert to action.
5. If recommended spending cuts look unrealistic or socially painful, trust will break quickly.
6. If users cannot grasp their runway within one screen, the workbench is too dense.
