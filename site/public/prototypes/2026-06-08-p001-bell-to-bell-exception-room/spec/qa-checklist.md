# QA checklist

## Happy path
- User opens the enforcement room, sees today status, reviews the heatmap, assigns exception owners, and exports the huddle script.

## Edge cases
- Medical/IEP exception with no expiry.
- Parent escalation that conflicts with policy.
- One department has low buy-in but no individual teacher should be exposed.

## Acceptance verification
- p001 is scaffolded with actual metadata, source signals, theme, design profile, and Stitch prompt.
- No placeholder bullets remain in the spec files.
