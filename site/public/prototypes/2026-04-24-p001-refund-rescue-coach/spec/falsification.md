# Falsification checklist — Refund Rescue Coach

1. If most disputes are resolved informally without enough friction to justify a dedicated tool, the workflow may be overbuilt.
2. If users cannot clearly estimate likely deductions, the comparison logic will feel too speculative.
3. If move-out evidence collection starts too late in the real world, the product may arrive after the highest-leverage moment.
4. If renters mainly want a lawyer directory instead of a planning desk, the value proposition is misframed.
5. If the action log adds paperwork without increasing confidence or outcomes, retention will collapse.
6. If local rules vary too much across housing types, the default templates may feel unsafe or generic.
