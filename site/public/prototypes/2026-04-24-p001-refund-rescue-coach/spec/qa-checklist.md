# QA checklist — Refund Rescue Coach

## Happy path
- User can capture multiple evidence items and immediately see their refund-risk impact.
- Negotiation path comparisons stay readable and do not hide the next recommended action.
- Move-out deadlines and action notes are expressed without placeholder text.

## Edge cases
- Partial evidence still produces a usable recovery plan without breaking the layout.
- High-stress scenarios with many deductions still keep one obvious next action visible.

## Acceptance verification
- Theme is labeled as 자산 방어.
- Design profile is labeled as financial-analyst.
- Required UI sections are present in the written spec and ready for Stitch export handoff.
