# Falsification checklist - Meeting Bot Consent Firewall

1. Hosts skip the workflow because it adds friction before calls.
2. Consent copy is too legalistic or too weak.
3. The product cannot represent different meeting types clearly.
4. Participant opt-outs are hard to track live.
5. Existing calendar/video tools solve this sufficiently.
6. Audit logs are not trusted without integrations.
7. Clients find the firewall alarming rather than reassuring.
