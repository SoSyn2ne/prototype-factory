# Falsification checklist (5–7)

1. Do users find parameter input too abstract ("I don’t know my open rate")?
2. Does the simulator lead to overconfidence rather than contingency planning?
3. Is reminder scheduling the wrong lever (maybe invitation design matters more)?
4. Do users really need a funnel, or is a simple "responses by day" chart enough?
5. Are cohorts so different that a single model is misleading?
6. Would users rather see *ranges* than a single expected line?
7. Does this add value compared to a spreadsheet template?
