# Falsification checklist (5–7)

1. Landlords already trust existing screening platforms and do not want a separate review surface.
2. Compliance risk makes "suspicious document" language unusable in practice.
3. The workflow cannot handle enough document formats to feel useful.
4. Independent employer verification is too manual to create a clear product moment.
5. Users treat the score as an automatic rejection despite disclaimers.
6. Applicant privacy concerns block adoption.
7. Screening companies can copy the core feature quickly.
