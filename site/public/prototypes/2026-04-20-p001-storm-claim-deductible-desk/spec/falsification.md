# Falsification checklist (5–7)

1. Would users still trust the tool without direct policy parsing?
2. Do premium-risk estimates create more confusion than clarity?
3. Is the claim-versus-cash decision actually too situational for a generalized planner?
4. Would homeowners prefer a mobile capture tool over a desktop decision board?
5. Does contractor scheduling urgency outweigh insurance math in real usage?
6. Will users complete evidence entry before they need advice?
7. Can a recommendation feel decisive without creating liability expectations?
