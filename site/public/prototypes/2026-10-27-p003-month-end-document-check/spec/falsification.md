# 반증 조건 — 월마감 누락 서류 점검

1. 담당자가 승인할 필수 서류 목록을 만들 수 없으면 대조 프로그램보다 업무 기준 정리가 먼저다.
2. 실제 병목이 포털 로그인·다운로드이고 목록 대조·분류 시간이 작다면 이 제안은 보류한다.
3. 기존 Excel이나 파일 공유 도구의 체크리스트로 같은 결과를 더 빨리 얻으면 별도 프로그램을 만들지 않는다.
4. 필요한데 없는 자료를 한 건이라도 수신 확인으로 표시하면 통과시키지 않고 판정 기준을 고친다.
5. 매핑·익명화·사람 검토가 기존 누락 추적보다 오래 걸리면 자동화 범위를 줄이거나 중단한다.
6. 승인된 입력이 없어 원본을 계속 직접 읽어야 하거나 예외·교육·지원 원가가 요금을 넘으면 납품 범위를 다시 정한다.
7. 자료 접근·검토 참여·가격 합의를 한 고객을 확보하지 못하면 유료 수요가 검증됐다고 표시하지 않는다.
8. 다음 달 다시 쓰지 않거나 반복 납품이 없으면 구독·정기 관리로 확대하지 않는다.
