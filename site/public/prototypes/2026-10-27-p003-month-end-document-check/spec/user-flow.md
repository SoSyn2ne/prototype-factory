# 사용자 흐름 — 월마감 누락 서류 점검

## 정상 흐름

1. 담당자가 닫힌 대상 월과 고객 별칭을 선택하고 필수 서류 기준을 확정한다.
2. 고객·월·서류 종류를 확인한 수신 파일 목록을 준비한다. 포털 로그인 정보는 받지 않는다.
3. 목록 대조 결과에서 각 필수 항목의 수신 확인·누락·검토 필요와 근거를 확인한다.
4. 누락 항목은 요청 목록으로, 애매한 항목은 확인 질문으로 분리한 초안을 읽는다.
5. 담당자가 상태·대조 근거·문구를 수정하고 기존 연락 채널에서 직접 처리한다.
6. 실제 처리 시간·오류·수정량을 수동 기준표와 비교해 계속할지 결정한다.

## 예외 1 — 이름만 비슷하고 대상 월이 다름

- 필수 자료는 9월 카드 명세서인데 후보 파일은 `카드A_확인필요.pdf`이며 승인 월이 없다.
- 다른 자료와 이름이 비슷해도 수신 확인하지 않고 검토 필요로 남긴다.
- 담당자가 원본을 확인해 매핑을 승인하기 전에는 누락 요청 대신 월 확인 질문만 초안에 둔다.

## 예외 2 — 누락 또는 중복

- 후보 파일이 없으면 목록 기준 누락으로 표시하고 확인한 목록 범위를 함께 적는다.
- 같은 필수 항목에 수정본·원본 등 여러 후보가 있으면 최신본을 추측하지 않고 검토 필요로 둔다.
- 담당자가 요청 또는 후보 확정을 결정하며 프로그램은 고객에게 자동 연락하지 않는다.

## 현재 읽기 전용 예시

HTML은 위 흐름을 실행하지 않는다. 합성 고객 `고객 가`와 닫힌 월 `2026-09`의
고정된 네 항목과 요청 초안만 보여 준다. 클릭 가능한 업로드·대조·발송 버튼은 없다.
