# Assumptions (KNOWN / ASSUMPTION / UNKNOWN)

## KNOWN
- The concept is being scoped as a Phase A Prototype Factory idea, not a production build.
- The main workflow should center on: Turn scattered symptoms into a readable weekly pattern, spot which routines actually help, and prepare a clearer conversation for the next doctor visit without spiraling.
- Theme is 건강 and design profile is calm-consumer.

## ASSUMPTION
- Users want emotional steadiness as much as data visibility.
- A guided weekly pattern view is more useful than raw daily logging alone.
- Manual journaling is acceptable if the payoff feels immediately clarifying.

## UNKNOWN
- Which symptom combinations matter most across users.
- How much interpretation the UI can offer without sounding medically overconfident.
- Whether users want private solo reflection or printable clinician-facing summaries.
