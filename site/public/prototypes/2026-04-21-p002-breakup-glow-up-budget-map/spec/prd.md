# PRD — Breakup Glow-Up Budget Map

## Problem
- A post-breakup self-reinvention planner that helps users split beauty, fitness, wardrobe, and photo investments into a realistic confidence comeback plan without revenge-spending chaos.
- Existing workflows split the emotional or financial pressure signal away from the next best action, so users stall or default to guesswork.

## Target user
- Recently single adults who want to look and feel visibly better within 30 to 90 days without blowing savings on impulsive makeover spending.

## Constraints
- Time: Users should understand the top action path in under 5 minutes.
- Budget: The first version should work with manual input, lightweight imports, and no deep enterprise integrations.
- Platform: Desktop-first planning product designed for a single high-focus session.

## Non-goals
- Full back-office system replacement.
- Heavy automation that requires hidden AI decisions.
- Multi-role admin tooling beyond the core operator or end-user workflow.

## Success metrics
- Users can understand risk, upside, or chemistry state in one screen.
- Users can identify the next action without reading a long manual.
- The interface makes the emotional driver of the product feel obvious rather than abstract.
