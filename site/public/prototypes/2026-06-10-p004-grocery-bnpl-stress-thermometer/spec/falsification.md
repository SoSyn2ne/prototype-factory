# Falsification checklist (5–7)

1. If the playful tone shames users, it fails the concept.
2. If the thermometer is not tied to actual payment dates, it becomes decorative.
3. If relief cards are too generic, the app will not change behavior.
4. If receipt entry feels tedious, the prototype should imply SMS/email import.
5. If users hide BNPL from themselves intentionally, a shareable summary may backfire.
6. If mobile layout cannot show calendar density, switch to a payday list view.
7. If the idea feels too financial-advice heavy, keep it as awareness and planning only.
