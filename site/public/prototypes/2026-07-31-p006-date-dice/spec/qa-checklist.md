# QA checklist — p006 Off-App Date Idea Dice

## Happy path
- 5-슬라이더 (도시 = 서울, 예산 = 3만원, 시간 = 저녁, 인원 = 2명, 에너지 = 중간) → 5-주사위 자동 굴림.
- 미션 카드 1장 표시 (분위기 = 아늑한, 준비물 = 0개, 비용 = 2만원, 실패 대안 = 카페, 사진 각도 = 자연광).
- 미션 완료 체크 + 인스타 스토리 1-click 공유 정상.
- 1주 1개 미션 캘린더 표시.

## Edge cases
- 도시 = 지방 소도시 → 미션 후보 풀 축소.
- 예산 = 0 → 무료 미션만 (산책/별 보기).
- 시간 = 새벽 → 미션 후보 풀 축소.
- 인원 = 3+ → 그룹 미션.
- 모바일 1-hand 인터랙션.

## Acceptance verification
- 12 sample missions (커피 워크/서점 룰렛/요리/포토 헌트/노래방/플리마켓/별 보기 등) 모두 1장 카드 채워짐.
- 5-주사위 5-슬라이더 입력 반응 80% 이상.
- 미션 카드 5개 필드 (분위기/준비물/비용/실패 대안/사진 가이드) 모두 채워짐.
- 모바일 1-hand 가능.
- 안전 가이드 명시.
- KR/EN 토글 정상.
