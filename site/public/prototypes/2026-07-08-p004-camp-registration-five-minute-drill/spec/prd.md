# PRD - Camp Registration Five-Minute Drill

## Problem
- A parent war room for the January camp scramble: rank camps, prefill constraints, rehearse clicks, and keep backup childcare alive.
- Source evidence: S10 - Reddit r/workingmoms, 2026, total summer camp costs: Parents in high-cost areas report camps around $6,000 per child for 8 weeks and affordable YMCA slots selling out within minutes. S11 - The 19th, 2026-06, real cost of summer camp receipts: Summer activities increasingly run about $2,400 to $6,000 per child, making camp a childcare affordability problem.

## Target user
- Working parents who need summer childcare but face expensive camps, tiny affordable capacity, and registration windows that sell out in minutes.

## Key UX
- Rank camps by schedule, price, commute, refund risk, and backup value; rehearse the registration sequence and produce a live fallback plan.

## Required UI sections
- Camp priority board
- True weekly cost rows
- Registration countdown drill
- Document and payment checklist
- Sibling and commute constraints
- Backup care ladder
- Family decision receipt

## Assigned design profile
- calm-consumer
- Design direction: steady family-planning interface with warm grouping, clear next actions, and low-panic countdown treatment.

## Theme
- 사교육

## Practical vs fun
- Practical / Commercial
