# Falsification checklist (5–7)

1. If users cannot explain the product value after scanning the hero and first panel, the information hierarchy failed.
2. If the required UI sections do not support the promised workflow (Daily recovery hero; empty-slot timeline), the concept is underspecified.
3. If the next action remains ambiguous after reading the summary state, the prototype is not operational enough.
4. If the screen needs live integrations to make sense, the Phase A scope is wrong.
5. If the design feels like a generic template instead of a purpose-built operator view, the Stitch prompt is too vague.
6. If a user cannot identify one concrete unblocker within 30 seconds, the CTA and state design failed.
