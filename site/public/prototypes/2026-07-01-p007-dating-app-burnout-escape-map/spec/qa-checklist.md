# QA checklist

## Happy path
- First screen communicates: If the apps feel like bots and dead ends, your next match might be at the $180 gym you actually enjoy.
- User can identify the target user and trigger within 3 seconds.
- User can complete the primary mechanic: social serendipity map.
- Prototype produces: Shareable 7-day offline dating escape map..

## Edge cases
- Empty input state explains what proof/data is needed.
- User with partial evidence can still get a next step.
- Mobile layout keeps key actions reachable.
- Copy avoids claiming legal, medical, insurance, or financial guarantees.

## Acceptance verification
- Design profile appears exactly once as playful-experimental.
- Required sections are present: Burnout intake quiz, Offline venue match map, Conversation opener cards, Budget/time commitment slider, 7-day escape plan poster.
- Stitch prompt cites signals S18, S19, S20 as problem evidence only.
- No custom demo is implemented during Phase A.
