# PRD — Machine Peel School

## Product intent
Teach spatial repair dependencies by making learners predict the next safe part before peeling it.

## Arrival / validation
Model-specific repair searches, makerspaces, and museum workshops. Validate lesson completion and expert-order improvement.

## Core loop
Rotate machine → choose next part/tool → commit prediction → peel → see consequence → compare expert order → export sequence.

## First screen / key screens
Isometric espresso machine with one highlighted dependency and peel handle. Part tray, consequence, correction, sequence card.

## Interaction rules
Wrong order teaches rather than dead-ends. Original illustration assets only; reference repo supplies interaction inspiration.

## QA / risks
Wrong tool, hidden fastener, skipped part, perfect order. Technical accuracy and manufacturer IP are risks.

## Development start prompt
```text
Build a desktop/tablet exploded espresso-machine lesson with layered original SVG-like parts, rotate/peel interactions, dependencies, tool choices, consequences, and expert comparison.
```
