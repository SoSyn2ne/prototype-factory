# PRD — Customer Rage Case File

## Problem
- A consumer counter-service tool that converts bad support loops, dynamic-pricing suspicion, and refund dead ends into a clean complaint packet.

## Target user
- Consumers stuck with airlines, telecoms, retailers, or subscription companies who feel exploited but need evidence instead of ranting.

## Key UX
- User drops receipts, support chats, screenshots, and timeline facts; the app turns anger into a calm complaint file, escalation target, and refund ask.

## Required UI sections
- Rage-to-evidence intake
- Fee and price-change timeline
- Support loop transcript sorter
- Refund ask calculator
- Regulator / company escalation selector
- Complaint letter preview
- Shareable calm case card
