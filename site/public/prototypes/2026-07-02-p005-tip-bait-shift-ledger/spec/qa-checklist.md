# QA checklist

## Happy path
- User sees the trigger: A $14 offer became $5 after the drive, and you need to know if it is a pattern or a bad night.
- User enters or reviews the evidence/input implied by: tip-delta incident log.

## Edge cases
- Missing evidence or incomplete source data still produces a clear next-step checklist.
- User understands what is known, assumed, and risky without legal/medical/financial overclaiming.
- Mobile layout keeps the main action and status visible.
