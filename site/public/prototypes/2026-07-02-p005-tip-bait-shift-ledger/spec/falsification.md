# Falsification checklist (5-7)

1. The first screen reads like a generic dashboard instead of a mobile field ledger.
2. The prototype does not visibly produce Weekly tip-bait evidence report and platform support note.
3. The required UI sections are missing or reduced below the Phase A spec.
4. The design does not match the field-ops profile.
5. The idea cannot cite its source signals: S15, S16.
6. The core trigger is not obvious in 3 seconds: A $14 offer became $5 after the drive, and you need to know if it is a pattern or a bad night.
7. The flow asks for vague data instead of concrete inputs from the source-signal workaround.
