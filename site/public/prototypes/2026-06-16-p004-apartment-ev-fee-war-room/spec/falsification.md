# Falsification checklist (5-7)

1. The user cannot identify the trigger moment in under 10 seconds.
2. The first screen looks like a generic dashboard instead of the named workflow.
3. The output artifact is unclear or not worth sharing/saving.
4. Required evidence fields are too hard for the target user to gather.
5. The design profile is visible only as colors, not as workflow structure.
6. The sample data does not reflect the cited source signals.
7. A near-duplicate from the last 7 batches would solve the same job with the same mechanic.
