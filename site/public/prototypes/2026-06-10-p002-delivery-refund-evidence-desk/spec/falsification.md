# Falsification checklist (5–7)

1. If operators do not already capture prep or handoff evidence, packet completeness may stay low.
2. If platforms rarely accept merchant disputes, value shifts to internal loss tracking.
3. If the UI feels like legal advice, it creates risk.
4. If the queue duplicates POS screens, it needs stronger evidence assembly mechanics.
5. If review response scripts sound defensive, they may harm reputation.
6. If tablet use is unrealistic during shifts, design should favor after-shift desktop review.
7. If Stitch overpacks the screen, prioritize order queue, timeline, and packet preview.
