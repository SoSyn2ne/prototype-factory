# QA checklist

## Happy path
- Risk queue highlights high-value drifted clients cleanly.
- Selected profile combines cadence, package, and outreach context in one view.
- Premium visual direction still preserves strong operational readability.

## Edge cases
- Clients without package plans still show useful state.
- Long treatment histories stay readable in the timeline.
- Different service categories do not break card hierarchy.

## Acceptance verification
- All required UI sections are reflected in metadata and specs.
- No placeholder template text remains.
- Demo stays scaffold-level only.
