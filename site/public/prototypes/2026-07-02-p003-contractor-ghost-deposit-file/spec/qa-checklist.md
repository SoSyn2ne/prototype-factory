# QA checklist

## Happy path
- User sees the trigger: The friendly contractor has your deposit, your texts, and suddenly no calendar.
- User enters or reviews the evidence/input implied by: proof timeline builder.
- User reaches the output artifact: State complaint or small-claims packet with evidence timeline.

## Edge cases
- Missing evidence or incomplete source data still produces a clear next-step checklist.
- User understands what is known, assumed, and risky without legal/medical/financial overclaiming.
- Mobile layout keeps the main action and status visible.
