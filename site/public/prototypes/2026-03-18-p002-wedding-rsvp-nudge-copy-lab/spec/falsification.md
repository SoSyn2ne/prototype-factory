# Falsification checklist (6)

1. If Polite, Playful, and Direct feel too similar in user review, tone separation is insufficient.
2. If moving closeness or urgency does not materially change phrasing, the controls are decorative.
3. If Kakao, SMS, and email outputs feel interchangeable, channel logic is too weak.
4. If notes frequently create awkward or bloated copy, freeform note injection needs redesign.
5. If copying fails in common local-file or browser contexts, the core workflow is broken.
6. If users read the score as real performance data, the score label is misleading.
