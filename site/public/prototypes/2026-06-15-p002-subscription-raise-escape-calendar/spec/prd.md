## Stitch prompt
Create a responsive web app prototype called "Subscription Raise Escape Calendar" for households, couples, debt paydown users, and adult children helping parents stop recurring-charge creep. The app should import subscriptions, renewal dates, trial conversions, price hikes, cancellation steps, household usage, and card ownership, then rank keep/cancel/rotate actions and generate cancellation scripts. Required sections: recurring burn header, subscription import table, price-hike and trial-conversion calendar, usage honesty check, cancel difficulty lane, streaming/software rotation plan, card-lock and reminder checklist, and annual savings receipt. Use realistic sample data with $171.53/month in charges, a streaming price hike, an annual software renewal, and one hard-to-cancel trial. Design direction: use the financial-analyst profile with off-white/graphite surfaces, restrained warning tones, compact savings comparisons, and calm confidence cues that make cancellation feel like a budget decision, not a shame spiral. Do not make a landing page; the first screen must be the working calendar.
