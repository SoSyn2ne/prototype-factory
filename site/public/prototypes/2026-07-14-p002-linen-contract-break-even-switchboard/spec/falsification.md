# Falsification checklist (5-7)

1. Target users cannot identify the problem from the first screen in 10 seconds.
2. The UI reads as a generic dashboard rather than restaurant procurement, cost control, vendor negotiation.
3. The source signals do not support the workflow trigger.
4. The design profile is not visible in layout, density, or control choices.
5. The Stitch output cannot show the required UI sections without placeholder filler.
6. The idea is too close to a prior seven-day PF batch after review.
7. The final artifact lacks a clear next action or share/export outcome.
