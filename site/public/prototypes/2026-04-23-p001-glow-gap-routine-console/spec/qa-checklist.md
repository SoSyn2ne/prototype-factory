# QA checklist — Glow Gap Routine Console

## Happy path
- User can enter an event date and see a reordered prep ladder immediately.
- Budget changes update the recommended routine without breaking the timeline.
- The interface clearly distinguishes must-do actions from nice-to-have upgrades.

## Edge cases
- Empty or partially filled manual inputs still preserve a readable layout.
- Very high stress or urgency scenarios still keep one obvious next action visible.
