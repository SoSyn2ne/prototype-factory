# Falsification checklist — Glow Gap Routine Console

1. If users still choose random treatments after seeing the priority ladder, the product is not reducing appearance anxiety enough.
2. If the same plan cannot serve both low-budget and premium-budget users, the planner may be too narrow.
3. If users do not trust manual self-scoring for skin, sleep, and hair condition, input quality will collapse.
4. If beauty prep decisions are driven mainly by influencer trends rather than event context, the planner may feel too rational.
5. If the visible payoff between recommended steps is too hard to explain, conversion to action will stay weak.
6. If the workflow takes more than five minutes to set up, stressed users may abandon it.
