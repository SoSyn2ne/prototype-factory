# Falsification checklist (5-7)

1. The first screen reads like a generic dashboard instead of a compliance rehearsal.
2. The prototype does not visibly produce Menu/QR/receipt patch packet plus staff fee script.
3. The required UI sections are missing or reduced below the Phase A spec.
4. The design does not match the operator-dense profile.
5. The idea cannot cite its source signals: S1, S3.
6. The core trigger is not obvious in 3 seconds: A new fee law says your service charge must be as visible as the burger, not buried at checkout.
7. The flow asks for vague data instead of concrete inputs from the source-signal workaround.
