# PRD - Restaurant Direct Order Migration Kit

## Problem
Restaurants plan a direct-order shift with QR perks, fee math, and customer scripts instead of just swallowing platform commission.

## Target user
Korean independent restaurants, immigrant-owned takeout shops, and local merchant associations trying to reduce delivery-app dependency.

## Key UX
Owner compares platform burden, direct-order incentives, customer messaging, and weekly migration goals; the app outputs QR campaigns, staff scripts, and fee evidence.

## Required UI sections
- Platform burden header with commission, promo spend, and order share
- App vs direct margin calculator
- QR and Kakao/SMS direct-order offer builder
- Customer script cards for pickup perks and loyalty credits
- Menu insert and receipt-stuffer preview
- Merchant association evidence log
- Weekly migration scoreboard by channel

## Assigned design profile
financial-analyst

## Theme
자산 방어 / 역전 - restaurant margin defense against platform dependency.

## Stitch prompt
Build a production-grade web app prototype called "Restaurant Direct Order Migration Kit" for Korean independent restaurants reducing delivery-app dependency. The first screen must be a working channel-migration workspace with a platform burden header, app-vs-direct margin calculator, QR and Kakao/SMS offer builder, customer script cards, menu insert and receipt-stuffer preview, merchant association evidence log, and weekly migration scoreboard. Use realistic sample data: 8.2% average commission, 15% promoted tier, 240 weekly delivery orders, 12% target direct shift, 2,000 KRW pickup perk, QR table tent, and a pending disclosure rule note. Design direction: use the financial-analyst profile with precise margin math, calm navy/off-white comparison panels, restrained warning tones, and Korean local operator cues. Do not make a marketing landing page; the first screen must be the working app.
