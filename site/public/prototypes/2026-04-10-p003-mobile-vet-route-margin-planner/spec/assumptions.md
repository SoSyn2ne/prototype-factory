# Assumptions (KNOWN / ASSUMPTION / UNKNOWN)

## KNOWN
- House-call businesses are sensitive to drive-time waste and schedule overruns.
- Urgent appointments can distort route profitability if inserted late.
- Dispatchers need map context and workload context at the same time.

## ASSUMPTION
- Mobile vet practices will accept margin-oriented planning if it still respects care urgency.
- Simple reroute recommendations are sufficient before full optimization engines exist.
- Operators can estimate visit value well enough for planning-level profitability views.

## UNKNOWN
- How often clinician specialty constraints make route-level recommendations unusable.
- Whether practices have reliable historical drive-time and visit-duration data.
- How emotionally acceptable margin-first visuals are in an animal-care context.
