# PRD — Hot Deal True Price Matchboard

## Problem
- Korean deal hunters compare coupons, shipping, options, and lowest-price history without reopening five tabs.

## Target user
- Korean hot-deal community users, family shoppers, and price-conscious group-buy organizers.

## Arrival path
- Search/community referral at the moment this trigger becomes urgent: budget defense / shopping truth.

## Business / validation route
- Validate with a focused landing/demo and measure completion plus artifact sharing; monetize through a lightweight subscription, template pack, or qualified partner lead.

## Core loop
- Paste a deal URL, match exact options, stack coupon and shipping conditions, compare effective price, and publish a proof card.

## First screen
- Communicate the one-liner in three seconds and expose the first input beside a realistic result preview.

## Key screens
- deal URL intake; exact-option matcher; coupon stack; shipping and membership costs; price-history strip; shareable verdict card.

## Interaction rules
- One decisive primary action per state; preserve entered data; show loading, empty, success, and blocked/error states.

## Output artifact
- Verdict card can be posted back into deal threads before others buy.

## Share / return loop
- Verdict card can be posted back into deal threads before others buy.

## Constraints
- Time: one-session prototype.
- Budget: local mock data; no paid external API.
- Platform: responsive web, desktop and mobile.

## Non-goals
- Full production integrations, legal guarantees, payments, or custom Phase A demo.

## Success metrics
- First action understood in 3 seconds; core flow completed without instruction; output shared or saved.

## QA / screenshot criteria
- Assigned profile financial-analyst is unmistakable; primary interaction and result fit above fold; mobile has no overflow; all required sections visible.
