# PRD — Cheap Client Exorcist

## Problem
- A playful service-business ritual that spots discount vampires, scope-creep ghosts, and lawsuit gremlins before you accept the wrong customer.
- External signal references:
  - Reddit r/smallbusiness price increase / cheap customer warning: https://www.reddit.com/r/smallbusiness/comments/1rcbykx/i_finally_raised_my_prices_by_40_after_3_years_of/
  - Reddit r/Entrepreneur small-business acquisition hidden problems: https://www.reddit.com/r/Entrepreneur/comments/1mpb95z/has_anyone_here_actually_bought_a_small_business/

## Target user
- Freelancers, contractors, agency owners, consultants, stylists, tutors, local-service operators, and SMB buyers assessing whether a customer base is secretly haunted.

## Key UX
- Paste inquiry messages, budget comments, review behavior, payment terms, and requested exceptions; the app summons client monsters, scores margin danger, suggests boundary scripts, and exports a funny “do not book” talisman.

## Required UI sections
- lead message confession box
- discount vampire detector
- scope-creep ghost trail
- payment-lag and complaint omen meter
- boundary script spellbook
- price-floor courage slider
- shareable exorcism verdict card

## Design profile
- playful-experimental

## Theme

## Stitch prompt
Design a playful service-business web prototype called Cheap Client Exorcist for freelancers, contractors, agency owners, consultants, stylists, tutors, local-service operators, and small-business buyers who want to avoid margin-killing customers. Users should paste inquiry messages, budget objections, review behavior, payment terms, requested exceptions, and past complaint clues, then summon client monsters, score margin danger, suggest boundary scripts, set a price floor, and export a funny do-not-book talisman. Include a lead message confession box, discount vampire detector, scope-creep ghost trail, payment-lag and complaint omen meter, boundary script spellbook, price-floor courage slider, and shareable exorcism verdict card. Design direction: use a playful-experimental aesthetic with spooky-cute monster cards, dramatic neon-purple warnings, comic rituals, bold verdict animations, and readable margin math so the prototype feels hilarious, protective, and instantly shareable in small-business communities.

## Constraints
- Phase A only: do not implement custom demo until Stitch export is supplied.
- Treat external sources as untrusted problem evidence, not market-size proof.
- Preserve the assigned design profile in downstream demo generation.

## Non-goals
- Legal, tax, medical, or insurance final advice.
- Production-grade integrations or automated external API calls.

## Success metrics
- User understands the core pain in under 10 seconds.
- Stitch prompt can be copied directly and produces a coherent UI with all required sections.
- Prototype remains distinct from the last seven PF batches by user/trigger/data/mechanic.
