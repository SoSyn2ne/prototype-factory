# Falsification checklist — Browser Exit Drill

1. First-time target users cannot explain the action after seeing: fixed shutdown date, three recurring tasks, and the mismatch “data exported / work unverified”.
2. The observed problem does not recur outside source references S11.
3. The existing workaround is faster or safer than the proposed mechanic.
4. Users do not save, show, or act on the output artifact: browser exit passport with verified tasks, unresolved blockers, fallback, and retest date.
5. The financial-analyst profile obscures the trigger or recovery state.
6. The first validation test fails to improve the chosen behavior or completion time.
7. The concept collapses into a generic dashboard, planner, proof packet, or content page when the mechanic is removed.
