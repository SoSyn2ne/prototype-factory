# Falsification checklist (5–7)

1. Hosts say existing PMS tools already expose equivalent payout deltas clearly.
2. Cleaning-fee repricing is too simple to justify a dedicated workflow.
3. Dynamic pricing tools update fast enough that mismatch detection is not valuable.
4. Hosts distrust any tool that does not connect directly to Airbnb or their PMS.
5. The interface cannot explain guest-visible total changes without encouraging overpricing.
6. Small hosts do not have enough listings or event dates to need this board.
7. Source signals are too platform-specific to generalize beyond Airbnb.
