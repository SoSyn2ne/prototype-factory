# Falsification checklist (5–7)

1. Do users already do this in Google Sheets with no pain?
2. Is manual data entry too annoying for couples (needs templates/import)?
3. Do the alerts feel obvious (“of course it overlaps”) rather than insightful?
4. Does single-track propagation mislead because real days have parallel tracks?
5. Is “travel time” too hard to estimate, making the feature unused?
6. Does the timeline visualization fail to communicate urgency/priority?
7. Are the results not actionable (no clear mitigation next step)?

## Same-day test plan (≤ 1 hour)
- Create a realistic schedule with 10–14 tasks.
- Run 3 scenarios:
  - HMU late +20 min
  - Ceremony late +15 min
  - Photo session overrun +30 min
- Ask: would you change anything based on the alerts?
- Fail criteria: you wouldn’t adjust the plan after seeing outputs.
