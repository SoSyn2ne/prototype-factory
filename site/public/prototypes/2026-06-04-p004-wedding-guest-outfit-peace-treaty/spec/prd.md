# PRD — Wedding Guest Outfit Peace Treaty

## Problem
- Hyper-specific wedding dress codes can turn event guidance into budget pressure, outfit shame, family conflict, and awkward declines.

## Target user
- Wedding couples, guests, planners, family coordinators, and wedding-party members negotiating confusing dress codes, color palettes, travel budgets, and social expectations.

## Key UX
- Paste a dress-code line or outfit concern, translate it into plain guest-friendly expectations, compare "wear what you own" options, and generate a tactful couple/guest message that protects both photos and relationships.

## Required UI sections
- Dress-code drama meter
- Invite wording translator
- Guest budget and closet reality check
- Outfit acceptability lane
- Couple expectation dial
- Tactful pushback and clarification scripts
- Photo-palette compromise board
- Shareable peace treaty card

## Design profile
- playful-experimental

## Constraints
- Time: Phase A only; do not implement a custom demo.
- Budget: Spec-first prototype candidate; no external LLM/API calls.
- Platform: Stitch prompt should create the first visual prototype.

## Non-goals
- Do not become a wedding planning suite.
- Do not shame couples or guests.
- Do not focus on bridal skincare, quotes, or fee math.

## Success metrics
- User can translate confusing dress code wording into plain language.
- User can produce a tactful clarification or pushback script.
- Shareable card feels funny without being mean.

## Stitch prompt
Create a responsive playful web app prototype called "Wedding Guest Outfit Peace Treaty" for wedding couples, guests, planners, and family coordinators dealing with confusing or overly strict dress codes. The app should let a user paste invite wording or describe an outfit concern, translate the dress code into plain expectations, check guest budget and closet reality, compare acceptable outfit options, and generate tactful clarification or pushback scripts. Required sections: dress-code drama meter, invite wording translator, guest budget and closet reality check, outfit acceptability lane, couple expectation dial, tactful pushback and clarification scripts, photo-palette compromise board, and shareable peace treaty card. Use realistic wedding sample data with travel cost, gift cost, color palette, "cocktail" confusion, and one hyper-specific attire request. Design direction: use the `playful-experimental` profile with bold social-game energy, expressive but readable cards, bright contrast accents, humorous status labels, and polished shareable artifacts that feel like a portfolio-worthy wedding diplomacy toy.
