# QA checklist

## Happy path
- User pastes confusing dress-code wording.
- User sees plain-language expectations, budget/closet check, and acceptable outfit options.
- User generates a tactful clarification or pushback script and shareable card.

## Edge cases
- Guest cannot afford a new outfit after travel costs.
- Couple wants a narrow color palette for photos.
- Dress-code label conflicts with venue/weather realities.

## Acceptance verification
- No placeholder bullets remain in specs.
- Prompt includes the `playful-experimental` design direction.
- Tone is playful but avoids insulting couples or guests.
