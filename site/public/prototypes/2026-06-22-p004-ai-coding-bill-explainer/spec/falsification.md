# Falsification checklist (5–7)

1. Reject if the prototype sounds like medical advice.
2. Verify users can generate questions without entering protected health information.
3. Confirm code complexity cards are understandable to non-experts.
4. Test whether the call script is calm rather than accusatory.
5. Reject if the AI angle feels sensational or unsupported.
6. Check due-date and follow-up tracker visibility.
7. Validate that the first screen reads as a bill decoder, not a generic finance dashboard.
