# Falsification checklist (5–7)

1. If users cannot explain the product value after scanning the hero + first panel, the information hierarchy failed.
2. If the required UI sections do not support the promised workflow (Overnight summary cards; Job outcome table), the concept is underspecified.
3. If the action checklist feels generic rather than decision-driving, the prototype is not operational enough.
4. If the screen needs live integrations to make sense, the Phase A scope is wrong.
5. If a user cannot tell what to do next within 30 seconds, the CTA and state design failed.
6. If the Stitch export would require a major layout rewrite before ingestion, the prompt is too vague.
