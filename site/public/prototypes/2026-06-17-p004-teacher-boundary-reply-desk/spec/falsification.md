# Falsification checklist (5-7)

1. The first screen reads like a generic dashboard instead of the named workflow.
2. The assigned design profile (operator-dense) is not visually obvious.
3. The source-signal pain is not represented by concrete sample data.
4. The main user cannot complete the key decision in under three minutes.
5. The output artifact is not useful enough to share, screenshot, print, or send.
6. The prototype claims market proof instead of showing problem evidence.
7. The Stitch export is missing code.html or screen.png for p004.
