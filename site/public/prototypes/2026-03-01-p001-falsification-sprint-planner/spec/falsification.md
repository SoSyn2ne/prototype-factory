# Falsification checklist (5–7)

1. Do users interpret “falsification” as academic/jargony and bounce?
2. If we remove scoring entirely, does completion rate *increase* (i.e., scoring is friction not value)?
3. Will users actually write measurable kill criteria (numbers + timeframe), or keep it vague?
4. Does a fixed set of test templates (landing/outreach/price) feel restrictive vs. helpful?
5. In a real use case, do users revisit the evidence log after the experiment, or ignore it?
6. Are the chosen inputs (Impact/Confidence/Effort) too subjective to be useful?
7. Does the “pick one to run today” step create clarity or anxiety (too committing)?
