# Falsification checklist (5–7)

1. Users cannot tell the difference between approve, save, and reroute recommendations at a glance.
2. Margin impact is too abstract without line-item economics or shipping costs.
3. The reason-code heatmap distracts from actioning the queue.
4. Policy exceptions create too much noise for normal daily ops.
5. The screen feels too compliance-heavy and not operational enough.
6. The value case collapses if most brands auto-approve returns anyway.
7. The Stitch export becomes too dense to drop into the stub demo cleanly.
