# QA checklist — p004 KR 편의점 시프트/알바비 Penalty 시뮬레이터

## Happy path
- 입력 (예상 매출/주 = 800만원, 시급 = 1.3만, 주간 시프트 = 30, 직접 시간 = 50h, 4대보험 = ON) → 3 시나리오 모두 채워짐.
- 인건비 비중 약 40% (현행) → 19시간 단축 시 약 25% → 부분 무인화 시 약 15%.
- 시프트 7칸 자동 분배 (알바 가용 시간 기준).
- owner 노동시간 gauge (현행 50h → 19시간 단축 35h).
- 소상공인 정책자금 CTA 5개 표시.

## Edge cases
- 시급 < 1.3만 (현행법 위반) → 경고 표시.
- 시프트 0 (전부 owner) → 시프트 7칸 비움.
- 4대보험 OFF → 인건비 비중 -10% 자동.
- 매출 < 인건비 (적자) → 경고 CTA.
- 모바일/태블릿 1-hand 인터랙션.

## Acceptance verification
- 4 sample stores 모두 3 시나리오 + 시프트 7칸 + 정책자금 CTA 채워짐.
- 인건비/4대보험 정확도 ±10%.
- 시프트 분배 현실성 (점주 5명 평가 80% 일치).
- 정책자금 데이터 freshness ≤ 14일.
- 모바일/태블릿 1-hand 가능.
- KR-only copy.
