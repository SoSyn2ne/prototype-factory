# QA checklist

## Happy path
- User selects an itch and sees branching upgrade paths with joy, regret, constraints, and receipt poster.
- Cheapest-fix reset is visible.
- Visual direction is playful-experimental and portfolio-worthy.

## Edge cases
- User has no budget.
- User only needs a $10 repair.
- User drinks one espresso per day but wants a premium machine.
- Household constraint conflicts with the upgrade path.

## Acceptance verification
- Includes design profile, theme, and signal references.
- Stitch prompt is present and copy/paste ready.
- Phase A remains scaffold-only.
