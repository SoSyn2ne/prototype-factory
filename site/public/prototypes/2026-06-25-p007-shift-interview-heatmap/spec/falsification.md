# Falsification checklist (5-7)

1. The first screen does not expose the core workflow.
2. The prototype feels like a generic dashboard instead of Shift Interview Heatmap.
3. The design uses more than one PF design profile.
4. Source signals are treated as market-size proof instead of problem evidence.
5. The target user cannot identify the next action within five seconds.
6. The required UI sections are missing or reduced to vague cards.
7. The sample data does not match the cited problem context.
