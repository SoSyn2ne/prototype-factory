# PRD - Exception Workflow Black Box

## One-liner
A small-business workflow recorder that catches the messy exceptions owners forget to mention before they waste money on brittle AI automations.

## Candidate type
Practical / Commercial

## Target user
Owner-led service businesses, local agencies, clinics, contractors, and AI consultants preparing to automate intake, follow-up, refund, or admin workflows.

## Problem
The target user is facing an emotionally charged, expensive, or reputation-sensitive decision where raw information is scattered across messages, screenshots, bills, device metrics, or family/operator memory. The prototype should turn that scattered situation into one clear guided workflow.

## Key UX
The owner replays a real messy week through event cards, captures exception decisions, then receives a workflow map, automation readiness score, kill-list, and first safe automation brief.

## Required UI sections
- Messy-week event intake
- Channel scatter map for DMs, calls, forms, screenshots, and email
- Exception decision recorder
- Owner-heuristic capture cards
- Automation readiness score
- Tool cleanup kill-list
- First-safe-workflow brief export
- Consultant handoff memo

## Stitch prompt
Design a desktop operations product called Exception Workflow Black Box for owner-led service businesses, local agencies, clinics, contractors, and AI consultants preparing to automate intake, follow-up, refund, or admin workflows. Users replay a real messy week through event cards from Instagram DMs, calls, forms, screenshots, email, and staff notes; the app captures exception decisions, hidden owner heuristics, tool failures, and repeatable bottlenecks, then outputs an automation readiness score, tool cleanup kill-list, and first safe automation brief. Include a messy-week event intake, channel scatter map, exception decision recorder, owner-heuristic capture cards, automation readiness score, tool cleanup kill-list, first-safe-workflow brief export, and consultant handoff memo. Design direction: use the operator-dense profile with compact audit tables, sharp exception badges, restrained charcoal and white surfaces, one decisive amber action accent, and a serious process-forensics hierarchy so the product feels like a workflow black box review rather than another AI dashboard.

## Non-goals
- Do not implement a production backend in Phase A.
- Do not replace professional legal, medical, financial, or admissions advice.
- Do not turn the experience into a generic dashboard; preserve the core workflow.
