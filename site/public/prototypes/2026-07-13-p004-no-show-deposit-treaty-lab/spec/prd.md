# PRD - No-Show Deposit Treaty Lab

## Problem
- Salons, clinics, tutors, and repair shops test deposit and reminder policies without making good customers feel punished.

## Target user
- Appointment-based small businesses considering deposits, card-on-file, cancellation fees, or SMS reminders.

## Key UX
- Compare policy options, preview customer wording, tag repeat offenders, and generate a fair no-show treaty plus reminder cadence.

## Required UI sections
  - No-show loss calculator
  - Policy option comparison
  - Customer comfort preview
  - Repeat-offender lane
  - SMS reminder timeline
  - Exception rules
  - No-show treaty export

## Design profile
- calm-consumer

## Theme
- Appointment reliability / customer-friendly policy

## Source signal references
- S8 (Reddit r/smallbusiness thread; https://www.reddit.com/r/smallbusiness/comments/1tz6m53/how_do_you_reduce_noshows_for_service/); S9 (Reddit r/smallbusiness thread, 2026-07 week; https://www.reddit.com/r/smallbusiness/comments/1uqg9ua/how_much_you_are_losing_to_cancelled_bookings_no/)

## Output artifact
- customer-friendly no-show policy treaty

## Stitch prompt

```text
Create a responsive web app called "No-Show Deposit Treaty Lab" for appointment-based small businesses. Include a no-show loss calculator, deposit/card-on-file policy comparison, customer comfort preview, repeat-offender lane, SMS reminder timeline, exception rules, and a customer-friendly no-show treaty export. Design direction: use the calm-consumer profile with warm policy language, low-stress warnings, plain scheduling cards, and a reassuring service-business tone.
```
