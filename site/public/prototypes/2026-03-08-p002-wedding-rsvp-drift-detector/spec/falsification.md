# Falsification checklist (7)

1. If we show only a change log (no severity), do users still find it actionable, implying scoring isn’t needed?
2. Are “diet changes” too rare to justify first-class UI, making it feel cluttered?
3. Do users trust the diff output, or do they need the original source (message/email) to believe it?
4. Does per-guest drift overwhelm users who think in households (e.g., “Kim family”) rather than individuals?
5. Does acknowledging drift create a false sense of completeness (things can change again)?
6. When changes happen rapidly (multiple updates in a day), does the queue model break down?
7. Does this fail for cultures/events where seating is fluid (standing buffet), meaning drift isn’t painful?
