# Falsification checklist (5-7)

1. Target users say the problem is annoying but not worth changing workflow for.
2. Existing tools already solve the specific trigger with less setup.
3. Required data is too hard to collect during the stressful moment.
4. The output is too generic to support a real decision or next action.
5. The assigned design profile makes the experience less trustworthy for this audience.
6. Stitch cannot represent the key UX without becoming a static dashboard.
7. The idea is too close to a recent PF batch after source-to-interaction review.
