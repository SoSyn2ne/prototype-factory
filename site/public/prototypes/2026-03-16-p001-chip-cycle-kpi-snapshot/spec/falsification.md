# Falsification checklist (5–7)

1. Do users disagree with the chosen KPI set (they want different inputs) after 2 minutes of use?
2. Does the scorecard produce “Go” on days the user *intuitively* thinks “Avoid” due to macro/earnings risk?
3. Are receipts perceived as obvious / unhelpful (“it just repeats the sliders”)?
4. Do presets feel unrealistic or misleading (Bull/Base/Bear don’t match how people think)?
5. Does the tool encourage overconfidence (users treat it like a forecast) rather than a stance summary?
6. Is the interaction too slow/annoying compared to writing a note in a journal app?
7. When exported, does the summary lack enough context to be useful later (no specific drivers)?
