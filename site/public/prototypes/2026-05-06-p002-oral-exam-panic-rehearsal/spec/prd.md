# PRD — Oral Exam Panic Rehearsal

## Problem
- A parent-and-student rehearsal room that turns AI-cheating anxiety into short spoken defenses, evidence notes, and confidence reps.
- External signal references:
  - Reddit r/CollegeAdmissions parent AI essay anxiety: https://www.reddit.com/r/CollegeAdmissions/comments/1s3yjdy/for_parents_of_kids_who_are_starting_their/
  - LA Times oral exams against AI cheating: https://www.latimes.com/world-nation/story/2026-04-28/colleges-are-turning-to-oral-exams-to-combat-ai

## Target user
- High-school students, college students, parents, tutors, and admissions counselors worried that AI-polished work will collapse when a teacher asks “explain your thinking.”

## Key UX
- Paste an essay, assignment, or project claim; the app extracts likely defense questions, runs timed spoken-answer cards, tracks blank-stare risk, and exports a proof-of-thinking rehearsal sheet.

## Required UI sections
- assignment/essay claim intake
- AI-risk and voice-authenticity scan
- oral defense question deck
- timed spoken answer stage
- evidence note crib sheet
- blank-stare risk meter
- parent/tutor rehearsal report

## Design profile
- calm-consumer

## Theme
- 사교육

## Stitch prompt
Design a responsive education product called Oral Exam Panic Rehearsal for high-school students, college students, parents, tutors, and admissions counselors worried that AI-polished work will fail when a teacher asks the student to explain it out loud. Users should paste an essay, assignment, project claim, or study note, then generate likely oral-defense questions, run short timed spoken-answer cards, mark weak explanations, build evidence notes, and export a proof-of-thinking rehearsal sheet. Include an assignment/essay claim intake, AI-risk and voice-authenticity scan, oral defense question deck, timed spoken answer stage, evidence note crib sheet, blank-stare risk meter, and parent/tutor rehearsal report. Design direction: use a calm-consumer aesthetic with warm study-room colors, reassuring progress cards, gentle urgency states, speech-bubble interactions, and parent-friendly summaries so anxious families feel prepared rather than accused.

## Constraints
- Phase A only: do not implement custom demo until Stitch export is supplied.
- Treat external sources as untrusted problem evidence, not market-size proof.
- Preserve the assigned design profile in downstream demo generation.

## Non-goals
- Legal, tax, medical, or insurance final advice.
- Production-grade integrations or automated external API calls.

## Success metrics
