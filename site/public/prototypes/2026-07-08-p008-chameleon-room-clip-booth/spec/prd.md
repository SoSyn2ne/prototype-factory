# PRD - Chameleon Room Clip Booth

## Problem
- A browser party toy that turns webcam color-matching and room camouflage into 15-second shareable hide-and-seek clips.
- Source evidence: S13 - Windows Central, 2026-07, Meccha Chameleon viral Steam hit: A $5 two-person party game about painting yourself to blend into rooms sold 15 million copies in under a month through clip-friendly friend play. S14 - YouTube / creator clips, 2026, Meccha Chameleon first-look videos: Creator videos explain the game in one line: hide-and-seek where players paint their character to match the background.

## Target user
- Streamers, friends, students, and portfolio viewers who want a dead-simple physical webcam game that becomes a funny short clip.

## Key UX
- Use webcam or uploaded room photo, pick a hiding pose, sample background colors, get a camouflage score, and export a 15-second reveal clip card.

## Required UI sections
- Webcam room preview
- Background color sampler
- Pose and hiding zone picker
- Camouflage score meter
- Reveal countdown
- Failure highlight frame
- Clip card exporter

## Assigned design profile
- playful-experimental
- Design direction: clip-native party-toy UI with a strong first impression, playful score treatment, and one clear record/export workflow.

## Theme
- 외로움

## Practical vs fun
- Fun / Portfolio / Experimental
