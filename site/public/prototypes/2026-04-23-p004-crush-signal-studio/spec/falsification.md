# Falsification checklist — Crush Signal Studio

1. If users are too embarrassed to type in a real crush situation, the product loses its emotional hook.
2. If suggested moves feel generic, the playful framing will not save retention.
3. If the concept reads as creepy instead of charming, shareability will collapse.
4. If people only want meme screenshots and not actual rehearsal, the workflow may be too heavy.
5. If confidence scoring feels arbitrary, the core payoff will feel fake.
6. If the main loop is not instantly fun in under a minute, the portfolio angle weakens.

- Theme: 성욕
- Design profile: playful-experimental
