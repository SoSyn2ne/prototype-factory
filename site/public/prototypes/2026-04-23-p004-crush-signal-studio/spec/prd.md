# PRD — Crush Signal Studio

## Problem
- A playful flirting rehearsal lab where users turn vague attraction, unread messages, and overthinking into bold scenario cards, chemistry scores, and shareable confidence boosts.
- People often freeze between wanting to flirt and fearing embarrassment, so the moment dies in DMs, unread signals, or endless friend-group analysis.

## Target user
- Young adults who like someone, hate mixed signals, and want a fun low-stakes space to rehearse flirt energy before making a move.

## Constraints
- Time: Users should understand the top action path in under 5 minutes.
- Budget: The first version should work with manual input, lightweight imports, and no deep enterprise integrations.
- Platform: Desktop-first planning product designed for a single high-focus session.

## Non-goals
- Full back-office system replacement.
- Heavy automation that requires hidden AI decisions.
- Multi-role admin tooling beyond the core operator or end-user workflow.

## Success metrics
- Users can understand risk, upside, or chemistry state in one screen.
- Users can identify the next action without reading a long manual.
- The interface makes the emotional driver of the product feel obvious rather than abstract.

## Notes
- Theme: 성욕.
- Design profile: playful-experimental.
- Core UI sections: crush vibe intake card, mixed-signal decoder board, move suggestion carousel, chemistry confidence meter, risk-versus-reward scene builder, victory recap drawer.
