# QA checklist

## Happy path
- First screen clearly states: AI-heavy creators see which app handoffs, subscriptions, and resize steps are draining each video.
- Shows target workflow for: YouTubers, short-form creators, faceless-channel operators, and small agencies producing AI-assisted video content.
- Includes all required UI sections: workflow step map, tool subscription stack, drag and handoff score, content reuse planner, budget leak panel, weekly workflow export.
- Uses exactly one design profile: financial-analyst.
- Includes a clear output artifact or decision state.

## Edge cases
- Empty or incomplete input state is visible.
- Risk, cost, conflict, or pressure states do not rely on color alone.
- Long labels fit on mobile and desktop.
- The UI does not become a marketing landing page.
