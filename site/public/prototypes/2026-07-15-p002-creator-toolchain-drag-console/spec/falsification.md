# Falsification checklist (5–7)

1. The target user cannot recognize the job-to-be-done within five seconds.
2. The required UI sections look like a generic dashboard rather than the specific workflow.
3. The design profile is not visibly reflected in density, tone, controls, and hierarchy.
4. The cited source signals do not clearly map to the selected user pain.
5. The Stitch output cannot show the core interaction on the first screen.
6. The final artifact would be indistinguishable from a recent seven-day PF candidate.
7. The prototype lacks one obvious share, export, or decision artifact.
