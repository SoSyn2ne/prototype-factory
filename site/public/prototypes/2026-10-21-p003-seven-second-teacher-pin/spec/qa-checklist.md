# QA checklist

## Happy path
- 학생 별칭을 선택해 7초 음성을 남기고 비식별화 전후를 검토한다.
- 관찰 칩을 수정·승인한 뒤 학교 서식 미리보기를 내보낸다.

## Edge cases
- 오프라인, 마이크 거부, 이름 노출, 승인 거절, 즉시 삭제, 빈 녹음.
- 자동 문장에 근거 없는 평가 표현이 섞이면 경고하고 제거한다.

## Acceptance verification
- 승인 전 내보내기가 차단되고 원본/수정본 연결이 유지된다.
- 모든 주 제어가 44px 이상이며 390px에서 한 손 조작 가능하다.
