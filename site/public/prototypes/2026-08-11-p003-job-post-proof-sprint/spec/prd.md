# PRD — Job Post to 7-Day Proof Sprint

## Problem / target
Junior developers find jobs but cannot turn requirements into credible evidence. Target: career changers and bootcamp graduates applying this week.

## Core UX
Paste JD → evidence verbs → choose proof project → seven daily artifacts → requirement-to-repo map → interview stories. Sections: JD, gaps, project cards, timeline, repo checklist, story deck.

## Design / theme / evidence
- Profile: `premium-editorial`; theme: 역전.
- Sources: S3 https://news.hada.io/topic?id=32325; S2 https://news.hada.io/topic?id=32321.
- QA: each requirement maps to an inspectable artifact; seven-day scope is credible; first project choice is understandable in 3 seconds.

## Stitch prompt
Design a responsive web app named “Job Post to 7-Day Proof Sprint.” Start with a split editorial layout: paste a developer job description on the left and see extracted evidence verbs and missing proof on the right. Let the user choose one of three tightly scoped portfolio projects, then reveal a seven-day timeline with one visible commit/deliverable per day, a requirement-to-repo evidence matrix, and five interview story cards linked to actual artifacts. Include progress, risk, and deadline states. Design direction: follow the premium-editorial profile with strong typography, black/ivory/one cobalt accent, magazine-like section rhythm, thin rules, and polished artifact previews rather than dashboard chrome.
