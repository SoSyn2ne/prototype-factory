# Falsification checklist (5–7)

1. Do coordinators already have a spreadsheet that’s “good enough”, making a new console pointless?
2. Does group-based seating create more problems than it solves (e.g., splits couples / ignores conflict pairs)?
3. Is printing a checklist too crude (they need export to PDF/Excel instead)?
4. Are allergy/accessibility notes too sensitive to store in a browser without encryption/auth?
5. Does data entry overhead outweigh value for weddings under ~50 guests?
6. Does the seating heuristic produce obviously bad output when one group is larger than a table?
7. In real usage, do users need multi-device collaboration (phone + laptop), invalidating local-only storage?
