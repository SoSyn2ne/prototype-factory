# Falsification checklist (7)

1. If users consistently ask “where did the numbers come from?” and stop using it, the heuristic isn’t transparent enough.
2. If different shock types produce rankings that feel indistinguishable, the model is too blunt to be useful.
3. If users want *news links and live context* more than ranking, a static offline simulator is the wrong product shape.
4. If experienced investors disagree with the direction of effects (e.g., equipment vs. designers) for common scenarios, the factor mapping is wrong.
5. If users can’t produce a one-sentence rationale after viewing the output, the UI/explanation is insufficient.
6. If the ranking changes too frequently with small slider moves (feels “noisy”), the scoring function needs smoothing.
7. If users only care about 1–2 tickers and not portfolio-level prioritization, the ranking table adds little value.
