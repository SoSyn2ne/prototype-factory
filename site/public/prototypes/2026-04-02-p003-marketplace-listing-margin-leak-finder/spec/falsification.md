# Falsification checklist (5–7)

1. Do marketplace teams already find margin leaks quickly enough in existing seller dashboards?
2. Is the real pain pricing authority rather than diagnostics and prioritization?
3. Are return and fee signals too delayed to support weekly intervention?
4. Would users value campaign-level recommendations more than listing-level triage?
5. Is coupon stacking too niche a problem outside a narrow class of sellers?
6. Does this become useful only when it can push fixes directly into marketplace systems?
7. Would finance teams prefer a margin postmortem report over an operator-facing control desk?
