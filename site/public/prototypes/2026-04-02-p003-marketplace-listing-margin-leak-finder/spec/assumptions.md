# Assumptions (KNOWN / ASSUMPTION / UNKNOWN)

## KNOWN
- Margin leakage often hides inside otherwise healthy top-line marketplace sales.
- Operators need listing-level prioritization more than exhaustive analytics depth.
- Weekly intervention is a realistic rhythm for merchandising and marketplace teams.

## ASSUMPTION
- Coupon, ad, fee, and return signals can be combined into a trusted leak score.
- Users will act if recommended fixes clearly show margin recovery potential.
- A compact comparison panel can replace several spreadsheet-style review steps.

## UNKNOWN
- Which leak source creates the strongest pain: ad overspend, promo abuse, or fee drag.
- Whether teams want catalog-wide scanning or campaign-specific review mode first.
- How much explanation users need before trusting the recommendation engine.
