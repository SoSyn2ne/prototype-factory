# Falsification checklist

1. If it reads like generic compliance content instead of shipment readiness, reject.
2. If the IOR checklist is not tied to actual release risk, redesign.
3. If supplier ownership/control flags are buried, the policy signal is underused.
4. If bond exposure and duty risk are not comparable by SKU/shipment, value drops.
5. If broker handoff tasks lack owners and dates, it is not operational.
6. If the memo generator is not grounded in current gaps, remove it.
7. If the visual system feels playful or consumer-grade, revise to financial-analyst.
