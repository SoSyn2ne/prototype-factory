# Falsification checklist — Pocket Linux Sidequest Deck

1. Five target users say the trigger rarely occurs.
2. Four of five already solve it satisfactorily with one existing tool.
3. Users cannot understand the first screen in three seconds.
4. The core loop needs unavailable private data to feel credible.
5. The output is not saved, shared, or acted on in a moderated test.
6. The playful-experimental profile obscures the primary action on mobile.
7. Source signals S7 and S12 do not reproduce in follow-up interviews.
