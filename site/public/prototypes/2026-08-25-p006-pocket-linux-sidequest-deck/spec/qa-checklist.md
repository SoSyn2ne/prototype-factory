# QA checklist — Pocket Linux Sidequest Deck

## Happy path
- Complete: Scan capabilities, deal three quests, run one with physical controls, capture proof, remix, and share a quest cartridge.
- Confirm every required section is present: Capability scan; quest deal; timer; control mapping; proof capture; remix rules; scoreboard; share card.

## Edge cases
- Empty input, malformed input, low-confidence evidence, long text, and mobile width have explicit states.

## Acceptance verification
- A quest is understandable within 15 seconds; controls map to real device inputs; safety notes appear before field actions.
- Source refs S7, S12 and profile playful-experimental match ideas.md and meta.json.
