# Falsification checklist (5–7)

1. Do users actually compare packages before the consult, or only after?
2. Does payoff framing feel credible without before-and-after data?
3. Would clinics resist a tool built to limit upsell behavior?
4. Is the emotional trigger too strong for rational planning UI to change behavior?
5. Do users want peer benchmarks or does that worsen insecurity?
6. Will a desktop-first format fit this high-intent moment?
7. Can the product feel appearance-smart without becoming judgmental?
