# PRD — Hagwon Burn Rate Board

## Problem
- A private education control panel that helps parents decide which hagwon, tutor, and workbook spend to keep, pause, or replace before guilt destroys the monthly budget.

## Target user
- Korean parents managing multiple classes and tutors who fear falling behind but need a defensible way to reduce spend and child fatigue.

## Theme
- 사교육

## Design profile
- operator-dense

## Key UX
- Put tuition burn, subject confidence, child fatigue, and exam timing on one board so parents can make one hard cut without feeling reckless.

## Required UI sections
- monthly tuition burn meter
- subject confidence grid
- child fatigue heatmap
- exam deadline strip
- keep-pause-replace command board
- family decision memo drawer

## Stitch prompt
Design a desktop parent operations board called Hagwon Burn Rate Board for Korean parents trying to control private education costs without feeling like they are sacrificing their child's future. It should combine tuition burn, subject confidence, child fatigue, and exam deadlines so users can decide which hagwon, tutor, or workbook spend to keep, pause, or replace. Include a monthly tuition burn meter, a subject confidence grid, a child fatigue heatmap, an exam deadline strip, a keep-pause-replace command board, and a family decision memo drawer. Design direction: use an operator-dense aesthetic with compact high-signal panels, dark slate neutrals, tight hierarchy, spreadsheet-like clarity, and one decisive action accent so the product feels practical, controlled, and built for hard family tradeoffs.
