# PRD — Agent Repo Graveyard Derby

## Problem
- Players bet which trending AI-agent repo will survive the week before the hype meter buries it.

## Target user
- Developer communities, AI-tool skeptics, devrel teams, and portfolio viewers who enjoy open-source trend humor.

## Key UX
- Pick a trending repo horse, inspect star spike vs commit durability, dodge hype traps, and watch the repo either ship, stall, or collapse into the graveyard.

## Required UI sections
- repo horse lineup
- hype meter
- durability cards
- weekly race lane
- collapse animation state
- shareable prediction card

## Design profile
- playful-experimental

## Theme
- AI repo hype, open-source durability, developer culture

## Source signal references
- S2 GitHub Trending runnable LLM apps
- S3 Reddit AI repo fatigue

## Stitch prompt
Build a polished web prototype called "Agent Repo Graveyard Derby" for a playful AI-developer culture game. The first screen should show trending AI-agent repos as race entrants, a hype meter, commit durability cards, weekly race lanes, funny collapse states, and a shareable prediction card. Required sections: repo horse lineup, hype meter, durability cards, race lane, collapse result state, and share card export. Design direction: use the playful-experimental profile with bold arcade energy, readable developer-data labels, controlled color pops, and funny failure states that still feel polished.

## Constraints
- Phase A only: do not implement a custom demo here.
- The 08:30 Stitch automation should export code.html and screen.png into the expected drop folder.

## Success metrics
- A reviewer can understand the first screen, target user, source evidence, and design profile without additional context.
- Stitch prompt is copy/paste-ready and contains the tailored profile direction.
