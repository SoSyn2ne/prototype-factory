# QA checklist

## Happy path
- First screen communicates: Stop typing your life story into a bot that only needed the word “cancel.”
- User can identify the target user and trigger within 3 seconds.
- User can complete the primary mechanic: bot maze escape.
- Prototype produces: Personalized human-agent script and escalation path card..

## Edge cases
- Empty input state explains what proof/data is needed.
- User with partial evidence can still get a next step.
- Mobile layout keeps key actions reachable.
- Copy avoids claiming legal, medical, insurance, or financial guarantees.

## Acceptance verification
- Design profile appears exactly once as playful-experimental.
- Required sections are present: Bot maze scenario picker, Trigger phrase cards, Evidence inventory, Escalation timer, Human-agent victory script.
- Stitch prompt cites signals S21, S22, S23 as problem evidence only.
- No custom demo is implemented during Phase A.
