# Falsification checklist (5-7)

1. Users see any verification as creepy.
2. Dating apps block or discourage profile inserts.
3. Friend attestations create social pressure or harassment risk.
4. AI-photo suspicion explainer feels like a detector despite disclaimers.
5. Singles-event hosts prefer offline-only icebreakers.
6. Privacy concerns prevent sharing enough proof.
7. The concept is funny but not repeat-usable.
