# Assumptions (KNOWN / ASSUMPTION / UNKNOWN)

## KNOWN
- Renewal leakage is the core value story, not generic property CRM activity.
- Users need to balance occupancy preservation against concession cost quickly.
- A single desktop screen should surface which tenants deserve immediate outreach.

## ASSUMPTION
- Teams already hold enough lease and payment history to estimate renewal confidence.
- Save actions can stay high-level without modeling full legal lease workflows.
- Most renewal triage happens on desktop during weekly occupancy reviews.

## UNKNOWN
- How much maintenance history needs to appear before the screen feels too dense.
- Whether managers prefer vacancy-risk ranking over tenant sentiment signals.
- Which concession simulator inputs feel essential for first-pass decision-making.
