# Falsification checklist

1. The first screen reads like a generic dashboard instead of benchmarking workbench + negotiation memo.
2. A target user cannot identify the next action within 5 seconds.
3. The required UI sections are missing: Fee burden comparison by platform; Promo/free-delivery cost pass-through tracker; Peer benchmark cards by cuisine/order size; Dispute evidence checklist; Negotiation packet preview in Korean.
4. The design direction does not match financial-analyst.
5. The prototype depends on source claims as market-size proof instead of treating them as problem evidence.
6. The workflow duplicates one of the last 7 PF batches without a new user, trigger, data source, or interaction mechanic.
7. The final screen lacks a shareable output, packet, receipt, or result tied to: A merchant can show a printable packet to nearby owners and recruit them into the same evidence pool.
