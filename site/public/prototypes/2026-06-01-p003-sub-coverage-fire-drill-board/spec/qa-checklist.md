# QA checklist

## Happy path
- User can enter absences and see coverage assignments, flags, sub cards, broadcasts, and notes.
- Missing plans and mismatched rooms are visually urgent.
- UI feels reliable, touch-friendly, and field-ops oriented.

## Edge cases
- No available substitute.
- Multiple absences in one department.
- Missing lesson-plan links.
- A room swap affects another coverage block.

## Acceptance verification
- Includes design profile, theme, and signal references.
- Stitch prompt is present and copy/paste ready.
- Phase A does not implement a custom demo.
