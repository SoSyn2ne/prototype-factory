# Falsification checklist (5–7)

1. Users cannot distinguish normal reorder variance from true revenue risk.
2. The watchlist table feels too CRM-like and not urgent enough for daily action.
3. Diagnosis details overwhelm the screen before the next step is clear.
4. Suggested recovery plays feel generic without account history depth.
5. The revenue rescue summary does not make saved upside concrete enough.
6. The value weakens if most accounts already reorder automatically.
7. The Stitch export becomes too dense to slot into the stub demo cleanly.
