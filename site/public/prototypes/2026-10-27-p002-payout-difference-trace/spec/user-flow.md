# User flow — 쇼핑몰 정산 차이 추적

## Happy path — 향후 실증
작성자의 직접 경험 확인 → 담당자 동의·자료 정의 확인 → 한 스토어·정산명세 한 건과 대응 거래 파일 확보 → 수작업으로 구성·연결 키 정리 → 근거가 있는 설명과 미해결 항목 분리 → 담당자가 원본 행·기간·통화를 검토 → 읽기 전용 검토 자료와 수동 후속 절차를 인수한다.

## Edge 1 — 서로 다른 범위
파일의 통화·기간·결제 경로·매출/입금 정의가 다르면 합계를 맞추지 않는다. 어떤 정의와 자료가 부족한지 표시하고 담당자가 추가 설명을 줄 때까지 보류한다. 추가 자료가 필요하면 파일럿 범위를 다시 합의한다.

## Edge 2 — 환불·조정의 연결 불가
원거래 키가 없거나 다른 기간으로 연결되면 “미연결·검토 필요”로 남긴다. 정상 시차·수수료·오류를 추정 확정하지 않는다. 현행 장부와 파일은 수정하지 않고 기존 수작업·지원 문의로 돌아갈 근거를 남긴다. 현재 HTML은 이 흐름의 고정 예시만 보여 준다.
