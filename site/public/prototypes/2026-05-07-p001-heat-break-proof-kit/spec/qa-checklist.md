# QA checklist — Heat Break Proof Kit

## Happy path
- User lands on the product and understands the target user + one-liner immediately.
- User can follow the core intake → analysis → recommended action/export path.
- All required UI sections are present in the Stitch demo.

## Edge cases
- Empty or incomplete input shows helpful examples instead of generic errors.
- Risk/scoring states avoid making final legal, safety, financial, or identity claims.
- Mobile/tablet/desktop behavior matches the intended context of use.

## Acceptance verification
- Design profile `field-ops` is visible in layout, density, color, and interaction style.
- Theme `건강` is explicit in copy or visual metaphor.
- Source references remain in meta/spec for traceability.
