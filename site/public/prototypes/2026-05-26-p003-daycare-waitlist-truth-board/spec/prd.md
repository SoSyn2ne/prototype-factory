# PRD - Daycare Waitlist Truth Board

## Problem
A parent-facing and center-facing waitlist transparency board that turns invisible childcare queues into clear next actions.

## Target user
Childcare center directors, admissions coordinators, and parents trying to understand realistic enrollment timing.

## Key UX
Centers publish queue rules and available-age-room projections while parents see their readiness status, follow-up tasks, and honest likelihood bands instead of calling every week.

## Required UI sections
- Center capacity snapshot by age room and target month
- Waitlist queue explainer with sibling priority, readiness, deposit, and response windows
- Parent readiness checklist for start date flexibility, paperwork, subsidy, schedule, and backup care
- Offer simulation lane for admins showing who will likely accept or ghost
- Communication log with templated updates to reduce repeated calls
- Fairness audit panel showing rule consistency and manual overrides
