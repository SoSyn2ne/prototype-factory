# PRD — Search Funeral Zine Machine

## One-liner
A playful memorial generator that turns a dying SEO article into a direct-audience comeback asset.

## Type
Fun / Experimental

## Problem
Users are dealing with a time-sensitive, high-stakes workflow where evidence, documents, or trust signals are scattered across systems and the penalty for delay is financial loss, missed opportunity, or public embarrassment.

## Target user
Independent publishers, niche bloggers, affiliate creators, and portfolio designers reacting to AI-search traffic collapse.

## Key UX
Paste a declining URL and traffic-loss note; the machine creates a "funeral zine" with obituary headline, lost-keyword tombstones, direct-audience CTA, email signup artifact, and shareable comeback poster.

## Required UI sections
- URL and traffic-loss input
- Article obituary generator
- Lost keyword graveyard
- Direct-audience conversion blocks
- Zine/poster preview
- Share/export controls
- Revival checklist

## Design profile
- playful-experimental

## Theme
- 역전

## External signal references
- Signal 3: Axios report on small publishers search traffic decline - https://www.axios.com/2026/03/17/chartbeat-search-traffic-ai-chatbots
- Signal 4: AI trust backlash around interview automation as a broader shareable cultural frame - https://www.hrdive.com/news/job-seekers-walk-away-from-AI-interviews/819443/

## Stitch prompt
Build a playful web app prototype called "Search Funeral Zine Machine" for independent publishers whose SEO articles are losing traffic to AI search. The interface should include URL and traffic-loss input, article obituary generator, lost keyword graveyard, direct-audience conversion blocks, zine/poster preview, share/export controls, and revival checklist. Use sample data for a niche review blog whose Google referrals dropped and whose AI referrals did not compensate. Design direction: apply the `playful-experimental` profile with bold editorial collage energy, humorous memorial motifs, punchy contrast, and portfolio-worthy visual moments while keeping the conversion CTA usable.

## Constraints
- Phase A only: spec and scaffold, no custom implementation.
- Demo must later preserve the original Stitch export environment.

## Success metrics
- User can understand the core workflow from first screen.
- Prototype presents a concrete, copyable artifact or decision output.
- Prompt includes design direction aligned with the assigned profile.
