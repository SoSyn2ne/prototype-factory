# PRD - Kiosk Empathy Field Test

## Problem
- A field kit for Korean shops to test whether seniors and disabled customers can actually complete kiosk orders before complaints or mandates land.
- Evidence: S14 (Korea kiosk accessibility mandate and user frustration, 2026).

## Target user
- Korean cafe owners, franchise operators, kiosk vendors, accessibility consultants, and store managers training staff assistance.

## Key UX
- A tablet-friendly field checklist where a manager runs timed order tasks with seniors or disabled testers, logs failure points, maps staff-assist alternatives, and exports a retrofit or compliance action sheet.

## Required UI sections
- Field-test session header with store, kiosk model, tester profile, and completion score
- Task script cards for ordering coffee, changing options, applying coupon, paying, and canceling
- Pain-point logger for height, touch targets, button discovery, voice guidance, glare, and queue pressure
- Staff-assist lane comparing immediate help, bell button, printed menu, and alternate payment flow
- Retrofit decision board for voice guide, tactile labels, screen angle, font size, queue layout, and staff training
- Complaint-risk and mandate checklist with evidence photos and vendor follow-up
- Before/after field report for owner, vendor, and local inspection file
