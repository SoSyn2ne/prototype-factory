# PRD — Teen Micro-Camp Swap Board

## Problem
- Parents of older kids pool half-day activities, host rotations, and pickup coverage when normal camps vanish or cost too much.

## Target user
- Working parents with kids 12+ who are too old for many camps but not ready to be unsupervised all summer.

## Key UX
- Build a parent pod schedule, list trusted hosts and paid mini-activities, balance pickups, and create a weekly safety/contact sheet.

## Required UI sections
  - Teen availability grid
  - Parent host rotation
  - Paid activity cost row
  - Pickup and commute coverage
  - Emergency contact sheet
  - Behavior and screen-time pact
  - Weekly swap receipt

## Design profile
- calm-consumer

## Theme
- Parent logistics / offline childcare

## Source signal references
- S14 (Reddit r/workingmoms, r/nycparents, r/longisland discussions)

## Output artifact
- teen micro-camp weekly swap sheet

## Stitch prompt

```text
Create a responsive planning app called “Teen Micro-Camp Swap Board” for parents of older kids who lack affordable summer camp options. Show a teen availability grid, parent host rotation, paid mini-activity cost rows, pickup coverage, emergency contact sheet, behavior and screen-time pact, and weekly swap receipt. Design direction: use the calm-consumer profile with warm practical planning surfaces, readable family schedules, low-stress warning states, and clear share/export controls.
```
