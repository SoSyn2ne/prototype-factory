# Falsification checklist (5–7)

1. Target users do not recognize the problem in the first screen.
2. Users say the workflow feels like a generic dashboard instead of a new mechanic.
3. The required inputs are too hard to gather manually.
4. The suggested action does not map to a real buying/sharing trigger.
5. The design profile `field-ops` does not fit the user's urgency or emotion.
6. The external signals are too weak or too derivative of recent PF batches.
7. The Stitch prompt fails to produce a main workflow with all required UI sections.
