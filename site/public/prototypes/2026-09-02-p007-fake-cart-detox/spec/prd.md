# PRD — Fake Cart Detox

## Problem
Fill a zero-charge cart and reveal the feeling each item was hired to create.

## Target user
Impulse shoppers, students, and friends wanting a playful pause.

## Core loop / key UX
Pretend-checkout, watch a fake delivery, then sort items by emotional intent before the cart dissolves.

## First screen
Make the core action and its evidence immediately understandable in three seconds.

## Required UI sections
fantasy storefront; zero-charge cart; emotion tags; pretend delivery; reveal; postcard; replay.

## Design
- Assigned profile: `playful-experimental`
- Theme: 충동 소비 실험

## Source signals
S10, S12 from `daily/2026-09-02/ideas.md`.

## Non-goals
- No production integrations or custom demo in Phase A.

## QA / screenshot criteria
No payment path exists; the three-second rule is clear and reduced-motion mode preserves the ritual.
