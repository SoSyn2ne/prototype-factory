# PRD - Solo Sick-Day Check-In Pact

## Problem
People who live alone create a non-creepy safety pact for missed check-ins, illness days, and emergency escalation.

## Target user
Single-person households, solo expats, remote workers, adult children living away from parents, and friends caring for each other from afar.

## Key UX
User defines normal routines, illness flags, trusted contacts, privacy boundaries, missed-check escalation, and comfort messages; the app simulates exactly what happens if they go quiet.

## Required UI sections
- Daily check-in status header with privacy level and next deadline
- Routine pattern and exception builder
- Illness-day quick mode with symptoms, supplies, and help threshold
- Trusted contact escalation ladder
- Message preview for gentle nudge, concern, and emergency
- False-alarm pause and travel mode controls
- Shareable pact summary for friends or family

## Assigned design profile
calm-consumer

## Theme
외로움 / 건강 - solo living safety without shame or surveillance.

## Stitch prompt
Build a production-grade web app prototype called "Solo Sick-Day Check-In Pact" for people who live alone and want a gentle safety net. The first screen must be a working check-in pact workspace with a daily status header, routine pattern builder, illness-day quick mode, trusted contact escalation ladder, message previews, false-alarm pause controls, travel mode, and shareable pact summary. Use realistic sample data: Seoul studio apartment, missed morning check-in, mild fever, no nearby family, two trusted friends, privacy level set to low-detail, two-day escalation rule, and a travel pause ending tonight. Design direction: use the calm-consumer profile with soft emotionally steady surfaces, clear reassurance copy, large readable safety states, and one gentle accent for confirming the pact. Do not make a marketing landing page; the first screen must be the working app.
