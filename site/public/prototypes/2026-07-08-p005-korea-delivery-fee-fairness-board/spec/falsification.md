# Falsification checklist

1. The first screen looks like a generic marketing page instead of the core workflow.
2. The prototype cannot produce delivery platform fairness receipt.
3. The user must understand policy or technical jargon before taking action.
4. The source evidence is treated as market-size proof instead of problem evidence.
5. The design ignores the assigned financial-analyst profile.
6. The workflow is too close to a recent PF batch without a new trigger, user, data source, or mechanic.
7. The Stitch prompt is not copy/paste-ready.
