# PRD — AliExpress Category Tariff Splitter

## Problem
- Mixed-category cheap import carts can become expensive when customs fees stack by product category, and hobbyists currently split orders by guesswork.

## Target user
- 3D printing hobbyists, electronics tinkerers, cosplay makers, and micro-import buyers building mixed-category carts.

## Constraints
- Time: Must help before checkout.
- Budget: Lightweight scenario tool, not a customs broker.
- Platform: Responsive Stitch web prototype with synthetic cart and fee assumptions.

## Non-goals
- Do not provide official customs advice.
- Do not connect to AliExpress or customs systems.

## Success metrics
- User can compare one-package vs split-package fee scenarios in one screen.
- Fee uncertainty and delivery-delay tradeoffs are visible.
