# PRD — Drone Roof Nonrenewal Sprint

## Problem
- Homeowners respond to insurer drone-photo roof threats with repair proof, inspection asks, and a renewal appeal timeline.

## Target user
- Homeowners who receive roof-condition notices, drone-photo inspection claims, cancellation threats, or nonrenewal letters from insurers.

## Key UX
- Log the insurer notice, request inspection evidence, attach roofer photos, track repair proof, and draft a nonrenewal appeal or broker call script.

## Required UI sections
  - Notice intake and deadline
  - Drone/photo evidence request checklist
  - Roofer inspection proof board
  - Targeted repair vs replacement lane
  - Insurer response timeline
  - Broker call script
  - Renewal appeal packet

## Design profile
- field-ops

## Theme
- Home insurance defense / field evidence

## Source signal references
- S13 (Reddit r/HomeInsurance / r/homeowners discussions, 2026 and earlier)

## Output artifact
- roof renewal evidence packet

```text

Design direction: use the field-ops profile with sturdy forms, photo evidence rails, high-contrast deadlines, practical mobile-first controls, and restrained emergency color only for renewal dates.
