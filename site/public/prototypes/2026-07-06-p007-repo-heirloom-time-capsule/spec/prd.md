# PRD — Repo Heirloom Time Capsule

## Problem
- A playful physical-ownership kit that turns a beloved GitHub repo into a printable archive, story card, and handoff ritual.
- Source evidence: S14 - PC Gamer report on GitHub's limited repo CD-ROM promotion: A playful campaign around physical code ownership points to broader anxiety about digital impermanence and archival rituals.

## Target user
- Indie developers, educators, open-source maintainers, and portfolio builders who want to make code feel tangible.

## Key UX
- Paste repo metadata, choose a preservation mood, then generate a mock CD label, story card, dependency tombstone, and handoff note.

## Required UI sections
- Repo import card
- Archive mood selector
- Physical label preview
- Dependency tombstone
- Story card
- Share/export ritual

## Design profile
- playful-experimental
- Design direction must be tailored inside the Stitch prompt and avoid generic dashboard styling.

## Theme
- 역전 / 포트폴리오

## Stitch prompt
Create a responsive web prototype for "Repo Heirloom Time Capsule". Target user: indie developers and open-source maintainers who want to turn a meaningful repository into a tangible portfolio artifact. Core UX: the user pastes repo metadata, picks an archive mood, and the product generates a mock CD label, dependency tombstone, project story card, and handoff note for future collaborators. Required sections: repo import card, archive mood selector, physical label preview, dependency tombstone, story card editor, and share/export ritual. Use the playful-experimental design profile: memorable concept-forward composition, one bold accent, strong first impression, recognizable controls, and novelty that never hides the workflow.

## Success metrics
- A Stitch operator can paste the prompt without rewriting it.
- The first screen shows the actual workflow, not a landing page.
- The output artifact is visible before the fold or immediately after the primary input.
