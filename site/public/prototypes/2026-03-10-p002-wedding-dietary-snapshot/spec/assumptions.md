# Assumptions (KNOWN / ASSUMPTION / UNKNOWN)

## KNOWN
- Dietary needs are often collected late and are easy to lose in chat threads.
- A kitchen needs counts (“how many vegan?”) more than narratives.
- People can have multiple constraints (e.g., vegetarian + nut allergy).

## ASSUMPTION
- A lightweight, offline tool is preferable to a full account system for a one-off event.
- Exporting as JSON (plus a plain text summary) is enough for downstream workflows.
- A short set of common tags covers 80–90% of cases.

## UNKNOWN
- Whether planners prefer per-table summaries (depends on seating finalized).
- Whether CSV export is more demanded than JSON.
- Whether guests will self-enter data (vs operator entry).
