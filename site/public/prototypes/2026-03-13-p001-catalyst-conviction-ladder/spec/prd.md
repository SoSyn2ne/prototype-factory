# PRD — Catalyst Conviction Ladder

## Problem
Investing decisions often start as messy "catalyst notes" (earnings, product launch, macro print, regulatory headline). The notes are:
- hard to compare across time horizons,
- easy to overweight with vibes,
- rarely paired with explicit disconfirming signals.

The result: weak conviction hygiene. People either (a) never act, or (b) act without a clear ranking and without a falsification plan.

## Target user
- Individual investors and small operators who maintain a watchlist and want a lightweight, repeatable way to rank catalysts.
- A user who is comfortable with simple scoring but not interested in a complex portfolio system.

## Constraints
- Time: 2–5 minutes per session.
- Budget: $0; static demo.
- Platform: local browser; no backend.
- Data: user-entered only (no market data integration in this prototype).

## Non-goals
- Price targets, full valuation models, or portfolio optimization.
- Live data pulls (earnings calendars, macro releases, etc.).
- Multi-user collaboration.

## Success metrics
- User can add 5–10 catalysts and immediately see a ranked ladder.
- User can explain why a catalyst ranked higher (formula is visible).
- User can generate plausible falsification questions and copy them into notes.

## Notes
This is intentionally a "decision hygiene" tool. The key value is forcing explicit inputs (impact, confidence, horizon) and pairing each catalyst with disconfirming prompts.
