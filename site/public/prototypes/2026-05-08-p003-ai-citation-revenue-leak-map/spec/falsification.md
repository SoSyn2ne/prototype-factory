# Falsification checklist (5–7)

1. Can the target user understand the pain and promise in 10 seconds?
2. Does the core screen avoid looking like a renamed recent dashboard/rescue/planner idea?
3. Are the cited signals visible as problem evidence, not fake market-size proof?
4. Does the assigned design profile (financial-analyst) clearly shape layout, colors, density, and microcopy?
5. Do all required UI sections appear in the Stitch prompt and PRD?
6. Is there a plausible paid, lead-gen, affiliate, agency, or viral sharing path?
7. Would a static Stitch demo still communicate the mechanic without external APIs?
